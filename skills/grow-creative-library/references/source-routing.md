# 来源路由与笔记架构

## 入库前确认门

任何“总结、记录、整理并放进 OS / Obsidian”的请求，都先按 [分区契约](library-layout.md) 判断学习或创作目的，再确定来源层笔记架构。已明确的目的、去向、架构或授权直接沿用；仅在关键决定缺失时确认一次。所需确认尚未取得时只允许读取链接元数据、可见目录、标题、时长、文件属性和已有笔记；不要下载完整媒体、运行 ASR/OCR、起草正式笔记或修改 vault。

一次确认必须同时给出：

- `材料类型`：课程、访谈、书籍、文章、零散知识等来源性质；
- `笔记架构`：来源层最终采用什么文件结构；
- `聚合单位`：按课、章、集、单篇或主题整理；
- `归位`：学习区子目录，或明确服务的创作岗位；
- `专业分类`：六类之一，作为属性和专业索引，不决定存储位置。

推荐问法：

> 我判断这是【材料类型】，建议采用【笔记架构】，按【聚合单位】整理；归入【创作岗位或学习子目录】，专业分类为【六类之一】。请选择：按推荐处理 / 改为单篇 / 自定义。

用户已经明确指定结构时，视为已经确认。来源总览或单篇来源笔记已有 `架构状态: 已确认` 时，后续新增材料直接沿用 `笔记架构` 和 `聚合单位`；只有新季、新模块、新卷或材料性质明显变化时才重新询问。

## 路由矩阵

| 材料类型 | 默认笔记架构 | 聚合单位 | 来源层默认结构 |
|---|---|---|---|
| 结构化课程、教学系列 | `课程分层` | `课` | 课程总览 + 按真实课次或模块的课级笔记 + 有实际跨课知识时建立统一知识总结 |
| 单场访谈、对谈、圆桌、播客 | `单篇材料` | `单篇` | 一篇来源笔记，内部按话题、发言关系和时间线整理 |
| 连续访谈或播客系列 | `系列分层` | `集` | 系列总览 + 每场独立访谈或每期节目一篇笔记 |
| 书籍、长报告、系统 PDF、EPUB | `章节分层` | `章` | 材料总览 + 按章节、部分或稳定主题模块的笔记 |
| 文章、论文、博客、独立视频 | `单篇材料` | `单篇` | 一篇来源笔记，保留原文标题或视频时间线 |
| 同主题零散知识、同批短链接 | `单篇材料` | `主题` | 一篇持续积累的来源笔记，按问题或主题分节 |
| 单条明确知识且用户要求加入知识树 | `主题直融` | `主题` | 融入已有主题笔记并保留精简来源卡；找不到合适主题时进入知识树收件箱 |
| 混合材料或类型不明 | 待确认 | 待确认 | 先分别提取元数据并给出推荐，不在确认前创建正式笔记 |

## 架构字段

新建或实质更新的来源总览、单篇来源笔记和聚合笔记记录：

```yaml
笔记架构: 课程分层 / 系列分层 / 章节分层 / 单篇材料 / 主题直融
聚合单位: 课 / 章 / 集 / 单篇 / 主题
架构状态: 已确认
```

这些字段只控制来源层形态，不替代 `分类`、`材料类型`、`沉淀状态` 或知识层主题属性。不要因物理归位批量升级旧笔记的属性或正文。

## 结构化课程

- 先读取完整课程目录或当前可见课次，建立课程矩阵，再开始详细整理。
- 聚合边界以真实教学目标、课次、模块和讲者命名为准，不以视频文件或 Bilibili `P` 机械切分。
- 多个 P 属于同一课时，合并到一篇课级笔记，并在 YAML 中记录起始 `P` 与完整 `包含P`。
- 课程总览回答“每一课讲什么、每一集讲什么、从哪里进入”；课级笔记承载分集脉络、时间线、案例与讲者原有的训练方法；统一知识总结保留跨课模型、方法、案例索引和工作流，不默认布置复习任务。
- 统一知识总结必须有真实内容才创建，不建立空白总结。跨课知识默认在学习区内部总结；用户明确选定具体知识后，才向创作区对应主题提炼并保留原课程来源。

## 访谈、对谈与播客

- 单场材料默认只建一篇来源笔记，不把每个话题拆成文件。
- 内部保留嘉宾、语境、关键主张、分歧、案例和时间线；讲者观点与 Codex 综合分开。
- 只有当多个独立场次构成稳定命名系列时，才使用系列总览和逐场笔记。系列综合知识在已确定分区内进入主题笔记，不额外制造重复总总结；个人学习访谈不自动进入创作区。

## 零散知识与短材料

- 同一批次或同一问题的零散材料默认进入一篇持续积累来源笔记，按问题分节并保留每条来源。
- 用户明确说“把这条知识放进知识树”且内容是一个可核查的紧凑命题时，才使用 `主题直融`；按已明确的学习或创作用途选择目标，未明确进入创作时不将学习知识自动跨区。
- 主题不明确、证据不足或无法安全合并时，写入 `知识树收件箱.md`，不创建空主题和空 wikilink。

## 网页文章与博客

优先读取可见正文、标题、作者、发布日期、小标题和原始链接。遇到动态页面或登录态内容，使用已安装的浏览器控制 Skill。文章导览按小标题和语义转折拆分，不使用虚构页码。

## B站视频与课程

调用 `bilibili-study-notes`。确认架构后再提取：优先字幕；无字幕时使用音频 ASR。保留分 P、标题、时长、时间戳和提取准确度。原始 `metadata.json`、`transcript.md`、`subtitle.json`、`audio.m4s` 和帧图只放在共享配置的 `raw_cache`。结构化课程按真实课次聚合；独立视频、单场访谈或单集播客使用单篇笔记。

## 抖音视频

识别到 `douyin.com` 或 `v.douyin.com` 链接时调用 `douyin-study-notes`。确认来源架构后，由该 Skill 使用后台静音临时 Edge 提取公开元数据、音频和 ASR；不得控制桌面、读取用户日常浏览器配置或持久化 Cookie。原始产物只放在共享配置的 `raw_cache/douyin`，完成后回到本 Skill：独立视频通常建立一篇单篇来源笔记，同主题短链接可按已确认架构汇入持续积累笔记，再按已明确目的决定学习区内部综合或选定知识的创作沉淀，不自动跨区。

## 其他视频

使用浏览器读取页面标题、简介、可见评论和实际媒体状态。需要素材时再使用 yt-dlp；站点失败一次后切换浏览器已加载媒体兜底，不循环碰撞 Cookie 参数。短视频存在烧录字幕时，优先关键帧，再考虑 ASR。

## 播客与音频

优先节目页、RSS、官方 show notes 或现成逐字稿。没有逐字稿时提取音频并使用 faster-whisper。记录节目、嘉宾、发布日期、时长和时间轴。

## PDF与扫描件

调用已安装的 PDF Skill。优先文本层；扫描件使用 OCR。记录版本、页码基准、缺页和 OCR 质量。页码必须说明是印刷页码还是 PDF 页序。

## Word与文档

调用已安装的 Documents Skill。保留标题层级和段落结构，使用原文标题作为文章导览锚点。

## EPUB与电子书

优先提取目录、章节和正文。没有稳定页码时使用章节与小节定位，不伪造页码。

## 只有书名

只查找出版社资料、作者资料、合法试读、公开访谈和可靠评论。不得寻找盗版全文。读取不到原文时在工作更新中说明缺口，并将所有补充标为外部资料，不需要再次等待确认。
