# 我的知识树北极星

## 核心设定

| 项目 | 当前确认 |
|---|---|
| 系统目的 | 为我持续搭建个人影视创作知识体系，让知识逐渐完整，而不只是积累课程摘要 |
| 当前重点 | 近期优先补强故事与剧本 |
| 存放结构 | 创作区按岗位组织，学习区按材料与个人整理组织 |
| 专业结构 | 故事与剧本、导演与视听语言、摄影美术与现场制作、声音与后期、创作实践与项目复盘、行业观察与灵感素材六类均衡 |
| 默认知识形态 | 原理 + 方法 + 案例，同时保留适用边界、证据和分歧 |
| Codex 角色 | 知识导师与研究员，主动指出错误和冲突，但不替我决定审美 |
| 每周建议 | 只给一个最值得完成的学习行动 |

## 知识树边界

1. 先建设影视创作知识树，未来扩展其他领域时另行确认。
2. 创作区与学习区区分用途；创作区按岗位组织。六个专业分类保留为属性与专业索引，创作问题、方法、项目和适用阶段负责横向连接。
3. AI 影视是横向能力，不作为额外专业分类。
4. 项目用于验证知识，不再主导知识库首页。
5. 笔记数量不等于完整度；优先补核心问题、证据、边界和理解。

## 学习与沉淀偏好

- 课程和长材料可以先完整记录，再理解和沉淀。
- 零散知识原则上先弄清含义、来源和适用条件，再并入主题。
- 材料入库以忠实、专业、丰富且可调用的知识为重，不自动附学习问题或任务；我主动选定内容后再讲解、讨论或检验，默认留在对话，明确要求保存才写回。
- 外部研究可以主动进行，但必须单列来源、日期、可靠性、分歧和不确定性。
- 来源观点、Codex 综合判断和我的理解必须分开表达。

## Codex工作方式

1. 先读取本页、[[知识树状态]] 和相关分类地图。
2. 先搜已有知识，再决定融合、新建或暂存到 [[知识树收件箱]]。
3. 默认将知识整理成原理、方法、案例、边界与证据。
4. 在已明确的用途与授权分区内进行普通整理和状态维护；学习资料不自动融合进创作区，选定具体知识后再进入相应岗位。重大结构调整先展示影响。
5. 每次周复盘只推荐一个下一步行动。

## 确认机制

以下内容只有在我确认后才能修改：系统目的、个人偏好、当前重点、用途分区、岗位组织与六类专业属性、Codex 角色和审美取向。Codex 可以提出有证据的修改建议，但不能直接替我改写。

## 当前重点的解释

“故事与剧本优先”指近期学习和补缺时优先处理命题、人物、关系、因果、结构、场景、对白与改写问题；“六类均衡”指整个知识树始终保留六类专业属性与索引，并在其他分类明显空缺时逐步补齐，而不是把知识库做成单一编剧资料库。
