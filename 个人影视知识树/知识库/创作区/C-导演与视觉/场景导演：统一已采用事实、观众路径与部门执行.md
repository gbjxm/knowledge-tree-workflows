# 场景导演：统一已采用事实、观众路径与部门执行

## 调用入口

- 使用者：C2；协作入口：B、C1、D。
- 触发：剧本事实已经采用，但表演、美术、镜头、灯光或声音方案各自成立却无法共同工作，或关键行动、持续状态与观众接收之间出现缺口。
- 需要输入：已采用剧本段落及版本、人物知情与首尾状态、当前观看意图、可用空间/资源和未决事实。
- 本篇交付：一张包含事实、解释、意图、候选实现、必要证据和可调整项的场景判断；向各部门给同一个优先级，并列出排练/连续观看需要检验的地方。

## 内容导览

先用核心命题确定判断对象与适用条件，再用专业方法、对照表和案例形成候选。各步骤可以回返和联合迭代，不要求固定填完所有字段；最后用岗位接口与实际验证办法核对结果。技术词典和历史来源只在对应问题需要时使用。

## 核心命题

导演意图需要说明具体任务与实现依据，不能只停在“压抑、电影感、孤独”一类抽象气氛或拍摄清单。按已确认的场景任务核对：

1. 已确认的时间、地点、人物和起始状态是什么？
2. 本段要发生、持续呈现或有意悬置什么？
3. 若存在明确追求，谁向谁要什么，采取什么行动，遇到什么回应或阻力？
4. 哪些行动、关系、信息或状态改变，哪些保持或未决？没有明确变化时如实记录。
5. 场景结束时，哪些结果或状态必须让观众辨认，哪些有意保留不确定？
6. 观众被引导注意、知道或等待什么？希望形成怎样的观看经验？
7. 哪些具体表演、空间、画面、声音和时长支持这些判断？

这些问题用于判断，不要求每场填出目标、阻力和转折。目标驱动部分须保留已确认的行动因果与结果或当前未决状态；观察、等待部分可无明确前后变化，但须说明具体声画与时长依据。混合场景按实际段落判断，未实际审看时只形成方案与待验证判断。

导演负责把不同创作元素整合为一个戏剧和审美整体。具体岗位可以合并，但“统一优先级、处理冲突、复核观众实际接收”的功能不能消失。

## 适用边界

- 本主题从已经采用的剧本事实出发，不替编剧重写人物动机、事件或结局。
- 它给各部门共同的场景判断，不替表演主题决定演员的具体行动，也不替摄影和灯光主题决定参数。
- “主题、情绪、调性”须转成具体行为、空间关系、信息控制，以及声画和时长的组织方式，才具有执行意义；保持与重复也可以是明确选择。
- 安静场景既可能有细微变化，也可能通过观察、等待或持续状态承担观看作用，不要求一定出现明确的前后变化。动作幅度小不等于没有事件；没有明显事件也不自动证明场景有效。
- 场景导演卡是本知识体系的个人化综合工具，不是行业统一表格。
- 本主题先建设传统拍摄准备知识，不讨论图片或视频模型提示词。

## 知识单元

### 一、建立不可改动的场景事实层

先建立一张事实底稿：

| 事实维度 | 要回答的问题 |
|---|---|
| 时空 | 这是哪个故事日、什么地点、日夜与时空层？ |
| 前情 | 人物带着什么刚刚发生的事实进入？ |
| 人物状态 | 身体、情绪、关系、服化道和道具起始状态是什么？ |
| 可用资源 | 空间、入口出口、行动道具、光源和声音条件是什么？ |
| 禁止改动 | 哪些剧本事实、顺序、信息权限和结果不可被视觉方案改变？ |

事实层只解决“是什么”，不提前决定“怎样拍”。如果上游事实仍互相矛盾，应返回剧本处理，而不是用表演或镜头掩盖。

### 二、按场景任务使用行动链或检查持续状态

目标驱动段落可用下面的工作链核对实际行动；它不是每项必填或必须依次发生的公式。观察、等待或持续状态的段落可以没有明确前后变化，应说明观察对象、持续方式及观看作用。同一场可以按段使用，不必给整场硬定一种类型。

```text
人物带着某种状态进入
→ 想从对象那里获得具体结果
→ 采取行动并获得回应或造成结果
→ 核对实际阻力、新刺激及是否发生策略、认知或关系变化
→ 记录实际结果或当前未决状态
```

目标驱动段落的检查重点：

- 目标必须指向对象并能在本场被追求，不是“想要幸福”。
- 阻力若是本段因果的一部分，应指出它怎样限制或影响行动，不能只有心理形容词；不能为填满链条另造阻力。
- 节拍不是按台词段落机械切分，而是行动、权力、信息或情绪方向发生变化的关节。
- 转折不一定等于剧情反转；一次没有说出口却被对方领会的反应，也可能改变关系。

已采用的行动、因果与结果必须保护；若结果确实未决，应说明当前行动推进了什么、悬置了什么，不擅自补出成功、失败或转念。观察与等待也须说明具体行为、声画和持续时间的作用，不能只写气氛形容词。实际效果须结合连续声画判断。

### 三、建立观众体验曲线

按实际段落或节拍记录五项，下列阶段仅为可选分析位置，不要求凑齐。等待或观察可以没有明确前后变化，但须说明具体声画和时长怎样支持观看；目标驱动部分仍要保护已确认因果与结果，未决内容按事实记录。表中是预期接收条件，实际效果须观看验证。

| 段落或节拍 | 角色在做什么 | 观众知道什么 | 观众站在哪里 | 期待或压力怎样变化或保持 |
|---|---|---|---|---|
| 基准 | 人物、空间与当前状态可被定位 | 当前任务所需的时空、关系或观察线索 | 客观、贴近某角色或被刻意隔开 | 建立注意、等待或观察对象 |
| 保持或推进 | 行动与回应发生，或持续某种行为、状态 | 新信息出现、被隐瞒，或保持已有信息 | 依附可能保持或转移 | 压力增加、方向改变，或体验持续时间 |
| 关节（如有） | 已发生的刺激、回应或决定被呈现 | 观众先知、同知或后知 | 视点支持当前信息任务 | 预期被确认、打破或悬置 |
| 收束或延续 | 实际结果落地，或未决、等待、观察继续 | 结果或持续状态有可辨依据 | 形成余味或下一场问题 | 压力释放、转移或继续，不强造峰值 |

“观众体验”不是替观众规定唯一情绪，而是设计信息和注意条件，让合理的感受有机会发生。

### 四、为关键行动、变化或持续状态选择证据

围绕本场任务选择必要的证据载体，可以先比较一到两类，不要求全部堆上。按已确认的信息时序，为需要观众辨认的行动因果和结果提供依据，不提前揭示有意隐瞒或未决的内容；持续状态则要说明看什么、听什么、保持多久及其作用，不要求为此制造变化：

- 表演证据：行动改变或保持、聆听、延迟、回避、抢话、身体重量、与对象的距离。
- 空间证据：进入/退出、靠近/远离、停留、占据高位、被遮挡、越过边界、失去退路。
- 道具证据：持有、拿起、交出、隐藏、破坏、拒绝使用或改变归属。
- 画面证据：视点、景别、构图重心、遮挡或焦点的保持与变化，以及镜头持续时间。
- 灯光与色彩证据：稳定的可见度与时空条件、人物进入不同光区、信息被隐藏或显露。
- 声音证据：静默、持续或变化的环境声、画外信息、声音提前或延后对注意与预期的作用。

如果只能用“他很难过”“画面很高级”说明场景意图，没有具体声画和时长依据，导演解释尚未落地。证据被安排出来也不等于观众已经获得预期体验。

### 五、形成跨部门共同优先级

导演不应给每个部门一串互不相干的形容词，而应发出同一任务的专业化版本：

| 专业 | 需要收到的判断 | 常见误用或不充分替代 |
|---|---|---|
| 表演 | 按本段任务提供实际目标、对象、阻力、刺激与回应，或需要保留的聆听、等待和持续行为 | 固定微表情清单 |
| 生产设计 | 世界规则、空间功能、人物生活痕迹、关键道具，以及需保持或改变的状态 | 具体机位和曝光 |
| 摄影 | 观众视点、信息尺度、空间关系、需要保护的表演时刻 | 只凭风格指定器材品牌 |
| 灯光 | 时空、可见度、人物与背景关系、光线保持或变化的叙事理由 | 无视安全和场地条件的灯具做法 |
| 调度与覆盖 | 人物为何移动或停留、需要保护的关系与状态、必要反应和持续时间、可剪接口 | 按每句台词平均切镜 |
| 场记 | 开始/结束状态、不可改事实、必须保护的连续性和欠拍条件 | 把场记当被动抄表人员 |

部门方案冲突时，先确认安全、同意与实际可执行条件，再比较各方案怎样保护场景意图、证据与表演，说明必要取舍。导演负责创作整合，不因此替代各部门的技术职责，也不能把纸面意图当作对实际效果的证明。

### 六、场景导演卡

仍使用同一张卡，按已确认任务填写；允许状态保持、结果未决，或注明某字段不适用及原因。目标驱动段落保留已确认因果与结果；观察、等待段落可无明确前后变化，但须填写具体行为、声画和时长依据。混合场景在相应字段内按段说明，不为填表补造事实。表格齐全不等于实际观看效果通过。

| 字段 | 内容要求 |
|---|---|
| 场景身份 | 场号、剧本版本、故事日、地点、内外、日夜 |
| 一句话事件／观看任务 | 实际行动及其结果或未决状态，或观察、等待、持续什么及其作用 |
| 开始/结束状态 | 人物、关系、信息、空间和关键物件的可比较状态；允许相同，不虚构变化 |
| 行动与节拍 | 按段记录实际目标、对象、阻力、策略、刺激、回应、因果和结果；持续段落说明行为及其组织方式 |
| 观众路径 | 依附对象、已知/未知、期待、误导、揭示和余味 |
| 核心表演时刻 | 哪一次或哪一段聆听、领会、压制、泄露、决定或持续行为不可丢失 |
| 核心视觉时刻 | 哪个空间关系、动作、道具、构图或持续时间不可丢失；需要保持什么、改变什么 |
| 部门共同规则 | 表演、美术、摄影、灯光、调度、场记共同遵守的3—5项 |
| 可调整项 | 可替换的动作、位置、镜头或装饰选择 |
| 不可妥协项 | 一旦丢失就会改变戏剧事实或观众体验的内容 |
| 验收 | 按已确认信息时序，连续观看时所需因果、结果或持续状态是否可辨，是否支持预期观看作用；未实际审看时保留待验证 |

### 七、用排练和预演反向修正方案

推荐最小循环：

1. 桌面分析：确认已采用事实、行动或持续状态、信息和观看任务，不先锁镜头。
2. 空间走戏：让人物在真实或示意空间里尝试相关行动、停留与持续方式，不为走戏强加移动。
3. 观察实际行为：记录聆听、回应、距离、道具交互或持续时间怎样支持任务，区分已发生的变化与保持。
4. 摄影与灯光验证：检查机位、焦点、光区和覆盖能否保护关键因果、结果或持续状态及所需时间。
5. 最小调整：为便于比较，尽量围绕一个主要问题调整；机位、灯光与表演相互依赖时可以联合修改，但记录改变了哪些条件，避免无法解释效果。
6. 观众复核：从连续观看结果判断是否成立，而不是看表格是否填满。

场景方案不是在排练前永久锁死的指令；排练发现更可信的行动或持续方式时，导演应保留已采用事实、因果结果与本场任务，允许实现方式改变。

### 八、常见失败

1. 把剧情摘要当导演意图，没有说清实际行动或持续状态及其观看作用。
2. 先列景别和运镜，再倒推这一场为什么存在。
3. 只写气氛形容词，没有具体声画、时长依据和优先级。
4. 每句台词都有镜头，却漏掉本段需要保护的聆听、回应、关系证据或持续时间。
5. 表演、美术、摄影和灯光分别引用不同参考，世界和情绪互相打架。
6. 节拍强度与持续时间不支持场景任务；或只为凑齐升级、转折和兑现，破坏有意的等待与重复。
7. 用漂亮构图或持续气氛替代本段必须呈现的行动因果、结果，或丢失必须保留的状态证据。
8. 排练只检查台词是否说对，不核对实际行动、回应或持续行为怎样支持任务。
9. 为了保住既定镜头强迫人物做无动机移动。
10. 方案无法说明哪些可调整、哪些一旦改变就需要返回剧本或总控。

### 九、把事实、解释、意图和方案分开

`[本体系综合]` 同一张导演卡至少区分四种信息：剧本明确事实；导演当前解释；想让观众形成的体验；实现它的候选方法。比如“人物背向门站着”可为事实，“他怕被看穿”可能只是解释，“观众比对方更早发现他在隐瞒”是意图，“拍镜中倒影”才是方案。不能因为方案便利，就把镜子、人物心理和知情状态自动写成已确认事实。

导演可以向摄影提出需要读到的细节，与演员讨论行动，与美术讨论空间，但部门输出仍须共同测试。这里的“不替代专业”指责任与知识边界，不是禁止导演讨论焦距、布景或声音。实际决策权依项目分工，不能从个人知识卡推导全球统一权限。

### 十、部门冲突如何比较

| 比较项 | 需要说清的内容 | 决定的依据 |
|---|---|---|
| 意图 | 观众此时必须知道、误解或等待什么 | 已采用故事和本场目的 |
| 必需证据 | 哪次动作、话语、声音或关系使判断成立 | 实际可见可听，不靠作者解释 |
| 表演条件 | 改动是否影响对手关系、注意与行为可信度 | 排练与演员反馈 |
| 技术/空间条件 | 机位、光区、遮挡、声源、布景能否共同实现 | 对应部门判断和测试 |
| 替代与代价 | 保留什么，舍弃什么；哪些后续需要一起调整 | 条件对比与可用资源 |

如果各方案都符合约束，可以保留候选作比较；表格不产生唯一正确答案。若没有办法同时满足关键故事事实与制作条件，带具体矛盾回故事或制片讨论，不让某部门在执行中偷偷改掉。

### 十一、一个贯穿例子：背身是否丢失隐瞒

`[构造教学例子；未用于真实拍摄]` 已确认甲必须掩饰手上的墨迹，观众应比乙更早知道。演员发现背身更有行动理由，但摄影机因而看不到手。问题不是“演员是否听话”，而是哪种呈现能同时保留行动与信息。

可以比较摄影机侧移、调整两人的相对位置、保留已存在的手部可见时刻或重排已确认的信息时序。每一项都可能影响轴线、光区、表演和观众知情；没有空间与剧本前后文，不能擅自指定倒影、插入或新对白。如果手部证据本就不需要此刻出现，也应先确认意图，而非保住原镜头。

变体：导演希望观众直到乙发现时才知道墨迹。此时背身可能支持隐瞒，原本要补的手部特写反而会破坏目标。相同动作是否有效由信息任务决定，不能从“看不见脸/手”直接判表演或摄影失败。

### 十二、观众体验怎样被验证

分开检查：观众能否定位事实，是否读到关系或选择，是否形成预期中的等待和情绪。看懂情节不保证情绪成立；没有明确转折的观察段，也可通过声音、持续时间、重复和细微差异构成体验。不要为了填卡强加动作或情绪峰值。

让未获解释的观看者先自由复述看到了什么、何时知道什么，再询问具体位置；问题本身不应泄露答案。保留理解不同的反馈，比较是否因信息缺失、执行、剪接或目标本身不一致。少数观看者的反应只能作为线索，不能宣称所有观众必然如此。未提供媒体时，只能形成假设和检查方法。

## AI制作转译与证据边界

本篇保留传统影视原理，但数字生成不自动继承摄影机、光源、演员或现场设备的物理可控性。先把专业判断转成可见/可听的结果、空间与状态约束，再由当前实际工具和真实输出检验；机型名、焦距、光圈、色温或表演动词只是输入描述时，不声称已经执行相应物理操作。

一次生成失败先定位实际差异和可能层次，不直接定责或改写故事。主要任务可以伴随其他动作或持续行为；是否需要拆分取决于具体模型、输入和实际结果，不设置固定的一动作上限。单一比较目标允许联动修改互相依赖的条件，但必须写清改变与保留项，避免把随机样本差异当成因果收益。

本轮建立专业判断和检查办法，没有生成、排练、真实剪辑、连续声画审看或观众试验；任何“可读、连续、可用、可复现”均需绑定实际结果和验证范围。
