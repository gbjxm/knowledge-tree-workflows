# C视觉拍摄知识建设｜04 场记连续性与现场拍摄流程专业资料汇编

## 材料简介

本资料汇编研究专业拍摄怎样在非故事顺序、多个镜头、多个take和跨日制作中保持剧本、表演、画面、资产与进度可追溯。它把场记从“查穿帮”还原为导演—现场—剪辑之间的信息接口，并把技术勘景、走戏、灯光、摄影排练、正式拍摄、回看、数据交接和日终复盘组织成可压缩但不可失忆的现场循环。

- 资料架构：同一专业问题、多类独立来源、单篇汇编。
- 检索与复核日期：2026-08-10。
- 第一轮：审计现有连续性知识，确认轴线、动作、视线和镜头衔接较成熟，实际take、剧本修改、服化道与日报记录为空白。
- 第二轮：检索ScreenSkills场记、1st/2nd AD、DIT资料，IATSE Local 871岗位说明，DGA技术勘景与每日样片原则，以及制作流程教学资料。
- 当前范围：场景连续性底稿、逐镜/take记录、coverage owed、技术勘景、场景执行循环、当日计划、日终交接和素材/记录完整性。
- 暂不展开：大型剧组完整通告、劳动排班、工会合同、危险动作、亲密协调、数据加密和现场网络工程。
- 学习状态：已完成来源沉淀；尚未进行用户理解检验和真实项目验证。

## 整体结构

```text
已采用剧本与版本
→ 场景连续性底稿
→ 技术勘景与联合平面图
→ 当日目标、拍摄顺序和setup条件
→ Blocking
→ 初步机位与灯光
→ 摄影排练与最终修正
→ 正式take及逐镜记录
→ 回看、可用性与coverage owed判断
→ 素材和记录交接
→ 日终复盘与次日调整
```

拍摄常因场地、演员、设备和效率按非故事顺序执行，因此story day、人物/资产状态和剧本版本是现场不可缺的共同坐标。

## 分章节／分集导览

### 1｜场记与制作连续性

#### 整体脉络

- `底稿`｜在开拍前记录故事日、人物、服化道、道具、空间、光线和不可改事实。
- `take`｜现场记录每次实际发生的表演、摄影、灯光、声音、问题和采用状态。
- `日终`｜把已拍、欠拍、可用take、变化和次日条件交给导演与后期。

#### 详细导览

##### 从计划连续到实际连续

主要讲什么：镜头方案描述计划，场记记录实际take与计划的差异；只有后者能支持补拍和剪辑。  

关键内容：

- 剧本版本、场号、镜号、take和story day是最小身份链。
- 人物、服化道、道具、灯光和摄影状态需以照片/文字/参数共同记录。
- 情绪连续性记录刺激、领会、行动和反应阶段，不用情绪分数替代。

复盘提示：如果三天后补拍，能否准确恢复开拍前一秒和结束后一秒的状态。

### 2｜技术勘景与场景循环

#### 整体脉络

- `技术勘景`｜把演员、摄影机、光线、美术、声音、安全和备用方案放进同一空间。
- `执行循环`｜走戏后再完成机位与灯光，摄影排练暴露问题，修正后正式拍摄。

#### 详细导览

##### Blocking—Light—Rehearse—Shoot

主要讲什么：这是一条可压缩的最小循环，不是不可更改仪式；它避免在人物行动未知时锁死摄影灯光，也避免把正式take当第一次测试。  

关键内容：

- Blocking确认动作、位置、时序和互动。
- 摄影与灯光据此建立安全、可执行的机位与光线。
- 摄影排练在服化、道具、摄影和灯光条件下运行，再做最终修正。

复盘提示：当前正式take之前，人物、摄影、灯光和道具是否至少共同运行过一次。

### 3｜日终交接与反馈

#### 整体脉络

- `素材身份`｜媒体文件和现场记录绑定场景、镜头、take与版本。
- `回看`｜判断拍到了什么、哪些take可用、哪些覆盖仍欠，不把“拍过”写成“通过”。
- `调整`｜把今天事实转成明日计划和补拍条件。

#### 详细导览

##### 日终五问

主要讲什么：每天只用事实回答完成、欠拍、可用、连续性和明日调整。  

关键内容：

- 记录采用候选的原因与已知问题。
- coverage owed与技术/表演缺口分开。
- 素材备份、记录和后期交接必须对应同一身份。

复盘提示：D能否仅凭素材和场记日志知道每个take是什么、为何候选、还缺什么。

## 独立来源提炼

### 场记岗位的核心功能

- 确认剧本被正确执行并获得足够覆盖。
- 维护视觉、情绪、物理、对白、动作、服化道和道具连续性。
- 记录镜头/take、摄影与灯光条件、实际时长、进度和欠拍。
- 向导演、制片和剪辑交付marked-up script、facing pages、编辑日志、连续性照片和当日报告等信息。

### AD与技术勘景的核心功能

- 从剧本识别部门、演员、特殊设备、场地、天气、许可、安全与应变条件。
- 在确定场地上让各部门共同确认机位、灯光、设备、路径和拍摄方向。
- 按场地、演员、设备和转换成本建立可实现的拍摄顺序，并及时传播变化。

### 数据与每日样片的核心功能

- 摄影和录音介质需要被接收、备份、检查并与现场记录绑定后交给后期。
- 导演通过rushes/dailies检查屏幕结果，使次日补拍或调整基于真实画面，而不是现场印象。

## 多源综合方法

### 三件套场记产物

1. 场景连续性底稿：故事日、人物状态、服化道、道具、空间、光线和不可改事实。
2. 逐镜/take记录：每次实际拍摄的表演、摄影、灯光、声音、问题与采用状态。
3. 日终场记交接：已拍、欠拍、可用take、变化、次日补拍条件及编辑日志。

### 联合技术勘景图

至少叠加：演员路径和停点、摄影机位/运动/轴线、光源和过灯区、道具/布景/可移动障碍、现场声音风险、供电/吊挂/出入口/安全及备用方案。

### 日终五问

1. 今天真正拍成了什么？
2. 哪些镜头、状态或覆盖仍欠？
3. 哪些take可用，为什么可用，有什么已知问题？
4. 哪些连续性和技术条件必须带到下一日？
5. 明日顺序、资产、表演或技术计划需要怎样调整？

## 复习区

### 一分钟核心摘要

场记维护剧本、人物、资产、摄影和灯光的真实状态，并把每个take与场景、镜头和版本绑定。现场先经技术勘景，再按走戏—机位灯光—摄影排练—修正—正式拍摄循环执行；日终只根据真实素材和记录判断完成、欠拍、可用与次日调整。
