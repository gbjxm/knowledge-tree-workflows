# 前期色彩：区分资产本色、光源与最终Look

## 调用入口

- 使用者：C1；协作入口：C2、D。
- 触发：色卡、服装、场景、光线和最终画面互相冲突，或同一资产换光、换反打后颜色改变，尚不清楚哪一层应调整。
- 需要输入：颜色的叙事/注意任务、资产身份与材质、场景面积关系、光源、摄影/监看条件、剧情变化与已采用参考。
- 本篇交付：六层颜色与责任表、面积/明度/饱和度结构、色彩脚本、固定/允许变化/首次出现/继承规则、受控比较和测试参考。

## 内容导览

先用核心命题确定判断对象与适用条件，再用专业方法、对照表和案例形成候选。各步骤可以回返和联合迭代，不要求固定填完所有字段；最后用岗位接口与实际验证办法核对结果。技术词典和历史来源只在对应问题需要时使用。

## 核心命题

影视颜色至少包含六层：

| 层次 | 回答的问题 |
|---|---|
| 资产本色 | 物体在中性、可比较条件下原本是什么颜色？ |
| 材质响应 | 粗糙、镜面、透明、半透明、吸光和高光怎样改变颜色可见方式？ |
| 环境综合色 | 场景、服装、道具和背景的面积、明度、饱和度与冷暖关系怎样组织？ |
| 光源颜色 | 自然光、实际灯和人工灯给对象加入什么综合色与变化？ |
| 摄影结果 | 白平衡、曝光、镜头、传感器、滤镜、记录和监看怎样改变显示？ |
| 最终Look | 后期在正确素材和意图基础上怎样统一、强化或有意偏离？ |

把六层混成一个颜色描述，会让资产、灯光和后期都以为对方会解决问题。专业配色应保留每层责任和测试结果。

## 适用边界

- 色彩没有脱离对象、面积、明度、饱和度、文化、剧情和上下镜的固定情绪意义。
- 十六进制、RGB或色名只能描述某个显示/编码条件中的候选值，不能完整代表实体材质、光谱、反射和摄影结果。
- 生产设计负责资产与场景的颜色关系；灯光负责光源综合色和受光层次；摄影负责记录与监看；后期负责基于正确版本完成Look。角色可以合并，责任不能混失。
- 资产本色连续不意味着每镜显示色必须相同；人物进入不同光源或剧情状态时，变化可以成立，但要有来源和继承规则。
- 具体色域、显示标准、色彩管理和交付参数属于技术管线知识，本主题只保留前期设计与交接接口。
- 本主题先建设传统影视色彩知识，不把模型提示词当作色彩设计本身。

## 知识单元

### 一、先写颜色要完成的任务

每个场景或段落先回答：

- 颜色要区分哪些人物、阵营、时空或心理阶段？
- 谁需要从背景中分离，谁需要融入环境？
- 哪个物件或信息需要成为点色？
- 颜色应建立稳定基准、逐步衰减、突然反转还是在结尾回归？
- 哪些颜色来自世界事实，哪些是有意风格化？
- 哪些文化或类型联想可能影响理解，是否需要通过上下文校准？

“红色代表危险、蓝色代表悲伤”只能作为待验证联想，不能成为脱离对象与剧情的规则。

### 二、用六项关系设计配色

| 变量 | 检查问题 |
|---|---|
| 面积 | 主色、辅助色、点色各占多少；点色会不会反客为主？ |
| 明度 | 转成灰度后，主体与背景是否仍有层级？ |
| 饱和度 | 哪些区域最纯、哪些被压低；高饱和是否抢走表演？ |
| 冷暖 | 用于空间、光源、时间或关系区分，还是只做表面撞色？ |
| 对比/亲和 | 需要冲突、分离、统一还是逐渐融合？ |
| 重复与变化 | 颜色何时出现、由谁携带、怎样积累和在哪个节点改变？ |

颜色结构应服务全片视觉强度曲线，而不是每场都追求最丰富、最强烈。

### 三、把资产本色与材质响应分开

关键资产记录：

- 中性条件下的基底颜色和允许误差；
- 表面粗糙、镜面、透明、半透明、金属、织物或吸光特征；
- 新旧、磨损、污渍、湿润、灰尘和褪色怎样改变颜色；
- 不同观看角度和高光是否使颜色偏移或消失；
- 与肤色、背景和关键道具同框时的关系；
- 不能共存的材料/颜色组合。

例如“深红皮革”还不足够；要说明它在中性光下的红、表面反射、磨损处露出的底色、暗部是否仍有综合色以及与背景的分离方式。

### 四、环境综合色需要跨资产统筹

场景不是单个色卡的相加。检查：

- 墙面、地面、家具、服装、妆发、肤色和道具的面积关系；
- 实际灯、窗光、天空、植物和反射面带来的综合色；
- 前景、中景、背景是否形成清楚层级；
- 高频复杂纹样、高饱和点色和亮面材质是否同时抢注意；
- 一个资产离开原参考背景后是否仍成立。

生产设计应提供关系规则，而不是要求摄影和灯光逐件“还原标准色”。

### 五、建立场景色彩脚本

| 场景/段落 | 人物或关系状态 | 主导色与面积 | 明度/饱和度 | 点色及承担者 | 光源综合色 | 变化与下场继承 |
|---|---|---|---|---|---|---|
| 基准 | 世界和关系初始状态 | 建立主色体系 | 建立正常强度 | 只保留必要重点 | 确立时空来源 | 作为后续比较基准 |
| 推进 | 冲突、靠近或疏离 | 颜色合并或分离 | 逐步增强/衰减 | 点色转移或被夺走 | 光源变化有动机 | 标记状态首次改变 |
| 转折 | 关系或认知改变 | 规则被打破 | 明度/饱和度突变或反转 | 新重点出现 | 光源/曝光共同验证 | 记录是否可逆 |
| 结果 | 新状态稳定 | 建立新基准或回归 | 留下余味 | 点色完成使命 | 与下一场时空衔接 | 后续场景继承 |

色彩脚本不是要求每场不同，而是让变化发生在可感知的稳定基准上。

### 六、光源颜色不是资产颜色的覆盖层

记录：

- 光源的可见/推断来源、色温或综合色；
- 同一资产在主光、暗侧、轮廓和背景反射中的不同表现；
- 混合光下哪一种来源占主导，人物移动时综合色怎样变化；
- 白平衡选择是中和某个来源还是保留相对差异；
- 是否存在LED、荧光、显示屏或特殊材料导致的肤色/物体偏差；
- 光源变化是剧情事件、时间变化还是技术不连续。

颜色关系必须和灯光方案及摄影测试一起确认，不能只在平面色卡中判断。

### 七、摄影与监看决定“我们现在看到的是什么”

最小记录：摄影机/记录路径、白平衡、EI/ISO、曝光参考、镜头/滤镜、监看Look、显示条件以及中性灰卡/色卡参考是否存在。

- 监视器上的颜色可能已经经过Look，不等同原始或Log记录。
- 有意偏色、欠曝或特殊光应同时保存中性参考或清楚说明，防止后期误中和。
- 同一场景跨日或补拍时，应重现光源、材质、曝光和监看条件，而不是只对照十六进制值。
- 后期可以统一和强化关系，不能凭空恢复前期从未记录到的材质层次和高光/暗部信息。

### 八、色彩连续性允许有规则的变化

色彩连续性最小表：

| 对象 | 固定项 | 可变项 | 变化原因 | 首次出现 | 后续继承 | 测试参考 |
|---|---|---|---|---|---|---|
| 角色 | 基础肤色、眼发、核心服装身份 | 疲劳、伤势、湿度、污损、阶段服装 | 剧情/时间 | 场景或镜头 | 下一状态 | 定妆与光照测试 |
| 场景 | 基础墙地、主要材质和实际灯 | 日夜、天气、事件损坏、临时陈设 | 时空/事件 | 场景 | 恢复或保留 | 场景参考静帧 |
| 道具 | 基底颜色、材料、归属 | 磨损、污渍、损坏、光源响应 | 使用/事件 | 镜头 | 后续归属 | 中性与实景测试 |
| 全片Look | 颜色结构与显示意图 | 分场强度和转折 | 叙事结构 | 段落 | 新基准 | 采用参考与版本 |

资产在暖光下变暖不一定是穿帮；如果光源、人物路径和前后镜一致，它是合理变化。无来源的色相跳变才是连续性问题。

### 九、色彩方案卡

| 模块 | 最小内容 |
|---|---|
| 叙事命题 | 颜色要区分、连接、隐藏或改变什么 |
| 结构 | 主色、辅助色、点色、面积、明度、饱和度、冷暖与对比 |
| 六层 | 资产本色、材质、环境、光源、摄影、最终Look分别记录 |
| 人物/场景曲线 | 每个阶段的基准、变化、转折和继承 |
| 禁用项 | 会破坏世界、肤色、层级或连续性的组合 |
| 测试 | 材质、肤色、服装、场景、光源、曝光、镜头和显示结果 |
| 参考 | 中性参考、采用Look、版本、日期与观看条件 |
| 连续性 | 固定、可变、原因、首次出现、后续状态和允许误差 |
| 责任接口 | 生产设计、服化道、灯光、摄影、场记和后期分别负责什么 |

### 十、常见失败

1. 色卡只有颜色名称和数值，没有对象、面积和叙事任务。
2. 把资产本色直接当最终镜头色。
3. 角色、场景、服装和道具分别配色，合在一起失去主次。
4. 固定使用“红危险、蓝悲伤”等跨文化情绪公式。
5. 每场都追求高饱和与强撞色，导致没有视觉基准和升级空间。
6. 点色面积过大或重复过多，失去强调作用。
7. 忽略灰度明度关系，颜色不同但主体仍和背景粘连。
8. 忽略材质和光源，同一色值在镜头里完全不同。
9. 监看套Look却没有保存记录路径和中性参考。
10. 把合理的受光变化误判为资产不连续，或把无来源色跳当作风格。
11. 期待后期恢复未记录的高光、暗部和材质细节。
12. 没有版本和采用状态，不同部门使用不同色卡。

## 颜色偏差如何定位到正确层次

以下“隔离比较—归因—改动”方法为本体系综合；光谱问题参照[美国电影艺术与科学学院SSI说明](https://www.oscars.org/science-technology/projects/spectral-similarity-index-ssi)。

### 相同色温为什么仍可能拍出不同布料颜色

**Spectral Power Distribution（光谱功率分布，SPD：光源能量随波长的分布）**不由一个色温数字完整描述。**Correlated Color Temperature（相关色温，CCT）**只压缩了白点附近的一部分颜色信息；相同CCT的光也可能有不同偏绿/偏品红与光谱分布。

对不发荧光的近似漫反射表面，摄影机某通道响应可以用“光谱照明×材质光谱反射×该通道光谱敏感度”的波长积分理解，再进入曝光、编码和显示处理。这是简化模型，不包括所有镜面、透射和多次反射现象。它解释为何两盏标称5600K的LED使灰卡接近中性，却让同一织物明显不同；灰卡通过不代表所有材质都通过。

**Metamerism（同色异谱现象：某一观察条件下颜色相配、换条件后不再相配）**提醒我们，不能只靠屏幕RGB或肉眼在另一种灯下的判断选布料。改变白平衡可能移动车内全部颜色，未必同时修正衣服和肤色。

### SSI的分数说明什么、不说明什么

**Spectral Similarity Index（光谱相似指数，SSI）**比较待测光谱与指定参考光谱的相似程度；写分数时必须写参考。它不是某一摄影机、某块布料或某种肤色的完整“正确率”。CRI、TLCI、SSI采用不同评价模型，不能把三个数字当同一分数互换，也不必追求所有叙事光都接近标准白光。

专业判断应是：这盏光在当前摄影机与关键材质组合下，是否产生所需且可重复的关系？色卡有助观察有限样本，不是替整个场景出具保证。

### 先区分实物变化、照明变化和观看变化

| 比较对象 | 需要尽量固定 | 差异提示 |
|---|---|---|
| 两件服装/道具 | 同光源、位置角度、曝光、摄影与显示 | 实物材料、染色、表面状态可能不同 |
| 同物换灯 | 机位、材质位置、记录与监看；交代是否重新平衡白点 | 光谱、入射角、亮度与周边反射共同影响 |
| 同文件换监看 | 文件版本、输入解释、Look、输出变换与显示条件 | 若像素未变而观感变，不能先归因资产 |
| 同物跨镜 | 已采用时空、路径、状态和画面上下文 | RGB不同可能合理，关系失读才需进一步判断 |

变量不能全部同时固定时，明确混杂条件而不是给单一原因下结论。中性参考应说明拍在什么光下、有无Look；不要为拍一张“标准灰卡”偷偷改场景照明却不记录。不同软件和屏幕的取样值还要注明色彩空间/变换，不能直接拿一个HEX要求调色逐镜对齐。

### 一个红外套的连续性判断

教学构造：人物从暖灯走廊进入冷色门厅，红衣变暗偏紫。先确认是同一件衣服与同一剧情状态，检查变化是否随进入光区连续发生，脸和墙面是否也按光源逻辑改变。若换反打后只有外套突然跳色，优先检查备用衣料、受光角、反射或记录/Look差异，而不是直接给服装换色。

关键意图若是让观众一直认出外套，可以比较改变照明组合、选择测试更稳的材料、调整背景分离或在后期做有限统一。每种方案都保护身份与叙事，不要求红衣每帧同一RGB。验证记录要同时保存中性条件和实际戏光结果；只看美术色卡不足以宣布连续。

## AI制作转译与证据边界

本篇保留传统影视原理，但数字生成不自动继承摄影机、光源、演员或现场设备的物理可控性。先把专业判断转成可见/可听的结果、空间与状态约束，再由当前实际工具和真实输出检验；机型名、焦距、光圈、色温或表演动词只是输入描述时，不声称已经执行相应物理操作。
