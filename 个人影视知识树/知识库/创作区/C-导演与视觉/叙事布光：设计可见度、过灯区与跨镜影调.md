# 叙事布光：设计可见度、过灯区与跨镜影调

## 调用入口

- 使用者：C2；协作入口：C1、D。
- 触发：光线标签缺少时空来源，人物一走动可见度失控，全景/近景/反打像换了光源，或光质、光量和颜色问题被混为一谈。
- 需要输入：已采用的观看任务、时空、人物路径、空间/材质/实际灯、记录与监看条件、可用资源和安全条件。
- 本篇交付：动机源与允许偏离、七个光线变量、明暗/影调功能、人物过灯区、摄影接口、跨镜继承及未验证的风险备选。

## 内容导览

先用核心命题确定判断对象与适用条件，再用专业方法、对照表和案例形成候选。各步骤可以回返和联合迭代，不要求固定填完所有字段；最后用岗位接口与实际验证办法核对结果。技术词典和历史来源只在对应问题需要时使用。

## 核心命题

灯光不是把主体照亮，而是控制：

1. 光从哪里来以及观众是否相信；
2. 哪些信息公开、隐藏或逐步显现；
3. 人物面部、身体、材质和空间怎样获得体积；
4. 主体与背景怎样分离或融合；
5. 人物移动时光线怎样变化；
6. 全景、近景、反打和跨拍摄日怎样共享同一时空逻辑；
7. 摄影记录和后期怎样识别原本的曝光与色彩意图。

“动机”不是必须看见一盏灯，也不是绝对写实。自然主义可以遵循场景内合理光源，绘画主义也可以有意偏离现实；关键是偏离必须服务明确的心理、形式或叙事目的，并在整场保持规则。

## 适用边界

- 本主题设计光线结果和跨部门接口，不替摄影主题决定完整记录系统，也不替生产设计决定场景和实际灯的造型。
- 主光、填充、轮廓、背景光是功能名称，不要求每场都按固定数量和位置摆灯。
- 光比、色温、False Color和波形值必须结合具体摄影机、记录曲线、监看Look和测试，不能照搬厂商示例阈值。
- 近景可以为面部和眼神做技术微调，但必须保持全景建立的光源方向、时空、反差和综合色逻辑。
- 本主题不提供高压配电、吊挂、升降平台、明火、烟雾、发电机或危险灯具的DIY操作。现场法规、风险评估和合格专业人员优先于画面目标。
- 本主题先建设传统拍摄灯光知识，不讨论生成模型参数。

## 知识单元

### 一、先确定光线要完成的叙事任务

每场先回答：

- 时间、季节、天气和空间是什么？
- 谁需要被看见，谁需要保留未知？
- 人物与背景要分离、融合还是彼此吞没？
- 面部要公开、分裂、成为轮廓还是逐步显现？
- 哪个材质、道具、入口或空间层必须被光揭示？
- 光线是否需要随人物行动、剧情信息或时间发生变化？
- 这一段相对前后场景的影调和色彩基准是什么？

若只能说“好看”，仍需说明该形式选择的观看作用与可验证条件；不要求每一束光都传递剧情新信息。

### 二、建立动机光源表

| 光源 | 场景内是否可见 | 推断位置与方向 | 色温/颜色 | 时间变化 | 实际塑形方法 | 允许偏离及理由 |
|---|---|---|---|---|---|---|
| 窗外天光 | 可见窗口/可推断 | 方位、高度、朝向 | 随时间和天气 | 稳定、变化或被遮挡 | 画外加强、柔化、遮切或反射 | 为保护表演适度延伸方向 |
| 实际灯 | 画面可见 | 灯具位置 | 灯泡/LED综合色 | 开关、闪烁、调光 | 可由隐藏光源补足 | 不制造第二套无来由阴影 |
| 画外环境光 | 不可见但可推断 | 走廊、街灯、月光等 | 与环境一致或有意对比 | 按剧情变化 | 主光、背景或轮廓功能 | 必须说明观众为何接受 |

实际灯出现在画面里不等于它真的能完成曝光与塑形；画外灯可以加强它，但方向、综合色和变化应保持可信。

### 三、用七个变量描述一束光

1. **方向**：水平角度和垂直高度决定阴影落向、面部结构与空间来源。
2. **相对大小**：相对主体越大，阴影边界通常越软；不是灯越亮就越硬。
3. **距离**：改变强度、相对大小、覆盖范围和人物移动时的亮度变化。
4. **强度**：决定曝光、层次和与其他光源的关系，不单独决定光质。
5. **颜色**：色温、综合色与光谱表现会影响肤色、服装、墙面和材质。
6. **形状与控制**：旗板、遮切、柔光、反射、网纱等决定光落在哪里、不落在哪里。
7. **时间行为**：稳定、渐变、闪烁、移动、被人物或物体遮挡，均可能参与叙事。

“柔和侧光”至少还要补：来源、方向与高度、相对大小/距离、暗侧保留、背景控制和人物移动后的变化。

### 四、按功能组织灯光，不按固定配方摆灯

| 功能 | 主要问题 | 可能做法 |
|---|---|---|
| 主体塑形 | 主要光向和脸部/身体体积从哪里建立 | 主光、窗光、实际灯方向、反射或环境光 |
| 暗侧控制 | 阴影保留多少信息和颜色 | 填充、反射、环境光或负补光 |
| 主体分离 | 人物如何从背景中跳出或融入 | 背景明度、轮廓、色彩、烟雾、材质反射 |
| 空间层次 | 前中后景怎样获得深度与注意顺序 | 分区亮度、光束、遮挡、背景光和实际灯 |
| 眼神与面部 | 眼睛、鼻颧、下巴和轮廓保留什么 | 微调光位、柔化、补光或遮切 |
| 叙事变化 | 光线怎样随人物、时间或事件变化 | 调光cue、实际灯开关、遮挡、过灯区或综合色变化 |

负补光属于减法控制：通过减少进入暗侧的环境填充建立反差，而不是简单“放黑布变电影感”。其位置和量取决于主光方向、脸型、机位、环境反射和暗部可读性。

### 五、方向与阴影决定人物信息

- 正面光通常保留较多识别信息，但可能减弱体积。
- 侧面和侧逆方向用阴影建立结构、冲突和明暗分配。
- 逆光可形成轮廓、透明材质和剪影，但需要背景关系和边缘材质支持。
- 顶光、底光和其他异常方向会强烈改变面部结构，应有题材和时空理由。
- 光位没有脱离脸型、姿态、机位、景别、材质和背景的固定情绪意义。

检查眼睛、鼻梁、颧骨、嘴部、下巴和外轮廓各保留多少信息，比只写“伦勃朗光”更可执行。

### 六、软硬、反差和影调是不同维度

- 软硬主要描述阴影边界与过渡，受光源相对大小等条件影响。
- 反差描述亮暗之间的差异和暗侧密度，可由加光、减光、反射、遮挡、材质和曝光共同形成。
- 高调/低调描述画面整体明暗面积；硬调/软调描述反差与过渡，二者可以自由组合。
- 低调仍应有可读层次；高调也不等于过曝。
- 灯光、墙面、服装、材质、烟雾、镜头、曝光和后期共同形成最终影调。

反差可以用主填档差或经过项目确认的其他方式记录，但数字只描述关系，不能代替人物和空间是否有效。

### 七、人物调度必须叠加过灯区

在人物平面图上标出：

- 起点、停点、转身、靠近/远离光源和终点；
- 每一区域的主光方向、软硬、色温、曝光和暗侧信息；
- 人物接近实际灯或近距离光源时的亮度变化；
- 摄影机反打后，哪些灯位会穿帮或改变脸部方向；
- 是否需要移动光、调光cue、接力光区或允许人物自然进出暗部；
- 哪些变化属于剧情，哪些会破坏连续性。

目标不是人物始终一样亮，而是变化有来源、有目的、可预测并能与前后镜衔接。

### 八、曝光监看必须说明信号路径

最小记录：

- 摄影机和记录色彩/伽马路径；
- 监看Look及它是否影响测量显示；
- EI/ISO、白平衡/色温、快门和ND；
- 曝光参考对象；
- 使用入射/反射测光、波形、False Color或Zebra中的哪一种；
- 高光、肤色、暗部和关键材质的保护意图；
- 有意欠曝、过曝或高反差的测试证据。

False Color只能帮助检查曝光分布，不能独自判断光线是否好看、肤色是否可信、材质是否正确或叙事是否成立。

### 九、全景、近景和反打的灯光连续性

先用全景建立：动机源、主要方向、综合色、背景层次、反差和人物移动范围。近景可以：

- 调整光源距离或相对大小以保护皮肤和眼神；
- 精确遮切背景溢光；
- 微调填充或负补以恢复与全景相同的暗侧密度；
- 为镜头、滤镜和景别变化补偿曝光。

但不能无理由改变：

- 光从哪一边来；
- 日夜、天气和实际灯状态；
- 人物与背景总体明暗关系；
- 关键阴影和综合色逻辑；
- 人物经过光区时的变化顺序。

### 十、灯光方案卡与连续性记录

| 模块 | 最小内容 |
|---|---|
| 场景目标 | 时空、人物可见度、空间和情绪变化 |
| 动机源 | 可见/推断光源、方向、综合色和变化 |
| 光线规则 | 主光方向/高度、相对大小、软硬、反差、影调 |
| 人物塑形 | 面部信息、暗侧、眼神、轮廓和背景关系 |
| 空间与材质 | 前中后景、实际灯、反射、透明、烟雾和高光风险 |
| 过灯区 | 人物起止点、光区、调光/移动光cue和允许变化 |
| 摄影接口 | EI/ISO、白平衡、记录路径、监看Look、曝光参考 |
| 连续性 | 全景基准、近景允许微调、反打和跨日复现字段 |
| 图与证据 | 灯光平面图、参考静帧、灰卡/色卡、设置和测试结果 |
| 安全与备选 | 风险、授权人员、天气/供电/时间约束和最低替代方案 |

### 十一、安全停止条件

遇到以下情况，知识设计只能记录目标与风险，必须交给合格人员和现场安全流程：

- 高压或大功率配电、发电机和湿区用电；
- 高空吊挂、桁架、升降平台、车辆或移动机械；
- 明火、爆炸、烟雾、特殊化学材料和高温灯具；
- 靠近架空电线、公众区域、复杂天气或逃生通道；
- 任何没有风险评估、当地许可或授权操作者的设备。

不允许为了画面继续给出未经训练人员可照做的危险步骤。

### 十二、常见失败

1. 在画面里放实际灯，却让人物主光从完全矛盾的方向出现。
2. 把灯具亮度误认为光质，没有控制相对大小和阴影边界。
3. 只增加填充，不会通过遮挡和负补控制环境反射。
4. 追求死黑而丢失眼睛、动作、材质和空间信息。
5. 每个近景单独美化脸，切回全景后像换了时空。
6. 人物一移动就忽明忽暗，过灯变化既无动机也不可复现。
7. 色温、白平衡、实际灯和美术颜色互相叠加，却没有综合色测试。
8. 只看监视器感觉，不记录信号路径、曝光参考和Look。
9. 只保存最终静帧，不保存灯光图、设置和允许微调。
10. 把某部影片或摄影师的灯位、反差和器材当成通用配方。
11. 把后期调色当作修复前期缺失层次和错误光向的保险。
12. 忽略电力、吊挂、热量、火焰和公众区域风险。

## 光质、光量与距离的定量辨别

以下算例与诊断步骤为本库综合；光质定义参照ARRI手册第4版印刷页5、13、17，距离边界参照[ASC的实测讨论](https://theasc.com/article/revisiting-and-updating-inverse-square-law/)。它们只支持条件推理，不是现场配电、吊挂或布灯施工说明。

### 柔光看有效发光面，不看布框尺寸或瓦数

**Apparent Source Size（光源视大小：从主体位置看见的有效发光区域所占角度）**比灯具型号更直接影响阴影边缘。一块大柔光布若只有中心小块明显发亮，不能按整个布框尺寸推定软度；加亮同一个小光斑主要改变光量，不自动扩大视大小。相同尺寸光源远离主体时视大小减小，其他条件近似时阴影会更硬。

还要分清“影子边缘软”与“脸的暗侧浅”：大光源可以配很少的环境填充，形成软边但高反差；小硬光也可以配足填充，形成硬边但低反差。判断高光形状时还须看表面粗糙度和摄影机—物体—光源的角度，不能把亮面上的清晰灯形误诊为所有照明都太硬。

### 光比先写清分子和分母

**Illuminance（照度：入射到单位面积上的光通量，常用lux/lx）**不是画面像素亮度。主填关系可记录为独立贡献K:F，也可记录亮侧总照度与暗侧总照度；同写“2:1”而不说明口径，可能讲的是不同状态。

教学算例：在指定点，主光独立贡献K=200 lx，填充F=100 lx。K:F是2:1；只有假设填充对两侧各贡献100 lx、主光对暗侧没有贡献且其他反射可忽略，亮暗两侧才是(K+F):F=300:100=3:1，约1.585档。两点实际照度比R对应档差为log₂R，2:1是一档，4:1是两档。不能用两盏灯面板上的百分比代替照度，也不能把这组数字直接称为肤色的画面反差。

记录测量对象、位置、表头方向、隔离哪盏光、是否包括环境反射及监看路径。反射式读数还受材质和角度影响；Log或显示变换后的数值之比不等于入射光量之比。

### 距离翻倍不是任何光源都固定掉两档

**Inverse-Square Law（反平方关系）**的点源近似下，其他条件不变时E₂/E₁=(r₁/r₂)²。2m到4m为1/4，即少两档；2m到3m为4/9，即少约1.17档，不是精确一档。若要光量减半，距离比是√2。

大面积光源近场、定向光束、反射混入、主体转面或遮挡时，不应直接拿灯到人的一个距离套公式。ASC文章对大柔光的经验实测有近远场条件，并非推翻光的叠加原理；本库不把“源对角线处即适用”的经验当所有灯的硬阈值。人物路径上应测实际起点、变化点和终点，不能由一个点的读数宣布整段均匀。

### 一个窗边走动场景的诊断

教学构造：人物从窗边走到桌前，脸暗了，但亮面杯子的高光反而更亮。先保持曝光/白平衡/监看不变，再区分人物离光变远、转脸改变入射角、走入遮挡，还是镜面杯子进入反射角。不要以“全景太暗”为由统一加光：那可能抬亮背景并提前暴露需要隐藏的信息。

可比较延伸有效光区、改变填充、调整已允许的路径或保留剧情性暗部。每个方案同时写对阴影软硬、反差、背景、人物行动的代价。照片只能证实一个停点；连续动作与真实监看结果才支持整段判断，未测试不能写“已可复现”。

## AI制作转译与证据边界

本篇保留传统影视原理，但数字生成不自动继承摄影机、光源、演员或现场设备的物理可控性。先把专业判断转成可见/可听的结果、空间与状态约束，再由当前实际工具和真实输出检验；机型名、焦距、光圈、色温或表演动词只是输入描述时，不声称已经执行相应物理操作。

一次生成失败先定位实际差异和可能层次，不直接定责或改写故事。主要任务可以伴随其他动作或持续行为；是否需要拆分取决于具体模型、输入和实际结果，不设置固定的一动作上限。单一比较目标允许联动修改互相依赖的条件，但必须写清改变与保留项，避免把随机样本差异当成因果收益。

本轮建立专业判断和检查办法，没有生成、排练、真实剪辑、连续声画审看或观众试验；任何“可读、连续、可用、可复现”均需绑定实际结果和验证范围。
