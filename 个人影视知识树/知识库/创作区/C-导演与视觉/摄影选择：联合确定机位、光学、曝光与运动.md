# 摄影选择：联合确定机位、光学、曝光与运动

## 调用入口

- 使用者：C2；协作入口：C1、D。
- 触发：只写焦距或机型仍不能定义观看结果，参数联动产生代价，或静帧成立但人物/摄影机一动焦点、曝光和信息可读性即失败。
- 需要输入：观看位置与信息尺度、人物/场景几何、资产与光线、记录系统/显示条件、运动与可调整资源。
- 本篇交付：观看任务与场景摄影卡、物理位置/视角/焦点/时间/曝光/监看联合条件、受控比较、测试证据和跨镜接口。

## 内容导览

先用核心命题确定判断对象与适用条件，再用专业方法、对照表和案例形成候选。各步骤可以回返和联合迭代，不要求固定填完所有字段；最后用岗位接口与实际验证办法核对结果。技术词典和历史来源只在对应问题需要时使用。

## 核心命题

摄影是观看条件的设计。一个专业摄影选择应能连续回答：

```text
场景要让观众看见什么、站在哪里
→ 画幅与记录条件允许什么
→ 机位距离怎样建立透视和关系
→ 焦距怎样决定视角与背景范围
→ 景深和焦点怎样分配信息
→ 帧率与快门怎样呈现运动时间
→ 曝光与光线怎样保留或舍弃层次
→ 摄影机是否、为何以及怎样运动
→ 这一选择怎样与前后镜头及后期接口保持一致
```

技术准确是底线，叙事选择是目的。任何有意偏离正常曝光、稳定运动或常规焦点的做法，都应说明它舍弃了什么信息、换取什么观看效果，并经过测试。

## 适用边界

- 本主题处理摄影造型与记录控制，不替导演决定场景事件，不替表演主题安排人物行动，也不替灯光主题设计光源与灯位。
- 焦距决定视角，机位距离决定透视；二者常被同时调整，因此不能单独给焦距贴固定心理标签。
- 景深、曝光和运动模糊是多变量结果；“参数相同”不保证不同设备、画幅、镜头和监看链得到相同画面。
- 厂商手册中的False Color、EI、Log和具体阈值只适用于对应设备与配置，不能机械移植。
- 摄影安全、支撑、车辆、轨道、摇臂、无人机和特殊设备必须服从合格人员、风险评估与当地法规，本主题不提供危险现场操作步骤。
- 本主题先建立传统摄影知识；后续AI转译不得反过来简化专业判断。

## 知识单元

### 一、先写观看任务，再写摄影参数

每场或每个镜头组先回答：

- 观众此刻贴近谁、观察谁，还是被放在关系之外？
- 需要读环境、动作、关系、表情还是物件细节？
- 空间应显得开放、压缩、深远、平面、稳定还是失衡？
- 运动要呈现清晰阶段、自然连续、拖影轨迹还是主观紊乱？
- 哪些高光、暗部、色彩和材质信息必须保留？
- 摄影选择相对前一段是建立基准、逐步变化还是突然反转？

只有这些问题明确后，参数才有验收对象。

### 二、建立场景级记录系统基线

| 维度 | 要决定什么 | 主要影响 |
|---|---|---|
| 画幅比例 | 画面宽高与安全区 | 人物群体、空间、留白、发行和后期构图 |
| 记录格式/分辨率 | 有效记录质量和数据需求 | 细节、裁切余量、存储、代理和后期负担 |
| 基础帧率 | 项目时间基准 | 运动节奏、同步、变速和后期时间线 |
| 快门角/时间 | 单帧曝光时间 | 运动模糊、频闪风险和曝光量 |
| 色彩/伽马路径 | 原始、Log或显示编码及变换 | 监看、曝光判断、交接和后期恢复 |
| 白平衡/色温策略 | 中性基准或有意偏移 | 光源关系、肤色、材质和跨镜连续性 |
| EI/ISO策略 | 设备灵敏度/曝光索引的使用方式 | 噪点、动态范围分配和所需光量 |

这些字段不是为了制造器材表，而是保证不同场景、补拍和后期读取的是同一记录逻辑。具体数值必须由设备手册与测试决定。

### 三、焦距、画幅与机位距离共同定义空间

关键区别：

- 视角：画面能容纳多宽的范围，受焦距与画幅共同影响。
- 透视：近大远小、前后尺度关系，主要由摄影机与对象的空间位置决定。
- 主体尺度：人物在画面中多大，可由焦距、机位和裁切共同改变。
- 背景范围：主体身后纳入多少环境，与视角和机位共同相关。

选择流程：

1. 先站到叙事上正确的距离：亲近、观察、窥视、压迫或保持环境关系。
2. 决定主体要占多大画面、环境需要保留多少。
3. 选择能实现该视角的焦距与画幅组合。
4. 检查脸部、空间、背景运动和前后层比例。
5. 检查场地是否允许机位、反打、灯位、对焦和摄影机运动。
6. 在同等主体尺度下做对比测试，再确定镜头家族。

### 四、镜头家族不只是焦段表

同一项目常需要建立一组共享特性的镜头，而不是每镜临时挑最“有味道”的一支。测试维度包括：

- 各焦段的视角、最近对焦与可用拍摄距离；
- 中心与边缘清晰度、畸变和暗角；
- 反差、色彩倾向、肤色和高光滚降；
- 逆光眩光、鬼影及高亮点形态；
- 焦点过渡、呼吸和焦外形态；
- 运动、变焦或跟焦时画面是否产生不需要的变化；
- 与滤镜、传感器、画幅和后期Look的组合结果。

“统一镜头家族”不等于全片只用一种焦段；它是让变化发生在可控基准上。

### 五、景深是信息范围，焦点是注意行动

景深受焦距、光圈、对焦距离及允许模糊标准共同影响；跨画幅比较通常还伴随焦距、放大率和观看条件变化，不能单凭画幅推出景深。它是“看起来足够清晰”的范围，不是绝对清楚与绝对模糊的分界。使用顺序应是：

1. 写明必须同时清楚的对象和允许模糊的对象。
2. 确定人物调度、最近/最远动作位置及关键对焦点。
3. 选择机位和焦距，再用光圈与照明求解景深。
4. 设计固定焦点、跟焦、拉焦、区域对焦或超焦距策略。
5. 检查演员速度、遮挡、低反差、反光和运动是否让对焦失去可靠目标。
6. 为关键焦点变化定义触发点、速度、落点和失败后的替代覆盖。

小景深可以隔离信息，也会提高表演、跟焦和连续性的成本；大景深可以保留人物与环境关系，也可能让背景干扰注意。二者都不是自动的“电影感”。

### 六、帧率与快门共同塑造运动

- 帧率先决定每秒记录多少时间切片，也决定正常播放、慢动作或快动作的基础。
- 快门决定每一帧暴露多久，影响动作边缘的清晰、拖影和频闪。
- 主体速度、摄影机速度、焦距、画面放大率和播放条件会共同改变运动感。
- 改变快门会改变曝光量；改变帧率还会影响同步、光源频闪、数据量和后期时间解释。

选择时先决定运动要读“阶段、轨迹、力量、速度还是混乱”，再测试对应动作；不要只因“高速快门更清晰”就牺牲自然运动感，也不要把意外拖影包装成风格。

### 七、曝光是一组有优先级的取舍

先区分感光面实际曝光、记录信号和显示亮度。实际曝光是感光面在曝光时间内接收到的光量，受场景亮度、光圈、镜头/滤镜透射和快门时间影响；ISO/EI改变信号增益、曝光参考或监看解释，具体依设备和模式，不能直接等同于增加入射光。相同显示亮度也不等于相同曝光或画质：

- 光圈还改变景深，并可能改变镜头性能和焦外表现。
- 快门还改变运动模糊。
- EI/ISO会影响设备的噪点、动态范围分配或显示解释，具体行为取决于设备。
- ND和滤镜会影响通光、颜色、反射或成像，需要真实测试。
- 增加照明会改变方向、光质、反差和现场条件，不只是“补足亮度”。

推荐记录：曝光参考对象、希望保留的最亮/最暗区域、光圈/T档、快门、EI/ISO、ND/滤镜、白平衡、记录曲线、监看Look、使用的测光/波形/False Color方式以及有意偏离基线的理由。

### 八、摄影机运动应说明观看作用

每次运动写清：

| 项目 | 要回答的问题 |
|---|---|
| 触发 | 什么人物行动、发现、声音或关系变化使摄影机开始动？ |
| 路径 | 摄影机相对人物和空间怎样改变位置？ |
| 新信息 | 运动过程中新增、隐藏或重排了什么？ |
| 速度 | 与人物动作、情绪和焦点变化怎样配合？ |
| 支撑 | 手持、肩扛、稳定器、轨道、摇臂或其他方式能否安全实现？ |
| 焦点 | 运动中的距离变化和遮挡怎样处理？ |
| 落幅 | 运动为何在这个构图结束，结束后给观众什么新状态？ |
| 接口 | 起幅、落幅、屏幕方向和运动势能怎样与前后镜衔接？ |

运动可以改变或有意维持信息、关系、空间、节奏与身体感；若无法说明其具体观看作用，比较固定摄影机、画内调度或减少运动，不因运动量直接判效果。

### 九、摄影测试是方案的一部分

在真实或等效条件下测试：

- 角色肤色、服装、妆发与关键材质；
- 场景墙面、玻璃、金属、镜面、LED和实际灯；
- 不同焦距、距离、光圈和滤镜；
- 正常、欠曝、过曝以及高反差条件；
- 运动速度、快门、频闪、滚动快门与稳定方式；
- 跟焦、最近对焦和景深容错；
- 记录文件、监看Look、代理、后期解码和最终显示。

测试必须保留设置、文件身份、观看条件和结论。只保存“最好看的一张”却不知道怎样得到，不能支持正式摄影。

### 十、摄影时机也是构图与叙事选择

连续摄影不只选择“用什么参数”，还选择动作和关系的哪一个阶段最值得成为画面。面对不可重来的事件，可同时观察：

- 主体动作何时进入关键形态；
- 对手或旁观者何时产生有意义的反应；
- 背景、光线、遮挡和图形何时与主体形成关系；
- 哪一刻既保留因果，又能让观众读懂人物和环境；
- 需要依赖预判、区域对焦、连续拍摄、最低覆盖还是可重复排练。

“决定性瞬间”不是只追求动作最夸张的一帧，而是让主体、他人和环境在同一时刻形成最有意义的关系。可重复剧情拍摄还应保护动作前因、关键瞬间和结果，避免只获得一张漂亮静帧却无法剪辑。

### 十一、场景摄影方案卡

| 模块 | 最小内容 |
|---|---|
| 场景任务 | 观众视点、信息尺度、空间与运动目标 |
| 视觉基准 | 画幅、构图倾向、镜头家族、距离和高度基准 |
| 记录基线 | 分辨率/格式、帧率、快门、色彩/伽马、白平衡、EI/ISO |
| 光学策略 | 焦段范围、透视目标、景深、焦点路径、滤镜 |
| 曝光策略 | 参考对象、高光/暗部保护、监看与有意偏离 |
| 运动策略 | 触发、路径、支撑、速度、焦点、起落幅 |
| 连续性 | 跨镜的视点、镜头特性、曝光、色温、方向和运动接口 |
| 部门接口 | 表演停点、场景可拆空间、灯光区、场记字段、后期基线 |
| 测试证据 | 测试文件、设置、结果、采用与禁用项 |
| 风险与备选 | 场地、时间、天气、设备、焦点、安全和最低替代方案 |

### 十二、常见失败

1. 只写焦距，不写摄影机距离、主体尺度和背景关系。
2. 把浅景深当默认高级感，导致动作、环境和关键反应失焦。
3. 为“电影感”任意改变快门，却没有检查运动和频闪。
4. 监看套了强Look，却没有确认记录信号的真实曝光。
5. 每镜使用不同镜头特性、白平衡或曝光逻辑，没有场景基准。
6. 运镜只有器材动作，没有触发、新信息和落幅。
7. 方案在静态参考图上成立，演员移动、跟焦和反打后立即失败。
8. 忽视美术材质和实际灯，现场才发现反射、色偏或穿帮。
9. 只做相机内测试，没有走完代理、后期解码和显示链。
10. 把设备规格、动态范围宣传值或单一厂商阈值当作项目已经验证。

### 十三、用受控比较解释焦距与透视

Focal Length（焦距：描述镜头成像几何、通常以毫米表示的光学量）、Angle of View（视角：有效画幅内能记录的角度范围）、Perspective（透视：从特定观察位置形成的前后相对尺寸和遮挡关系）需要分开。以下比较采用普通直线投影镜头，先忽略畸变、呼吸、像场和入口瞳位置差异。

| 比较条件 | 主要变化 | 不能据此声称什么 |
|---|---|---|
| 保持观察位置，换较长焦距 | 视角缩小，各对象的像同时放大 | 不能仅由此说明前后距离比变了 |
| 保持观察位置，将广角中心裁到相同画面范围 | 理想几何透视相同；分辨率、畸变、景深和镜头表现未必相同 | 不能把几何相近说成两份影像所有品质一致 |
| 换较长焦距，同时后退以维持主体大小 | 摄影机到前后物体的距离比变化；背景相对主体显得更大 | 不能把这一组合效果全部归给焦距 |
| 保持焦距与观察位置，改有效感光区域/裁切 | 记录范围改变 | 不等于人物和背景真的靠近 |

以两个等高、同朝向且与像面平行的标记为例，距离指沿观察方向的深度，摄影机沿同一方向后退。在这个理想投影模型里，像高比由深度比决定。前标记在2米、后标记在6米，前者约为后者3倍；摄影机退后4米，深度变为6米和10米，比例约为1.67。再增加焦距恢复前标记大小，不会把比例恢复成3。这个简化计算解释常说的“压缩”，不是实拍测试报告。Nikon 的相同人物大小对比明确改变了拍摄距离。[官方教学的“遠近感の違い”](https://nij.nikon.com/learn/phototech/manual/19/02.html)

实际测试记录相机观察位置、有效画幅、焦距、对焦距离和裁切；对齐主体大小后再看背景比例与遮挡。镜头前后位置、畸变校正和近摄呼吸会影响严格匹配，应记录而不是把所有差异都叫透视。

### 十四、景深与焦点的诊断顺序

Depth of Field（景深：在约定观看条件下可接受的清晰距离范围）不等于焦外背景模糊程度，也不等于对焦准确。两个人一前一后要同时可读，先测最近/最远关键动作距离、焦距、有效画幅和对焦点；再在目标输出尺寸下测试光圈，不能凭f值直接保证。

| 观察到的问题 | 可能原因 | 区分方法与取舍 |
|---|---|---|
| 静止时一人清楚、一人不清楚 | 景深不足或焦平面选择不合适 | 比较不同对焦点与光圈；收光圈会损失光量，需要另求曝光 |
| 静止清楚，移动时断续失焦 | 跟焦时序/目标丢失、路径越出容差或遮挡 | 对照距离标记、跟焦记录与原速回放；景深补偿不能代替对焦检查 |
| 单帧焦点似乎正确，运动边缘拖长 | 主体运动模糊、摄影机抖动或读出形变 | 分看静态目标与运动边缘；缩短曝光可减少主体运动和机身抖动造成的单帧拖影，但不能消除逐帧构图晃动，也不保证消除读出形变 |
| 两人都清楚却不知道看谁 | 注意设计而非光学清晰度不足 | 检查声音、表演时机、亮度、遮挡与构图；不必先把一人虚化 |

缩光圈通常增加景深，但过小光圈的衍射与系统分辨率也需要测试。改变人物深度、机位或剪辑方式同样可以改变任务；它们会触及调度与观看意图，应共同决定。Nikon 官方光圈资料用于支持基本趋势，具体容差仍由实际镜头、距离和输出标准决定。[What is Aperture](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/what-is-aperture)

### 十五、快门时间、运动形态与光量怎样一起算

在常规快门角定义下，曝光时间 `t = θ / (360 × 记录帧率)`。项目播放帧率和传感器记录帧率不同的时候，分母用实际记录帧率。公式见 ARRI ALEXA 35 SUP 1.3 手册“Home Screen / SHUTTER”；这里只引用公式，不继承该旧版本的当前功能范围。[官方手册](https://www.arri.com/resource/blob/377580/e0b87c943e2265fa98f00ba7d4ca8957/alexa-35-sup-1-3-0-user-manual-data.pdf)

例如24fps、180度为1/48秒；改90度为1/96秒，在光线、光圈和透射等不变时，光量减半，即少一档。运动拖影通常减少，但逐帧位置变化仍由帧率和屏幕速度决定，运动可能更顿挫。若用开一档光圈补亮，会同时改变景深；用ISO补显示亮度没有补回光子。滚动快门形变由读出时序等条件影响，不能保证缩快门就消除。

拍摄原速动作并按目标帧率、尺寸和显示条件回看；记录主体速度、摄影机运动、实际灯光与屏幕设置。光源调制和电子屏刷新可能造成频闪或条纹，不能凭一个常用快门数字保证无问题。

### 十六、ISO、EI、记录信号和监看亮度分层判断

ISO在数码系统中的具体作用可能涉及增益和读出模式；EI（曝光指数：用于选择曝光参考、监看及后期解释的指标）也不是所有机器相同的增益旋钮。未知设备时，先确定我们调的是哪种模式。

| 层 | 要核对什么 | 可以先作出的判断 |
|---|---|---|
| 入射光与积分时间 | 照明、光圈、ND、快门以及自动功能是否真的固定 | 都不变时，仅改ISO/EI不会使感光面接收两倍光 |
| 感光与读出 | 基准ISO、双转换增益或读出模式是否切换 | 噪声、高光余量如何变化需查相机，不给通用倍数 |
| 文件编码与元数据 | RAW/Log/显示编码、增益是否写入、EI是否只记元数据 | 监看变化不能自动证明文件信号以同样方式变化 |
| 显示 | LUT、EI显示补偿、显示亮度和自动后期调整 | 变亮可能只是显示解释；需用共同变换比较源文件 |

Sony 的《Exposure and Exposure Compensation》区分入射光量和影像亮度；《Using the Exposure Index in shooting》说明其相应Cine EI方式中记录使用基准ISO，EI可影响监看和元数据。此例不能推广到所有厂商，更不能忽略Cine EI Quick可能自动切换基准的条件。[曝光说明](https://www.sony.com/electronics/support/articles/00267925)、[EI使用说明](https://helpguide.sony.net/di/pp/v1/en/contents/TP1000756720.html)、[模式差异](https://helpguide.sony.net/ilc/2240/v1/en/contents/TP1000673422.html)

要检验差异，关闭或记录自动光圈、自动快门、自动ND和自动ISO；固定照明，拍同一灰阶与肤色样本，保存源文件、设置与共同监看变换。在相同最终亮度下比较噪声、可恢复层次与剪裁。结果前只能说明可能机制，不能承诺“升ISO更干净”或“EI高一档多一档总动态范围”。

### 十七、一个贯穿例子：两人之间的观看距离

`[教学构造案例；未拍摄、未生成、未验证观众效果]`

前提：甲在近处说话，乙在后方先察觉窗外变化；导演需要观众在同一时刻理解两人的不同知情状态。先保留二人的空间与反应，再决定是否必须同时清晰。若叙事需要观众自主发现乙，可以测试同框较深景深；若需要先被甲占据，再被乙吸引，可以比较声音、动作或焦点引导。拉焦会影响发现时机，不能只当漂亮效果。

测试版把人物位置和行为固定，先比较机位，再求焦距与主体尺度；确认两人的可读性后求光圈和焦点，再配光量与快门。这里的先后是为了看清变量，不妨碍现场联合迭代。

若空间不允许后退，不能只提高焦距却声称获得远距离透视。若补光能力有限，缩光圈可能迫使改变位置、记录方式或覆盖；须向导演说明将牺牲哪部分观看关系。若用户只给“要压迫感”，尚不足以选定焦距、ISO和f值。
