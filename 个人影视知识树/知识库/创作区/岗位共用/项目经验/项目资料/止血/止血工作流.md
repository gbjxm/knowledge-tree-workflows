# 止血工作流

> [!note]
> 已确定设定：主角为男性，40岁左右，姓名暂未定；重伤者为12岁左右男孩；当年死在主角手术台上的是男孩的父亲；片长控制在7分钟左右。当前重点先完善设定、结构和分场，台词暂不细化。

## 一句话创意

```text
一名曾因狂妄自负、在连续高强度手术中拒绝副手接替而失误害死病人的天才外科医生，因此恐惧做手术患上晕血症，隐居在偏远山区经营诊所；多年后的一场暴雨中，他不得不再次拿起手术刀，抢救当年死在自己手术台上的病人的孩子。
```

## 故事大纲

**起因：**暴雨中的山区诊所里，40岁左右的男医生正在给村民包扎伤口。他处理动作熟练，却在看见血迹时下意识轻微干呕，暴露出隐藏的晕血反应。闲聊中，村民提到早上有一群小孩进山露营，给后面12岁男孩被送来急救埋下钩子。

**发展：**暴雨越下越大，山路塌方、通讯断续。夜里，露营队伍中的12岁男孩重伤被送到诊所，伤势必须马上处理。主角起初试图推脱，强调设备不足、救援会来；随行家属/知情人互相认出身份他曾是顶级外科医生，并揭开孩子父亲当年死在他手术台上的往事。

**转折：**男孩情况急转直下30分钟内必须进行止血，外援无法赶到。主角被迫面对两层恐惧：眼前的血，以及当年因为连续高强度手术、拒绝副手接替而害死孩子父亲的负罪感。他第一次直面自己的恐惧，并让护士/助手和村民参与分工。

**结尾：**简陋条件下，主角靠团队协作完成关键止血，男孩暂时脱离生命危险。雨停后救援抵达，主角没有被彻底“治好”，但他能看着沾血的双手不再逃开；他明白自己无法改写孩子父亲的死亡，但这一次他直面自己的内心选择承担责任。

## 剧本

片名：《止血》

> [!note]
> 写作格式：每场按“场景标题 + 动作描写 + 人物名 + 对白”推进。动作只写观众能看到、听到的内容；心理活动尽量转成动作、声音或停顿。

### 1. 内景 山区诊所 夜

【动作描写：暴雨、诊所环境、主角给村民包扎伤口、看见血后轻微干呕。】

**村民**

【对白：自然提到早上有一群小孩进山露营。】

**主角**

【对白：回应天气、山里不安全，或用沉默掩饰不适。】

【声音/画面提示：雨声、雷声、纱布吸血、主角手指停顿。】

### 2. 内景 山区诊所 夜

【动作描写：村民离开，主角清理带血纱布；暴雨加重，救援困难的信息出现。】

**护士/助手**

【对白：察觉主角脸色不对，或提醒外面路况。】

**主角**

【对白：否认自己不适，继续回避开刀和血。】

### 3. 内景 山区诊所门口 夜

【动作描写：门被撞开，12岁男孩被抬进来，露营钩子兑现。】

**送诊者/村民**

【对白：说明男孩受伤、求主角救人。】

**主角**

【对白：判断伤势，但试图以设备不足、等救援为理由拒绝。】

### 4. 内景 治疗室 夜

【动作描写：男孩情况恶化，主角看见血后失控；有人认出他的过去。】

**家属/知情人**

【对白：揭开男孩父亲当年死在主角手术台上的事实。】

**主角**

【对白或沉默：无法否认，闪回开始。】

【闪回提示：无影灯、监护仪长鸣、手术手套上的血。】

### 5. 内景 临时手术台 深夜

【动作描写：外援无法赶到，主角必须决定是否动手。】

**主角**

【对白：承认自己害怕，开始分配照明、递器械、按压、观察脉搏等任务。】

**护士/助手**

【对白：回应主角，进入协作。】

### 6. 内景 临时手术台 黎明前

【动作描写：手术中出现危机，主角差点重复当年独断错误。】

**主角**

【对白：一度命令所有人安静，随后改为让助手复述生命体征。】

**护士/助手**

【对白：给出关键反馈，帮助主角找到出血点。】

【动作描写：止血成功，声音从混乱转为稳定。】

### 7. 内景 山区诊所 清晨

【动作描写：雨停，救援抵达，男孩被转运。】

**家属/送诊者**

【对白或动作：不必明确原谅，可以只留下一个克制反应。】

**主角**

【对白或动作：看着沾血的手套，不再立刻逃开。】

【最后镜头：诊所门口、清晨山雾、救护车灯、主角留在原地或跟车离开。】

| 护士/助手 | 诊所助手，熟悉主角的回避 | 知道主角有能力但长期不用，也看见他面对血时的生理反应。 | 在手术中成为主角真正依靠的人，帮助他完成从“一个人扛”到“把命交给团队”的转变。 |

## 音乐与音效想法

| 时间/段落 | 声音类型 | 描述 | 作用 |
| - | - | - | - |
| 开场 | 雨声 | 密集、持续、压低人声，偶尔夹杂远处山体滑落或雷声。 | 建立封闭空间和不可逃离的外部压力。 |
| 主角见血 | 主观音效 | 雨声被抽空，心跳、耳鸣、手套摩擦声被放大。 | 让观众进入晕血症和创伤记忆。 |
| 事故闪回 | 医疗声 | 监护仪长鸣、无影灯电流声、手术器械碰撞声短促切入。 | 把过去与现实剪在一起，提示他差点重演旧错误。 |
| 团队协作 | 节奏音 | 器械盘轻响、助手报数、呼吸节奏逐渐稳定，音乐只铺低频。 | 从混乱走向秩序，表现主角重新学会信任。 |
| 手术成功后 | 环境声 | 雨声变稀，清晨鸟鸣或救护车远处声逐渐进入。 | 不给煽情大音乐，保持克制和真实的余味。 |
