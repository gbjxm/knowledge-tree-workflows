# 旧壳 - 镜头语言演示案例

> 本文完整保存原 `镜头语言专业总表 v2.0` 中的项目演示，使通用知识与具体项目事实分层。它只证明描述格式如何使用，不代表镜头已进入正式制作或已经验证有效。

## 本轮目标

- 当前阶段：镜头语言学习与项目演示。
- 要解决的具体问题：把城市生态、人物伤势、动作限制和摄影机方案放入同一个镜头描述。
- 完成标准：镜头任务、画面范围、空间呈现、视点、运动和连续性约束均可被识别。

## 原始演示

```text
交代城市生态并埋设伤势；关系兼环境镜头，中景，28mm 广角、近距离，深焦，胸肩高度平视，侧面半主观；男主置于左三分区并向右保留运动空间，摄影机与其等速平行跟拍，前景管道依次遮挡并露出能源摊和陪伴机器人广告；男主始终用左手固定背包，右臂不主动抬高。
```

## 本轮决策与执行

| 层级 | 原描述中的内容 | 当前判断 |
|---|---|---|
| 镜头任务 | 交代城市生态并埋设伤势 | 清楚，但尚未说明所属场景节拍和前后镜关系 |
| 镜头功能 | 关系兼环境 | 有主次方向，但需确认人物与哪一环境要素形成主要关系 |
| 景别与空间 | 中景、28mm、近距离、深焦 | 能描述空间感，仍需结合真实场景平面和主体距离验证 |
| 观看位置 | 胸肩高度平视、侧面半主观 | 具备观众位置，但需要明确半主观所贴近的角色体验 |
| 构图与运动 | 左三分区、向右运动空间、侧面平行跟拍、前景遮挡揭示 | 信息丰富，需检查单镜时长能否容纳所有揭示节点 |
| 连续性 | 左手固定背包、右臂不主动抬高 | 对人物伤势和动作限制有明确价值 |
| 尚缺接口 | 入点、出点、轴线侧、声音、开始/结束状态、AI 风险 | 应在正式镜头方案中补齐，而不是继续塞进一句话 |
