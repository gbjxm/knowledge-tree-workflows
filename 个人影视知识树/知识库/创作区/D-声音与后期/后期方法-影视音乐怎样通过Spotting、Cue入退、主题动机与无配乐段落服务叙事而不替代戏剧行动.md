# 后期方法-影视音乐怎样通过Spotting、Cue入退、主题动机与无配乐段落服务叙事而不替代戏剧行动

> 本文是面向D岗位的专业方法正文。原稿的学习、个人理解与练习保留原位；此处以当前制作问题进入完整方法。旧稿中的阶段1—6、Stage、OPC及C部门标签用于解释专业功能与历史综合，不能替代当前V1的部门协作、工作集、采用或执行规则。

## 调用入口

- 当前问题：手术室外等待这一段用音乐很感人，撤掉后效果下降，能否据此认定故事不成立？如何区分音乐承担叙事与掩盖信息缺口？
- 何时进入：需要判断音乐是否出现、站在哪个情感视点、何时入退或主题怎样变化时进入；先写叙事职责，再比较音乐变量。
- 先带哪些事实：当前对象和精确版本、已知创作意图、已经观察到的结果与限制；缺少真实媒体时区分方案判断和执行结论。
- 何时结束：关键方法及其条件已能支持本次判断，剩余未知已定位；不因章节多而要求通读全部，也不只读标题或摘要便宣称方法覆盖。

## 快速认识

- 核心问题：为什么音乐旋律好听、情绪强烈、与画面同步，仍可能让场景变浅、变俗或失去真实行动。
- 主要结论：先用Spotting决定音乐是否必要、承担什么和站在哪一侧，再决定Cue的精确入退、内部轨迹与主题变化；无配乐也是正式决定。
- 调用价值：学会从“给画面加什么音乐”转向“观众此刻还缺少什么信息、距离或情感位置”，并能识别音乐正在揭示戏剧还是替戏剧工作。
- 适用环节：剧本和分镜中的music-first预判、Rough／Fine期间的音乐诊断、稳定画面上的制作型Spotting、Temp拆解、Cue审听及阶段3声音协商。

## 核心命题

音乐可以揭示新意义，也可以组织、延展或强化已有的视点、结构、时间感和情绪；不必每次都提供画面之外的新信息。撤掉音乐可以帮助定位依赖，但不能据此要求所有场景独立于音乐成立：歌舞、节拍驱动或由音乐承担叙事信息的段落，本来就以声画共同构成为前提。需要诊断的是非预期的遮掩与失效，不是音乐参与本身。

~~~text
Rough／Fine与阶段3声音WIP
→ 诊断型音乐Spotting
→ 音乐／无音乐策略与Temp功能拆解
→ Picture Lock或明确先行基线
→ 制作型音乐Spotting
→ Cue入退、情感视点、主题动机与内部轨迹
→ 与对白、FX、环境和声音设计协商
→ 绑定CUT的音乐叙事决定
→ 交给配乐制作、音乐编辑和最终混音
~~~

“更感人、更紧张、更有电影感”不是完整叙事决定。音乐为何出现、为谁出现、改变了什么，以及何时让位，必须能够被解释和比较。

## 适用边界

- 本主题只处理音乐的叙事策略与Cue决策，不负责和声、配器、Mockup、录制、生成、Music Master与Stems的完整制作链。
- 原创、既有、曲库和AI属于生产来源；本主题只讨论这些来源怎样影响叙事选择，不负责作品／录音双身份和清权。
- 本主题区分Temp、Reference、候选和采用等制作状态，但不把Temp文件当正式音乐资产。
- 诊断型音乐判断可在锁画前发生；精确入退与正式制作应绑定Picture Lock或明确标识的先行基线。
- 音乐先于画面的表演、舞蹈、歌词或节拍驱动段落属于合法分支，不应强迫套用picture-first。
- 无配乐不等于全片静音；对白、呼吸、环境、Foley和声音设计仍可能是前景。
- 本主题不规定固定音乐覆盖率、Cue数量、主题数量、Hit数量、入退公式、曲风或配器。
- P70部分音画关系术语的ASR仍待二刷；本主题只使用已能被语境与外部资料支持的同步、反差、对位、游离等功能，不构造固定“五种关系”。
- Agent未实际看到当前CUT、听到阶段3声音WIP并比较音乐／无音乐版本时，不得声称Cue叙事有效。

## 内容导览

### 整体脉络

- 分流：用四条轴区分生产来源、叙事位置、制作状态与权利状态，避免用一个“音乐类型”替代判断。
- 诊断：在Rough／Fine比较有音乐、无音乐与不同音乐，先确认戏剧是否成立。
- 定位：为每个Cue确定叙事功能、情感视点和全片位置。
- 入退：用故事节拍而不是时间码本身解释为什么现在开始、现在结束。
- 发展：让主题、动机、音色、密度和速度随人物关系变化，而不是机械贴标签。
- 协商：与对白、声音设计、环境和关键FX确定谁在前景、谁承担转场。
- 前置：遇到演唱、舞蹈、口型或节拍驱动画面时，触发music-first并把Guide交给上游。
- 验收：音乐承担已声明的声画职责，并通过有音乐、无音乐及替代方案比较核对；可组织或强化已有视点、时间与情绪，不要求增加新意义。关闭音乐后仍能定位上游问题，所有决定绑定同一CUT。

## 知识单元

### 一、四条轴不能合成一个音乐标签

| 轴 | 典型值 | 本主题怎样使用 |
|---|---|---|
| 生产来源 | 委约原创、既有录音、曲库、重录、AI、混合 | 判断可获得性、可修改性和是否会反向约束叙事 |
| 叙事位置 | 故事内／画内外声源、故事外配乐、由内转外、边界模糊 | 判断角色能否听见，以及音乐属于谁的世界 |
| 制作状态 | Temp、Reference、候选、Demo、采用、拒绝 | 防止把探索材料当作已批准叙事事实 |
| 权利状态 | 未核、待补证、受限、当前用途已核验 | 只作为采用门；不能用“有授权”替代审美理由 |

叙事位置是本主题的核心，但其余三轴会改变决策可行性。Source Music描述的是故事世界中的声源关系，不自动等于既有音乐；AI生成描述的是生产来源，也不说明角色是否听见、音乐是否采用或权利是否完成。

### 二、先建立全片音乐命题

单个Cue可以有效，却共同制造一部没有音乐方向的片。Spotting前先写清：

- 整部片的音乐在追问什么，而不只是使用什么风格；
- 音乐主要靠近哪个人物、关系、记忆、世界或作者态度；
- 哪些信息由音乐提前暗示，哪些必须等戏剧行动发生后再出现；
- 哪些段落故意不使用音乐；
- 全片音乐从稀到密、从完整到破碎或从稳定到不稳定的变化弧；
- 音乐与声音设计分别承担哪些主题材料；
- 最后一个Cue怎样回望或推翻前面的音乐经验。

音乐命题不是曲风清单。相同的钢琴、弦乐或电子音色，可以站在完全不同的情感和伦理位置。

### 三、两层音乐Spotting是两种功能

| Spotting | 时机 | 回答 | 最小产物 |
|---|---|---|---|
| 诊断型 | Rough／Fine，可重复 | 是否需要音乐；音乐承担什么；无音乐版是否成立；走哪种来源；是否music-first | 绑定CUT的暂定音乐地图，全部标明假设 |
| 制作型 | Picture Lock或明确先行基线 | 精确入退、Cue弧、主题／动机、Hit／Avoid、对白／FX优先级和制作路线 | 稳定Cue ID及可进入制作的音乐决策表 |

这不是规定所有项目召开两次会议，而是把“探索问题”和“精确制作”分开。前者允许撤销，后者需要稳定版本与责任；画面变更后，制作型决定必须重新审看。

### 四、Spotting先问为什么，再问在哪里

每个重要Cue至少回答：

1. 不用音乐时，人物行动、表演、信息和节奏是否成立。
2. 音乐增加的是信息、情感距离、期待、反差、结构还是主题联系。
3. 音乐站在角色、关系、事件、作者还是观众预期一侧。
4. Cue内部从什么状态走向什么状态。
5. 哪个故事节拍触发进入、变化和退出。
6. 对白、动作、FX、环境和音乐谁应在前景。
7. 它怎样承接前一个Cue，又为后一个Cue或无配乐段落留空间。

只有在这些问题有暂定答案后，时间码才是可制作的定位，而不是假精确。

### 五、情感视点决定音乐站在哪一边

常见位置包括：

- 角色视点：让观众接近某人的欲望、恐惧、记忆或误解；
- 关系视点：音乐不属于单个人，而属于两人之间正在形成或破裂的联系；
- 事件／世界视点：强调历史、地点、制度、共同体或超出角色认知的力量；
- 作者视点：保持距离、评论、反讽或提出伦理判断；
- 观众预期：让观众比角色更早知道、误判或等待某件事。

视点不是固定标签。同一Cue可以先贴近角色，随后在真相出现时退到作者或事件位置。判断标准不是“情绪像不像”，而是观众被邀请与谁站在一起、知道多少、保持多大距离。

### 六、音乐与画面可以同向，也可以增加差异

音乐可能：

- 同向强化已经出现但尚未充分展开的情绪；
- 提前建立威胁、希望或记忆，让观众等待画面兑现；
- 延迟情绪，等角色真正领会后才进入；
- 与人物认知错位，让观众看到他没有看到的东西；
- 与暴力、喜悦或秩序形成反差和对位；
- 相对游离，以独立音乐层扩展时代、地域、主题或作者态度；
- 从故事内声源转成画外配乐，或反向揭示声源。

同向不是低级，反差也不自动高级。每种关系都必须说明它增加了什么，而不是为了术语而选择。

### 七、Cue入点是一次信息与注意力切换

可测试的入点包括：

- 画面或场景开始前预先进入，建立期待或音乐桥；
- 与明确事件同步进入，强调结构性转折；
- 事件发生后延迟进入，让行动先被观众真实感受；
- 在角色领会而非事实发生时进入，绑定心理变化；
- 在切换视点、时空或叙事层时进入；
- 从故事内音乐逐渐扩展为故事外配乐。

入点判断法：

1. 把入点前移，观众会过早知道或被过早指挥什么？
2. 把入点后移，是否更能保护表演、现实重量或悬念？
3. 完全撤掉，场景失去的是必要结构还是只是熟悉的情绪提示？
4. 入点是否同时与对白、FX或声音桥抢夺同一注意力？

“切镜就进音乐”“人物哭就进音乐”都不是专业公式。

### 八、Cue出点决定意义落在哪里

常见退出方式：

- Hard Out：在明确事件、揭示或断裂处停止；
- Tail Out：让尾音自然结束，保留余韵和空间；
- 在对白、环境或关键FX接管前退出；
- 跨场延续，把上一场的主题、情绪或误解带入下一场；
- 从画外配乐收束为故事内声源；
- 在人物尚未完成情绪时提前退出，拒绝替他表达。

出点不是技术收尾。退出太晚会替角色总结，退出太早可能切断尚未完成的音乐弧。应比较“观众最后听见的是音乐、人物呼吸、环境还是某个动作”，因为最后留下的声源常决定场景余义。

### 九、无配乐是一项积极的叙事决定

NO SCORE／无配乐可能用于：

- 让呼吸、犹豫、空间、材质和动作代价进入前景；
- 让观众停止接受情绪指令，自己形成判断；
- 保留现实重量、尴尬、危险、疏离或伦理距离；
- 让阶段3的声音桥、主观听觉或环境母题承担主题；
- 为后续音乐进入建立真正的对比和稀缺性；
- 暴露场景在没有音乐支撑时是否仍成立。

Spotting表应记录“无配乐”及理由，而不是把空白当未完成。无配乐仍需审听阶段3声音；没有音乐与误丢声音轨道完全不同。

### 十、Temp与Reference要先拆功能

- Temp是当前被放进画面、用于剪辑、试映或沟通的临时音乐。
- Reference是用于说明速度、能量、音色、结构或态度的参考材料，不一定进入时间线。
- 同一首音乐可以同时承担两种角色，但必须分别说明，不能只写“像这首”。

拆解维度：

| 维度 | 要提取什么 |
|---|---|
| 节奏 | 速度、脉冲、密度、停顿和推进方式 |
| 结构 | 起伏、段落长度、高潮位置和尾音 |
| 音色 | 乐器、材质、演奏、空间、失真与真实／电子比例 |
| 和声／旋律 | 稳定与不稳定、明暗、旋律存在感、重复和主题感 |
| 叙事 | 情感视点、入退理由、与画面同向／反差及注意力关系 |
| 禁止模仿 | 具体旋律、歌词、标志性编配、声音身份和作品指向 |

控制Temp Love的最小比较：

1. 必要对白与环境声版；
2. 当前Temp版；
3. 无音乐或明显不同音乐版。

比较叙事任务和观众反应，而不是要求正式音乐复刻Temp表面。若只有Temp版成立，区分它是否承担不可缺少的结构／信息，还是以熟悉感掩盖问题；不能仅据无音乐版失效判定剧本或表演失败。

### 十一、主题与动机必须有变化规则

主题或动机可以关联人物、关系、欲望、地点、观念、记忆或未被说出的信息。它不等于“每个角色一条固定旋律”。

每个重要音乐单元应回答：

- 初次出现时代表什么，观众应感到什么但不必立刻解释什么；
- 哪些场景故意不出现；
- 当人物、关系或认知变化时，它怎样变化；
- 是否通过旋律、和声、节奏、配器、音域、密度、空间或完整度改变；
- 与其他主题怎样靠近、冲突、融合、破碎或消失；
- 最后一次出现是确认、反转、哀悼、释放还是悬置。

主题的意义可来自音乐变化、语境变化或再次出现的位置与间隔。原样复制可能只是识别提示，也可能形成仪式、期待或反讽；不能仅看音符是否改变判断有无发展，须检查观众实际获得的联系。

### 十二、节奏与Hit服务结构，不是追点比赛

视听节奏来自故事事件、人物情绪、镜头内部变化、镜头间剪辑和声音共同作用。音乐可以与画面同向加速，也可以以慢音乐对抗快画面，制造距离或压迫。

- Hard Hit用于必须精确对应的同步或结构事件；
- Soft Hit只需在段落关系上大致对齐；
- Avoid Point提醒音乐不要在对白、表演或关键FX处突然抢重音；
- 音乐可以跨越切点，让乐句而非剪辑率控制呼吸。

每个动作和切点都被音乐重音，会形成机械追点。Mickey-Mousing可以是明确风格，但不是专业默认。镜头短、节拍快也不代表节奏有效；没有新事件、新关系和新信息时，音乐只能制造表面速度。

### 十三、music-first是必要的前置触发

以下情况应在生成、拍摄或最终画面剪辑前确定足以同步的音乐Guide／Pre-record：

- 角色唱歌、演奏、舞蹈或口型；
- 动作、摄影机或剪辑结构依赖固定节拍、乐句或歌词；
- 动画／AI角色表演由音乐驱动；
- 原创歌曲或故事内表演是剧情事实；
- 主题草图是整部影像节奏和气质的共同上游。

前置最小信息包括：音乐版本、速度、结构、段落标记、必要同步点、可变范围、Guide文件和当前采用／权利状态。music-first不等于音乐永远锁死画面；最终画面形成后仍需重新检查、编辑和Conform。

### 十四、阶段3与阶段4协商的是注意力和责任

阶段3应交给音乐判断：

- 对白及呼吸必须保持前景的位置；
- 关键FX、Foley、环境、声音桥和主观听觉；
- 设计性留白和音乐避免区；
- Drone、Pulse、Riser、Stinger等边界元素的当前责任方。

本主题应交回阶段3／后续制作：

- 音乐Cue入退、密度、动态弧和情感视点；
- 主题、Source状态、音乐桥和NO SCORE区；
- 哪些音乐元素会与设计声音共享频段、脉冲或叙事功能；
- 哪些转场由音乐负责，哪些必须留给声音。

边界元素没有统一归属。应为每个关键元素指定MUSIC或DESIGN责任方，避免两边同时堆叠。阶段4可以通过编配、密度和入退为对白让位，但全片最终平衡、响度和处理属于阶段6。

### 十五、轻量Cue记录也必须绑定CUT

本主题的最小叙事Cue字段：

| Cue ID | CUT | 入／出点 | 叙事功能 | 情感视点 | 故事内／外 | 内部轨迹 | 主题／动机 | 对白／FX优先级 | Temp／Reference | 状态 |
|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |

制作型Cue还会增加音乐版本、Hit／Avoid、Conform、批准和交付字段；这些由相邻的配乐制作与音乐编辑主题展开。Cue ID采用何种格式并不重要，重要的是唯一、稳定、可追踪。

## 方法与案例

### 音乐变化不只有“更快、更响”

Tempo（速度）说明单位拍的推进速率；Rhythmic density（节奏密度）说明给定时间里音符／事件有多密；Harmonic rhythm（和声节奏）说明和声更替的节奏。三者可以独立变化。每分钟120拍的持续音层与同速度的十六分音符型，听感不同；保持同一速度、把和弦由每拍一换改成两小节一换，也不等于音乐文件变慢。

Scarlet Keys的[Berklee教学文章](https://www.berklee.edu/news/berklee-now/telling-story-harmonic-rhythm)以歌曲写作说明和声更替怎样支持叙述；本库将其作为配乐判断的可试验维度，不把某种和声速度与某种情绪永久绑定。以下是本库综合：

| 需要改变的体验 | 可以先比较的音乐变量 | 容易误判 |
|---|---|---|
| 不加速却逐渐紧迫 | 节奏细分、音域、织体密度、和声稳定度 | 只提高BPM，破坏原动作与乐句 |
| 行动已结束但心理未解决 | 延迟终止、保留悬置音或让纹理继续 | 把一切尾音都当可随便剪的混响 |
| 相同主题变得疏远 | 配器、音区、完整度、伴奏与出现语境 | 只降音量却没改变关系 |
| 给关键对白留空间 | 改写同一时刻的旋律活动、配器或入退 | 只压低整条音乐，把结构一并丢掉 |

这些是候选控制变量，不是情绪配方。缺少真实音乐时只能提出比较，不能保证某一改法有效。

### 乐句完成与画面切点不一定同时发生

Phrase（乐句）是音乐中可感知的组织单位；Cadence（终止式／终止感）是形成结束或暂歇的方式。电影切镜可能发生在乐句中间，音乐也可以跨切点组织一个更大的段落。技术上平滑淡出，并不等于音乐意义已经结束；反过来，突然截断也可以有意制造拒绝、惊扰或断裂。

本库构造：人物收起一封信，音乐在他伸手前已完成安定的终止，可能提前替动作下结论；若结尾和声悬着，信收起后仍保留未决感。先决定观众何时获得“结束”的信号，再安排入退。不能只以波形没有点击、尾音足够长就判定叙事正确。

### 主题召回依赖观众经验，不是标签出现次数

主题可以通过音程轮廓、节奏、音色或和声关系被识别，不一定靠完整旋律。它第一次出现是否可辨认、与什么事件同时出现、之后相隔多久，都会影响再次出现的意义。同一段原样音乐在完全不同的场景里也可能产生反讽或重新解释；“没有改音符”不自动等于“没有发展”。

[SCGC职业指南](https://screencomposers.ca/working-with-a-composer/)支持反复运用主题材料维持全片连续；本库进一步建议比较首次、转折与末次出现时的观众已知信息，而不是强制三次出现。只有在实际看片后，才能判断观众是否接收到了设计者期待的联系。

### 撤除测试要区分必要依赖与补救性遮盖

先声明音乐在这段的职责，再比较保留、撤除或替代版本。如果歌词提供事实、角色正对音乐行动，撤掉它会主动删除叙事材料，这不是公平的“剧本独立测试”。如果音乐原本只营造氛围，却掩盖了观众不知道谁在追谁，则应回查信息设计。

一次比较尽量固定画面、对白与主要效果，只改变一个问题：入点、配器密度、终止位置或一条具体主题。音量尽量可比，但不为机械等响破坏原定前后景。记录观众“何时相信什么、何时等待什么”，比只问哪版更感人更可定位。若整体方案本来依靠歌曲完成结构，应在完整声画条件下验收，不另设无配乐硬门。

### 跨软件音乐叙事决策法

1. 接收当前CUT、故事命题、阶段3声音WIP和已知音乐前置事实。
2. 写一段全片音乐命题，标出最重要的NO SCORE区。
3. 在Rough／Fine做诊断型Spotting，只记录功能、视点、假设和music-first风险。
4. 对Temp／Reference拆解可迁移性质与禁止模仿项。
5. 比较必要声画、Temp、无音乐／不同音乐三版，路由上游问题。
6. 基于锁画或明确先行基线做制作型Spotting，为关键Cue分配稳定ID。
7. 逐Cue确定入退理由、内部轨迹、主题变化、Hit／Avoid和注意力优先级。
8. 与阶段3协商音乐桥、声音桥、边界元素和NO SCORE区。
9. 先分类审听关键Cue，再整片审听音乐弧；问题进入制作、画面、声音或撤掉音乐。
10. 输出绑定CUT的音乐决策，不宣称作曲、权利、最终混音或母版已经完成。

### 综合虚构案例：手术室外等待

画面是角色独自在手术室外等待，手机屏幕亮起又熄灭。三种方案可能产生不同叙事：

- 角色视点版：从他第一次无法拨出电话时进入不完整动机，靠近犹豫与内疚。
- 作者距离版：保持无配乐，只留空调、远处推车和呼吸，让观众不被提前告知该原谅谁。
- 关系视点版：直到门内传出动静后才进入两人共同主题的残片，音乐不解释结果，只唤回关系。

没有一版天然正确。要比较影片此刻希望观众知道多少、与角色多近，以及音乐是否抢走手机动作和门内声音的叙事功能。

### Temp Love反例

粗剪长期使用一首著名钢琴曲，剪辑点逐渐依赖其旋律和高潮。正式音乐虽然完成相同的叙事任务，却因旋律不同被评价为“不够感人”。此时不应要求复制原曲；先拆出真正需要的是延迟进入、稀疏音色、逐渐升高的和声不稳定，还是仅仅熟悉效应，再用无音乐与不同参考版检查画面是否被Temp锁死。

### 逐动作追点反例

角色起身、拿杯、转头、开门、回望，每个动作都被音乐打击命中。同步很多，却没有新的结构层级，音乐还盖住杯响和门外脚步。更有效的方案可能只在角色决定离开时改变音乐，其余动作由Foley和环境承担；或者完全无配乐，让回望成为真正重音。

### music-first案例

AI角色要在镜头内唱两句并随节拍转身。若画面先生成，再临时寻找音乐，口型、动作峰值、乐句和镜头时长很可能无法同时成立。应先确定Guide版本、速度、歌词、段落和必要同步点，交给表演与镜头生成；最终画面回来后再做音乐编辑和Conform。

## 专业职责与工具边界

下表用于说明专业职责与创作取舍。已有采用方向和本次授权直接复用；普通专业步骤由岗位处理，新的重要创作取舍随完整候选统一审阅。每一行不构成独立审批门。

| 工作 | 专业处理与候选 | 采用依据与需统一审阅的创作取舍 |
|---|---|---|
| 音乐策略草案 | 从剧本、CUT和声音WIP提取节拍、无配乐区与功能候选 | 全片音乐命题和音乐是否必要 |
| 诊断型Spotting | 建立Cue候选、版本、问题和music-first风险 | 哪些假设进入制作 |
| Temp／Reference拆解 | 分析速度、结构、音色、能量、入退及相似风险 | 真正喜欢／排斥的性质和禁止模仿边界 |
| Cue入退候选 | 提供前移、后移、撤掉、Hard／Tail Out等比较方案 | 最终入退、情感视点和余义 |
| 主题连续性 | 检查动机出现、缺席、变化和重复 | 主题代表什么、变化是否属于人物与关系 |
| 节奏与Hit检查 | 标出切点、动作、Hard／Soft Hit和Avoid候选 | 哪些点值得音乐命中，是否采用追点风格 |
| 声音协商 | 检测对白、FX、声音桥、脉冲和频段冲突 | 前景优先级、MUSIC／DESIGN责任和留白 |
| music-first预警 | 识别演唱、舞蹈、口型、歌词和节拍驱动需求 | 是否冻结Guide并返回上游 |
| 版本与表格 | 维护CUT、Cue ID、状态和差异 | 当前事实源与批准状态 |
| 审听支持 | 输出音乐／无音乐差异、可定位问题和最小修改 | 叙事、审美和残余风险 |

Agent适合扩大比较和维持系统记忆，不适合替用户决定观众应与谁站在一起。一个人兼任导演、音乐编辑和AI生成者时，应分轮次切换身份，避免“自己生成、自己证明必要、自己批准”。

## 方法摘要

### 一分钟核心摘要

影视音乐先通过Spotting回答“是否需要、承担什么、站在哪一边”，再决定Cue的入退、内部轨迹和主题变化。诊断型Spotting用于Rough／Fine探索，制作型Spotting绑定锁画或明确基线；两者是功能而非固定会议次数。Temp要拆功能并与无音乐／不同音乐比较；NO SCORE不是漏配，也不是全静音。音乐、对白和声音设计必须协商注意力，music-first段落则要把Guide提前交给上游。

### 关键概念

- 四轴：生产来源、叙事位置、制作状态、权利状态
