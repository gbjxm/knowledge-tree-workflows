# 查理老师的编剧课 - 第十七课 新手跳坑

## 本课速览

- 核心问题：初学者写完梗概、大纲或剧本后，怎样从大量作业中反复出现的共性错误入手自改。
- 主要结论：本课集中处理七个坑：选材过度自我、把苦难误当艺术、主角缺少共情与行动、对手薄弱、铺垫过量、剧情缺少事件流动、情绪色调单一。
- 修改顺序：先确认材料对陌生观众是否成立，再保住主角的目标与解决能力；随后强化对手、压缩铺垫、把对白放回事里，最后检查整部作品的情绪配比。
- 学习价值：这不是新增一套创作公式，而是把此前人物、阻力、事件、铺垫、对白和节拍知识改造成一轮可执行的编辑清单。
- 适用环节：作业自评、梗概诊断、大纲返修、初稿编辑、共情修复和节奏检查。

## 时间线笔记

### P39 十七课-新手跳坑17

#### 整体脉络

- `00:00-04:47`｜说明加课原因：编剧必须动手练习，但作业数量已无法逐份批改，因此改为提炼学员作品中的共性错误，让每个人自行对照。
- `04:47-12:01`｜第一坑，选材过度自我。新手常写自己的青春、爱情、家庭或身边朋友，却把多年关系背景带来的私人兴奋误认为公共叙事价值；陌生观众并没有同样的前提。
- `12:01-19:33`｜第二坑，把苦难、不被理解和孤独当成艺术性的证明。主角“可怜”只是共情的一部分，不能把整部作品写成连续受难；先讲好故事，并在真实苦难中寻找希望、行动或救赎。
- `19:33-28:25`｜第三坑，主角共情和行动线失守。优缺点过于抽象，最初目标不被认可，行动显得莫名或愚蠢；更严重的是核心问题最后由爱情、富亲家或天降财富替主角解决。
- `28:25-37:36`｜第四坑，对手过弱、过散或根本不存在。写实风格也需要明确阻力；训练时可先设一个具体的人，让他从主角角度“坏到家”，从自己角度又“无比正确”，并让主角最大的成长由对手逼出。
- `37:36-45:58`｜第五坑，铺垫太多。前史、童年和成长轨迹占掉大量篇幅，单场戏也总从状态进入、状态离开。铺垫应集中交代对当前行动有用的现状，然后尽快进入激励事件。
- `39:44-45:58`｜用《我不是药神》对照：店铺、父亲、儿子、前妻和前小舅子分别用约五六场交代，随后吕受益提出代购药品，故事开始。即使这是偏多的现实主义铺垫，也已接近上限且每场都有明确任务。
- `45:58-48:12`｜第六坑，剧情不流动。人物总坐下来聊天，用对白承担关系变化和重大推进；修改时应先把事件排满，让对白在行动中完成信息与关系任务，避免“状态进、状态出”。
- `48:12-53:13`｜第七坑，情绪单一。苦难片一苦到底、喜剧一路只乐都会造成体验疲劳。建议用颜色标记场次情绪，检查主色之外是否有悲伤、欢乐、紧张、平静、期待和思考的调节。

#### 详细导览

第一坑处理的是“素材真实”与“故事成立”之间的差别。亲身经历当然可以写，但创作者不能要求观众自动继承自己的情感背景。一个朋友做出普通动作之所以在熟人圈特别好笑，可能依赖几十年的性格认知和关系积累；电影若没有先建立这些前提，事情本身就未必精彩。

第二、第三坑经常连在一起：为了让主角可怜，创作者不断增加家庭、学校、社会和命运的打击，却没有给主角可认可的目标、具体优缺点和解决问题的行动。结果人物看似受苦很多，观众却无法跟随。课程要求把“错误决定”和“愚蠢决定”区分开：错误可以源于缺陷并带来成长，愚蠢则通常缺少动机、信息或因果支撑。

对手部分并不要求所有写实作品都设置脸谱化反派。更重要的是让主要阻力被具体承载，并与主角行动正面冲突。《我不是药神》的警察从主角视角看是持续阻止卖药的人，从职业立场看又是在执行法律；这种双重成立使冲突比单纯坏人更有力量。对手还应真正促成主角的最大蜕变，而不是只在外面追逐，主角却从无关支线突然悟道。

最后三坑进入编辑层：铺垫只交代当前故事需要的现状，事件负责牵引剧情，对白服务事件，情绪色块负责观众体验。它们共同解决“写了很多却迟迟不开始”“人物一直说但局面不变”“全片只有一种感受”的问题。

## 核心观点

- 私人经历不自动等于公共故事；先确认陌生观众能否在片内获得理解所需的前提。
- 苦难可以成为材料，但不能替代行动、希望、价值选择和故事推进。
- 主角的优缺点要落实为具体行为，初始目标要可理解，核心问题最终要由主角亲自解决。
- 对手应具体、主动、立场自洽，并直接逼出主角最大的成长。
- 铺垫服务现状和行动，不负责穷尽人物一生。
- 电影应由事件牵引；对白最好在事件中工作，不要独自扛起所有大事。
- 情绪可以有主色，但必须有变化、间歇和反差。

## 方法与案例

### 七坑自检表

| 坑 | 诊断信号 | 首要修改动作 |
| --- | --- | --- |
| 选材过度自我 | “只有我和朋友知道为什么有趣” | 删除私人前提后复述故事，补足片内可见的关系与事件价值 |
| 苦难等于艺术 | 主角持续受害，作品没有行动出口 | 保留必要痛点，增加欲望、选择、希望或救赎路径 |
| 主角失去共情 | 优缺点抽象、目标莫名、结局靠外援 | 把性格写成行为，让目标可认可，并让主角亲手解决核心问题 |
| 对手薄弱 | 阻力分散、抽象或只靠环境 | 先具体为一个人，建立与主角相反但自洽的行动线 |
| 铺垫过量 | 大纲前半仍在讲童年和背景 | 只留与当前激励事件有关的现状，尽早进入事 |
| 剧情不流动 | 多场坐聊，谈完局面不变 | 先设计事件和动作，再把对白嵌入事件 |
| 情绪单一 | 同一种感受连续覆盖全片 | 用颜色标场，补入必要的反差和缓冲 |

### 《我不是药神》对手案例

- 主角行动：程勇通过代购药品解决经济与病患需求。
- 主要对手：警察必须阻止非法卖药，且与主角有前亲属关系。
- 双重成立：从程勇视角，对方不断封锁行动；从警察视角，执法完全合理。
- 成长功能：阻力不能只制造追捕，还要逼主角重新选择自己为什么卖药、愿意承担什么代价。

### 铺垫压缩案例

- 《我不是药神》用不同场次分别交代经济状况、父子、父亲病情、前妻与警察关系，随后迅速进入吕受益的委托。
- 《夏洛特烦恼》直接从婚礼事件进入，人物现状则在夫妻冲突中补足。
- 两种路径不同，但共同点是铺垫不脱离当前事件，也不先完整讲完人物前史。

### 情绪色块法

1. 给每场戏标一个主要体验，如欢乐、悲伤、紧张、平静、期待、思考。
2. 把同类场次涂成同色，观察是否出现过长的单色区。
3. 保留类型主色，同时在关键节点安排反差、喘息和情绪转换。
4. 数量建议只作观察工具，不机械追求固定场数。

## 适用边界

- 本课不是禁止自传性写作，而是要求亲身经历经过筛选、结构化和陌生观众检验。
- 本课不是禁止表现苦难，而是反对用苦难姿态代替故事、人物行动和价值判断。
- 写实作品的对手可以是多个人、制度或环境；“先具体为一个人”是初学训练，不是所有成片的唯一方案。
- 前史不是绝对不能写，只有与当前现状、欲望和冲突相关时才值得占用篇幅。
- “少坐聊”不是禁止静态场面；如果一场对话本身持续改变权力、目标或风险，它仍然是事件。
- 情绪变化不能为了配色硬插段落，所有反差都要服从人物与因果。

## 可实践练习

1. 用一句话向完全不了解你生活的人复述当前故事，标出只有熟人才懂的前提，并把它们改成片内事件。
2. 写出主角最初目标、最终核心问题和亲手完成的关键行动；若最后一项属于配角，重新分配高潮责任。
3. 为主要对手分别写“主角对他的控诉”和“他为自己的辩护”，两段都要成立。
4. 把大纲前四分之一逐场标为现状、激励或推进，删除不能改变当前理解与行动的前史。
5. 给全片场次涂情绪色块，找出最长单色段，并用人物因果允许的方式增加一次变化。
