本课讨论的不是人物应该按顺序表现哪些情绪，而是故事走到不同位置时，观众为什么愿意继续看、会替谁担心、何时生气、何时获得满足。查理把这些变化画在起、承、转、合的时间轴上，再用《摇滚校园》逐段说明。

## 本课速览

这张表的对象是观众。角色处处碰壁，观众仍可能快乐；看到人物的动机和隐患，观众又会思考、担心。课堂把注意力、关心、预期、阶段满足、失望、恢复和最终兑现放在故事进程中，再另画悬念线，用《摇滚校园》解释同一事件怎样同时改变感受和隐藏风险。

## 分集脉络

P51独立构成一课：先回顾结构、元素、情感、情绪四个分析方面，并谈学习和入行；随后画出观影情绪与悬念两条线；最后用《摇滚校园》核对各阶段的作用。原视频约51分48秒，讲师在约48分59秒结束讲课，视频之后还有片例。

## 时间线笔记

### 00:00—01:12｜听懂课程以后，还要实际写

开场承接上一课分析和改写《战国》的作业。查理强调，练习是把理论变成能力的必要环节：飞行员即使理解仪表和操作原理，也需要实际飞行时间；编剧知道概念后，同样要经历足够的写作磨合。

他以“50万字”说明训练量的尺度。这是课堂的经验性建议，不是本课新布置一项必须交足50万字的作业；本课也没有为上一课的开放改写题提供唯一标准答案。

### 01:12—10:43｜四个分析方面各自在检查什么

**结构检查故事最基本的设定和对抗。** 故事属于什么类型，人物、世界和规则如何设定，谁和谁、什么和什么形成冲突，常常能用两三句话说清。查理认为，好故事的结构往往简单、干净、有力。先看这个骨架是否合理、有力量、值得讲，再考虑填入什么具体情节。

《加勒比海盗》在查理的讲述中，可以抽出“好人借助坏人去办好事”的关系：特纳想救伊丽莎白，却缺乏航海等能力，不得不借助海盗；两人立场、做法不同，因而会争执，又会因为共同敌人和共同需要重新合作。吸引力来自这种彼此需要、又互不相同的组合。他简要提到《恶人传》，也是为了比较这类好人与坏人合作的结构，并未在这里完整分析该片。

另一种关系是夹在两个阵营之间的中间人。《阿凡达》的主人公处在地球人与外星人之间；讲师也以《哪吒》的人、魔身份问题提示内外对抗。不同世界、不同人物可以沿用某种相近的结构，具体故事仍然不同。

**元素检查观众实际会看到什么。** 即使知道《碟中谍》或007的英雄大概率能战胜坏人，观众仍然会期待新工具、新障碍和具体行动：爬楼、钻地道、扒飞机，怎样做才有真实感、冲击力和新鲜感。一个“胡八一去盗墓”的设定本身有吸引力，却还需要落实成遇到什么机关、如何破解，而不能让盗墓两个字代替全部场面。

这些具体看点不全能靠结构课教出来。它们依靠想象力、观察、联想、类比，以及长期收集素材的能力；落实到影片还涉及视效、声音和表演等制作环节。讲师提醒学生自行积累和练习这些能力。

**情感关乎较深的人情联系，情绪关乎更直接的观看刺激。** 作品要检查B故事是否扎实、能否调动人类共通的情感；也可以通过害怕、紧张、欢乐或悲伤把观众吸引住。即使结构、元素和深层情感不突出，若能一直使人紧张、害怕或哭泣，讲师也认可其调动情绪的能力。

四方面都强当然理想；查理认为，有两方面做得好，作品往往就已经有基本可看性。这是他的评价经验，不是“两项达标就必然成功”的通用评分法。学生提出希望对观影情绪有更明确的安排方法，本课于是集中展开第四项。

### 10:43—16:14｜不同学习目的与入行路径

有人把编剧当职业，有人只想理解电影、发展兴趣或多学一项本领，讲师认可这些不同目的，也鼓励学生提出具体、有质量的知识问题，便于课程回应实际困惑。对于想入行、又担心没有关系和带路人的学生，他的建议是先把专业能力练出来。他认为才华和努力稀缺，真正有本领后，入行就不那么难；这是讲师对行业机会的经验判断。

讲师举了一种常见请求：学生先说免费听课让自己不好意思，随后又希望到他身边学习，只要求包吃、包住。他用这段对话说明，学生看似在谈生活安排，主要还是希望有人带自己入行；他理解这种心情，再把建议转回先学本领、拿出实际能力，而没有答应靠跟在他身边获得工作。

他提到录课时通过考试进入实验班、在了解学生能力后帮助推荐简历或作品的路径。这属于当时的课程安排，不能理解成今天仍在招生或保证推荐。

他还建议向影视公司投简历，不一定只盯着“编剧”岗位：策划、助理等工作也可能让人接触项目，展示自己会写、会导、会剪的能力。进了公司后，靠承担任务和拿出成果让别人看见自己。他用“一晚上码8000字”说明写作需要埋头投入，这种实干往往没有人抢着做；这是说明工作态度的例子，不是对所有工作设定统一产量，也不构成就业保证。

### 16:14—18:30｜先分清这张表的对象

在本课的划分中，情感较深，更多对应B故事中的内在关系；情绪较直接，更多随着A故事的外在事件起伏。板书用起、承、转、合表示进程，把观众的感受放在时间轴下方。

**这是一张观众的表。** 人物倒霉时，观众可能觉得好笑；人物信心十足地出发时，观众可能已经担心他将要受骗。因此，不能拿人物此刻高不高兴，直接替代观众的情绪判断。

查理多次限定，这些是多数商业片中常见的组织方式，不是说100%的电影都如此。

### 18:30—30:56｜观影情绪如何随故事推进

| 故事阶段 | 希望调动的观众感受 | 讲师说明的原因与条件 |
|---|---|---|
| 开场抓注意力 | 综合刺激，暂用“兴奋”概括 | 先使人愿意看下去。枪战、武戏可在观众尚未分清人物好坏时产生刺激；恐怖片也可能先让人害怕，不必都表现成快乐。 |
| 建立人物、使人入戏 | 怜、信、爱 | 让主角可怜、可信、可爱，使观众开始关心他，而不只是旁观热闹。 |
| 上路前后 | 期待、憧憬，或担忧 | 对下一步形成预期：可能变好，也可能出事。两个方向都能带来继续观看的动力。 |
| 承的前段、游戏时光 | 欢乐 | 人物进入新环境、尝试新事情，观众享受新鲜与碰撞；主角吃瘪，也可能令观众欢乐。 |
| 伙伴、爱情、试炼等继续展开 | 期待或担忧放大，进入思考 | 新关系、新道具和新行动使人进一步判断未来，也会重新考虑主角做得对不对、是否还支持他。 |
| 中点、阶段性结果 | 小满足，可带高兴、惊讶或悲伤 | 期待得到一次暂时回应；给观众想要的东西，却用未曾想到的方式给，也可能产生惊讶。 |
| 转，先前的顺利被打破 | 生气 | 发现之前的结果并不可靠，或事情根本没有解决；生气的是观众，不要求人物同步生气。 |
| 谷底、灵魂黑夜 | 难过、悲伤 | 失败和损失落实下来，前面积累的人物关系在这里产生代价。 |
| 谷底之后的反思、恢复 | 欣慰 | 看见人物舔舐伤口、积蓄力量、学到东西，使观众从难过过渡到愿意再相信他。 |
| 合，重新投入最后行动 | 激动 | 人物站起来，孤注一掷地争取目标，观众愿意跟着他冲向结果。 |
| 结尾 | 大满足，可以喜也可以悲 | 完成更大的情绪兑现；反转还可以增加惊讶，并非只有大团圆才满足。 |

开场的“兴奋”是讲师暂时概括综合刺激所用的词。他还举一些网大用性感形象吸引注意力的例子，说明吸引注意的材料未必与主线有强联系；这不等于每个故事都必须安排这类内容。真正要检查的是观众是否被吸引住。

中点的小满足和结尾的大满足不是一回事。中点的虚假胜利或虚假失败，只回答眼前的一部分期待，后面仍有变化。讲师把高兴、惊讶、悲伤都列在中点位置；他在口头举例时把“虚假胜利”和悲剧连着说，表述有松动，因此这里保留多种情绪的可能，不据此规定悲伤只能对应哪一种假结果。

**伙伴的死亡能否产生悲伤，还取决于陪伴时间。** 查理举例：从开场一直相伴的伙伴，到了约65分钟遭遇损失，观众已有较长的情感投入；若伙伴约30分钟才出现，约60分钟就死，关系积累可能还不够，这类人物通常会陪伴到更后面，甚至到结尾才面对生死。这里的分钟数是解释陪伴长度的经验例子，不是要求每部影片在固定时间让某个人死去。

**从难过到激动，中间常需要“欣慰”。** 主角在谷底稍作恢复，想通一些事，获得新的能力，观众才有理由重新期待。可以安排一场表现人物状态的戏，让他沉下心来思考，再投入反击。讲师随口用“周星驰翻秘籍、看会降龙十八掌”来比喻这种积蓄；本课没有把它作为某部电影的准确情节考据。若没有这一步，人物忽然振作去决战，情绪转折可能过急。

### 30:56—34:52｜在情绪之外，再看一条并行的悬念线

讲师在板书下方另画一行“悬”，是为了补充观众的紧张感。这条线并不只属于悬疑、侦探或谍战类型：普通商业片里，也可以有尚未揭开的危险、谎言或后果。

| 与故事进程的对应 | 悬念的推进 | 观众掌握的信息 |
|---|---|---|
| 上路前后、形成预期 | 展开 | 知道有个隐患，主角却可能还兴冲冲地前进；开始担心后果。 |
| 期待放大、开始思考 | 加强 | 出现更多危险迹象，让人怀疑前面的选择能否撑住。 |
| 生气、难过和谷底附近 | 爆发 | 一直悬着的问题真正造成损失，先前的担心兑现。 |
| 结尾 | 可以再反转 | 重新理解之前的局面，获得额外惊讶。 |

查理用一颗“炸弹”比喻这种过程：先看见它挂在那里，再看它越来越危险，随后爆开，最后还可能翻转。悬念线与上方的欢乐、思考、难过等情绪互相作用；不能只列出几个情绪名称，就认为紧张感自然存在了。

### 34:52—44:47｜《摇滚校园》怎样使这张表变得具体

查理把《摇滚校园》作为一部标准商业片，按自己记忆中的情节逐段解释。基本情境是：一个落魄摇滚乐手被乐队赶走，后来冒用朋友的身份去学校代课；发现学生会演奏乐器后，他想带孩子们组乐队参赛，赚取奖金，也向原来的乐队证明自己。

以下依照讲师的分析，区分“发生的事”和“它为什么改变观众的感受”。讲解中确有穿插原片的画中画，片段的表演和声音效果仍需连续复核。

#### 开场先使人注意，随后让人关心这个失败者

约36:44起，讲师指出影片以男主角在原乐队中的演出开场。摇滚表演像一些影片用动作场面开场一样，先给观众直接刺激，吸引注意力。

随后，主人公被乐队踢出、穷困、付不起房租，还可能失去住处，建立了“可怜”的一面。讲师又抓住一个小选择：这个人虽然有赖皮、讨人嫌之处，仍想卖掉珍爱的吉他来付房租。吉他几乎是他的生命，愿意作这种打算，使人看到他并非完全没有担当，也多了一点可爱。这里说的是他想卖，不是说课程已经交代他卖掉了吉他。

查理以人们普遍会遇到缺钱的压力，说明这种处境为何容易让观众理解人物。重点不在把主角先写成完美好人，而在于让观众看见他值得关心的地方。

#### 新工作让观众期待，也让人预感他会出洋相

约38:55起，主人公接到招聘代课老师的电话，得知薪水不错，就冒用朋友身份去上班。一个文化修养和生活习惯都与学校很不相称的地下摇滚乐手，进入规矩严整的贵族学校，立刻产生错位。

观众可以期待他会闹出什么事，也会担心他怎么教课、怎样应付其他老师。讲师用“刘姥姥进大观园”比喻这种进入陌生环境的反差。不会教数学、可能惹麻烦等说法，在这里主要用来说明观众的预期，不要把每项想象都当成影片已经发生的情节。

约40:24起，主人公在学校里不懂规矩、碰壁、出洋相，进入游戏时光。人物过得并不顺，观众却可以觉得好玩，这恰好说明表上记录的是观众情绪。

#### 从新鲜欢乐，转为判断这个人做得对不对

约41:08起，他发现孩子们会演奏乐器，产生利用他们组乐队参赛挣钱的想法。这个行动使期待和担忧放大：乐队是否能组成、学校会不会发现是一层；他为了自己的利益利用孩子，是否厚道、还值不值得支持，又是一层。观众开始思考，而不只是等下一个笑料。

约41:55起，事情暂时有了进展。他设法应付校长和家长，把教室遮起来排练，又要协调全班配合保密；孩子里也有想认真学习、不愿任他胡来的，并非全无阻力。暂时蒙混过去、排练得以进行，带来阶段性的小满足。

但到了约42:39，利用孩子赚钱的动机越来越刺眼，观众会生气；随后假身份曝光，他被开除，比赛似乎也参加不了。孩子的课业被耽误，音乐愿望又遭挫，前面看似搞定的事一起塌下来，情绪落到难过和失望。

#### 重拾真正的愿望，才有理由再次激动

约43:12起，孩子们并没有因为他被开除就放弃音乐。他们仍来找他，希望继续参加比赛。主人公也认识到，事情不能只围绕自己挣钱，孩子们的音乐梦想比他原先所图的利益更重要。观众看见仍有值得继续的东西，先产生欣慰。

约43:43起，重新行动又面对时间紧迫、参赛资格等障碍，他们仍设法赶上演出，观众由欣慰进入激动。最后表演成功，原先严肃、刻板的家长也受到感染；讲师以律师、医生等家长为例，说明孩子们的表演怎样突破成人原有的期待。

更大的满足还在于主人公找到另一种意义：他可以把摇滚传给孩子，而不只是通过比赛赚钱。课程在这里强调表演成功和人物转变，没有交代他们赢得冠军；不能自行把“大满足”补成“比赛夺冠”。

### 44:47—48:24｜同一个案例，再检查悬念怎样变化

查理随后回到板书下方的悬念线。这一遍不是简单重复剧情，而是在检查另一种观看动力：主人公的谎言什么时候会被揭穿，以及揭穿后怎么办。

1. **展开：冒名当老师。** 接下工作时，观众已经知道他不是那个被聘用的人，身份问题开始悬着。
2. **加强：把教学变成乐队排练。** 他不但冒名，还用课堂做别的事，校长和其他老师随时可能察觉，隐瞒越来越困难。
3. **爆发：被发现、被开除。** 先前埋下的风险成为实际损失，与故事的谷底相接。
4. **反转：假老师成为真的音乐老师。** 按讲师概括，结尾他成了音乐老师，不必再假装教数学或历史，可以发挥自己的音乐专长。这里保存的是讲师对结尾转变的解释；原课没有说明教师资格怎样取得，也没有具体交代原学校的聘用手续。

这部喜剧的隐患并不像谍战片那样生死攸关，紧张强度也不必相同；但悬念展开、加重、爆发和反转的机制仍可以存在。分析时应辨认它在具体故事中的形式，不必强行换成类型片里同样的危险。

### 48:24—51:47｜如何使用，以及视频还留下什么

讲师最后再次提醒，这种观影情绪安排并不覆盖所有电影，但可以用来检查自己的故事：观众的注意力从哪里来，什么时候开始关心人物，预期怎样被推动，何时得到回应，失望之后又凭什么愿意重新期待。原课没有给出能自动计算这些效果的公式，也没有为每一步规定统一分钟数。

约48:59结束讲课。宣传卡之后，约49:10起能看到《摇滚校园》的整屏演出片段，直到视频结尾。它与前文讨论的演出和观众满足有关，不能因为讲师已经说“下课”就从来源范围删除。现已核到演出画面和部分字幕，但尚未连续核清音乐、表演、观众反应与剪接怎样共同起作用；这里保留片例位置，不补写尚未核清的声画分析。

本课延续“理解之后要练习”的要求，并示范用同一影片检查情绪线与悬念线；没有另行布置带固定答案的新作业。


## 核心观点

结构、元素、情感、情绪检查的是不同方面，不能用会讲一个骨架代替具体场面，也不能用人物表情代替观众体验。情绪随事件和关系积累产生；伙伴损失需要前面的陪伴，谷底之后常需要思考与恢复，让欣慰成为再度激动的理由。中点和结尾的满足可以喜也可以悲，课堂分钟数只是讲师解释关系积累的经验例子。

悬念也能发生在喜剧中：假身份、隐患及其后果会展开、加重、兑现，结尾还可改变原来的含义。它与情绪线并行，不必把所有故事都写成谍战片，也不保证观众按表机械地产生感受。

## 方法与案例

先辨认故事让观众看见什么，再查他们为何注意、关心、期待或担心；中段回应哪些期待，谷底损失从何积累，恢复为何值得欣慰，最后怎样兑现。完整阶段表及伙伴时间例见18:30–30:56，悬念线见30:56–34:52。

《摇滚校园》把房租/吉他、冒名学校反差、组乐队的利益动机、保密阻力、曝光失业、孩子仍来找和演出成功串起来；逐阶段解释及再查假身份悬念见34:52–48:24。表演成功不等于课堂已讲比赛夺冠，成为音乐老师也不等于已核原校正式聘用。
