## 速览

- 核心问题：零基础学习者怎样把编剧当作可训练手艺，持续获得并检验创作材料；一个模糊灵感又怎样成为完整、可看的故事，让主角带住观众、配角服务行动线，再经过类型、结构、场景、对白和修订检查变成能拍、能持续推进的剧本。
- 主要结论：学院理论与速成公式都只是工具，必须由真实写作验收；影视作品与生活观察组成双源素材本，共情和真实幻想把材料变成可进入的人物处境。此后由八要素保证完整，故事支点与类型发动机制造吸引力，人物、结构、场景与对白把抽象判断翻译成可执行事件。
- 学习价值：P2-P41 连成一条完整工作链：实战学习与双源素材 → 共情与真实幻想 → 灵感素材化 → 三要素与八要素 → 提高烈度 → 找故事支点 → 区分主题与结果 → 剧本格式 → 梗概事件化 → 十序列大纲 → 主角共情与多主角判别 → 类型发动机与同母题迁移 → 剧集编织 → 场景与对白 → 十五节拍与 A/B 故事 → 悬念反转 → 七坑返修 → 开场选择。
- 最重要的方法：以能否写出或改好具体文本验收理论与公式；同时记录影视素材与生活素材；换到他人的资源、压力和代价中练共情；诚实展开真实幻想；再用始于心、成于脑、负价值定语、原始欲望、及物动作、持续悬念、分层阻力、绕过动作实现欲望、拿事说话、虚假胜利、原罪回收和三面共情推进故事。
- 最适合应用的环节：编剧入门与学习校准、素材积累、人物视角训练、从零找故事、检查故事完整性、把平庸故事做出支点、把梗概扩展为可拍大纲，以及检查主角群、类型承诺、剧集长线、场景效率、对白行动、信息差、结构低谷与开场策略。

## 课程总览

P2-P41 不是互相独立的知识点，而是一条从学习准备、素材积累到故事和剧本，再从单线进入复杂结构、媒介适配与修订的连续路径。P2-P4 先解决“编剧能否训练”和“从哪里持续获得材料”：学院理论与速成规律可以共同使用，但都要由真实写作验收；影视作品与生活观察组成双源素材本，共情练习帮助进入他人处境，真实幻想作业则把抽象愿望展开为用途、关系、代价与可见动作。

P5-P6 接着解决“故事从哪里来”和“怎样保证故事完整”：灵感来自自己的欲望、恐惧以及对他人的共情，随后用人物、事件、主题三要素和身份、欲望、动作、问题、阻力、结果、正价值、负价值八要素把材料组织成故事。

P7-P10 再解决“完整为什么仍然不好看”。课程把八要素逐项增强：身份加入负价值定语，欲望要原始到“猴子也能听懂”，动作必须具体，问题要维持悬念，阻力从环境、对手、自我三层递进，结果最好绕过动作实现欲望。创作没有起点时，可以从身份、激励事件、过激行为、悬念、环境五个故事支点中任选一个突破；但创新必须和观众预期保持张力，不能八项全部反常。

P11-P13 处理两个常见误区。第一，主题的“正义”不等于结局必须圆满：坏人可以没被抓、主角可以失败或死亡，但作品最终肯定的价值仍要清楚。第二，剧本格式只是协作接口，不能代替故事能力；场号、场景、时间、内外景以及描述、行动、对白，都是为了让各部门读懂并执行。

P14-P17 把故事从梗概推到大纲。梗概可以用一千到两千字讲清八要素，正式剧本要落实到场景、动作、对白、节奏和格式，大纲则是二者之间的施工图。课程用“想殉职的警察”示范：十个序列做横轴，八要素做纵轴；主角从逃避责任、以殉职换补偿，走到虚假胜利、原罪反噬，最后以真正承担责任的行动回答主题。

P18-P19 在大纲骨架之后集中深化人物。主角不是戏份最多或最显眼的人，而是持续推动故事、带观众经历故事的人；共情要从身份、欲望、动作三面维持。配角不应先写一堆小传，而应从序列事件的功能需求中产生，再合并功能相近者并补一个鲜明记忆点。人物关系图记录配角对主角行动线的推力或阻力，人物弧光则用来检查主角从起点到终点是否发生了有层次的成长。

P20-P27 把单主角基础扩展到复杂叙事与类型迁移。复杂结构先按人物、事件、视角、时间四轴还原；复合型主角、团队主角和真正双主角要靠独立目标、激励事件、选择链、代价结果和人物弧线区分。随后课程把商业／文艺、市场标签和故事发动机分成三个分类轴，用十类型的最低承诺检查路径、关系、秘密、规则、空间、选择与牺牲，并用《小蝌蚪找妈妈》证明同一母题换类型时必须连人物、因果、语气和结局一起改变。

P28-P37 转向长篇、场景和结构执行。电视剧采用“整体编人物，单集编事件”：主线让主角群相生，副线让关系相克，全剧人物表负责长线，单集事件负责可见行动。场景以“扛事”为标准，检查信息、推进、变化、对抗、进出和效率；对白则通过分角色单写、素材库、问答陷阱、潜台词和角色日记摆脱作者统一口吻。十五节拍把十序列进一步细分，并用 A/Want 与 B/Need 同时追踪外在任务和内在成长。

P38-P41 提供一轮修订和入口检查。悬念由未知性、可能性和压迫感构成，底层是角色与观众之间的信息分配；反转则通过误导或暂扣关键事实打破预期。七项新手坑列出选材、苦难、主角、对手、铺垫、事件流动和情绪配比七类共性问题；课堂讲授顺序不等于固定返修优先级。开场最后回到项目选择：常规建制可以从世界、人物、现状或代表性场面抓人，非常规开场则可提前激励事件、前史、结局／大悬念或中段代表场面，但被延后的因果必须补回。

## 核心观点总览

- 编剧是一门可以学习和训练的手艺；天赋、学历和文学功底会影响路径，却不是开始写作的唯一许可。
- 学院理论提供基本功与解释框架，速成公式提供结构提示；两者都必须回到具体文本，以能否帮助写出、改好剧本来验收。
- 素材同时来自优秀影视作品与真实生活；前者扩展间接经验，后者保留直接观察，记录时都应抓动作、台词、关系和变化，而不是照搬情节或暴露隐私。
- 共情是把自己放进对方的资源、压力、目标和代价中重做一次选择，不等于认同；真实幻想则应诚实展开成用途、关系变化、风险与可见动作，作为后续故事加工的原材料。
- 灵感不是神秘天赋，而是被记录和加工的欲望、恐惧、观察与共情；故事“始于心，成于脑”。
- 三要素与八要素解决完整性，故事支点与烈度设计解决吸引力，两者不能互相替代。
- 一个故事至少要有一处强支点：身份、激励事件、过激行为、悬念、环境都可以成为下手点。
- 人物欲望要下钻到可感知的原始需要，动作要具体，阻力要从环境、对手进入自我，悬念则不能中途断掉。
- 最好的结果常常不是“动作成功”，而是人物绕过原计划，以更深的方式实现或重新理解真正欲望。
- 主题的正义与结果的正义必须分开：外部可以失败，作品最终肯定的价值仍应通过人物变化落地。
- 剧本格式是跨部门协作接口，不是故事能力；场号、场景、时间、内外景、描述、行动和对白都服务可执行性。
- 大纲是从梗概到剧本之间的施工图，不是拿去出售的包装材料。
- 梗概可以概括，大纲必须事件化；抽象判断必须变成环境、动作、对白和场面。
- “拿事说话”的意思是让观众通过具体事情判断人物，而不是让作者替观众宣布人物。
- 画面感不是华丽描写，而是可执行信息；能被拍、能被演、能被剪，才是大纲里的画面。
- 十个序列是一组训练用结构关节，不是固定神圣公式，也不是十场戏。
- 八要素不能只在梗概里列一次，而要在每个序列里持续变化。
- 配角不是越早越多越好，先抓主角，配角从主角要处理的事件中自然长出来。
- 主角由主动力和行动力定义，并承担观众视角；共情不是让人物完美，而是让观众理解其欲望并愿意继续跟随。
- 身份用“可怜、可信、可爱”缩短距离，欲望用原始需要降低理解门槛，重大动作则要取得观众许可。
- 配角要带着事件功能出场，完成大纲后再合并同类功能并补鲜明记忆点；人物关系要同时标记身份关系和对主行动线的推力／阻力。
- 人物弧光首先是主角成长的检查工具，不是要求每个角色都完成一百八十度变化的硬指标。
- 复杂叙事先还原人物、事件、视角、时间四轴；人物多、剪辑快或倒叙都不自动等于多主角或非线性。
- 第二主角必须拥有独立目标、激励事件、持续选择链、专属代价与结果、可辨认弧线；共享任务的多人也可能只是团队主角。
- 类型至少分创作取向、市场承诺和故事发动机三个轴；十类型只提供专项检查，不能替代八要素和结构。
- 同一母题迁移类型时，必须同步改变人物缺陷、伙伴功能、世界规则、对手、价值选择和结局，而不只是更换外观。
- 电视剧要“整体编人物，单集编事件”：共同目标保证主线相生，私人欲望与关系冲突让副线相克。
- 场景必须承担信息、推进或变化，并尽量从有效动作进入和离开；对白要贴人物、贴情境，并以潜台词完成行动。
- 十五节拍是更细的结构提示表；A/Want 追踪外在任务，B/Need 追踪内在成长，两线应尽量在同一事件中共同推进。
- 悬念依靠未知性、可能性与压迫感，底层是角色和观众之间的信息差；反转必须回头解释前文，不能靠伪造因果。
- 新手返修可从选材的公共可理解性、苦难、主角、对手、铺垫、事件流动和情绪变化七类问题检查，不能把苦难或台词密度当作故事；修改先后应按当前问题及其依赖判断。
- 开场强度服从媒介、题材和气质；非常规开场只是调序，必须把被延后的世界、人物、现状与因果补回。
- 中段胜利常常可以设计成虚假胜利：外部状态改善，但内在问题没有解决。
- 后半段真正有力的打击最好来自主角自己的原罪，而不是随机空降的坏事。
- 高潮要回答主题问题；动作场面只是外壳，人物是否完成内在转变才是核心。

## 从灵感到完整故事

### 灵感的两个来源

1. **自己的肉身经验**：欲望、恐惧、羞耻、遗憾和“如果当年”的幻想。这些材料最容易带出真实情绪。
2. **对他人的共情**：观察别人渴望什么、害怕什么、怎样保护自尊，再把这种处境转化为自己可以理解的内部经验。

灵感进入故事前，先建立素材包：围绕一个欲望，把相关记忆、现实观察、可能代价、相反力量、人物关系和最害怕发生的结果列出来。单一愿望是向上的力量，恐惧、代价或秘密提供向下的力量，两者相撞才形成最小冲突。

### 三要素与八要素

| 大要素 | 小要素 | 写作检查 |
|---|---|---|
| 人物 | 身份、欲望、动作 | 他在这个故事中的关系位置是什么？真正想得到什么？为此具体做什么？ |
| 事件 | 问题、阻力、结果 | 核心悬念是什么？哪些力量阻止他？最终局面怎样改变？ |
| 主题 | 正价值、负价值 | 两种价值怎样通过选择角力？作品最终肯定了什么？ |

八要素连起来应形成因果，而不是人物卡：某种身份的人产生欲望，采取动作解决问题；环境、对手和自我构成阻力，行动得到结果，正负价值的较量随之落地。

### 八要素的烈度增强

| 要素 | 课程方法 | 需要避免 |
|---|---|---|
| 身份 | 加一个可信的负价值定语，再讲给朋友听，看他是否追问 | 只为猎奇而失去可信度与共情 |
| 欲望 | 用“猴子测试”下钻到生存、爱、保护、复仇、地位等原始需要 | 把“正义、成功、成长”当成已经足够具体的欲望 |
| 动作 | 使用明确及物动词：抓谁、救谁、偷什么、夺回什么 | 只写想法、态度和状态 |
| 问题 | 保持悬念不断，并逐步增强；可以换问题，但不能让观看动力消失 | 中段把核心问题解决后另开一部戏 |
| 阻力 | 环境 → 对手 → 自我，三层叠加并逐渐内化 | 只有一个坏人反复拦路 |
| 结果 | 绕过动作实现欲望，让人物得到更深层答案 | 动作成功就直接等于故事完成 |
| 主题 | 让正负价值在行动与代价中角力 | 用台词宣布价值，或把圆满结局误当主题成立 |

### 五个故事支点

1. **身份**：一个反常但可信的人物设定，例如“迫切想殉职的警察”。
2. **激励事件**：小人物遇大事，或大人物遇小事；关键是事件迫使人物改变日常状态。
3. **过激行为**：惯常动作失败后的第二次行动，例如没考上大学后直接造一所大学。
4. **悬念**：灾难、假身份、秘密、时间锁或未解问题形成持续的“炸弹”。
5. **环境**：空间本身提供规则、限制与反差，例如荒岛、精神病院、封闭修道院。

一个强支点足以开始故事，两个支点开始产生鲜明性。课程建议保持“一半海水，一半火焰”：部分要素兑现类型承诺与观众预期，部分要素负责创新；如果八项都反常，故事反而失去辨识度。

### 主题正义与结果正义

结果回答“人物最后赢没赢”，主题回答“作品通过整个过程肯定了什么”。《杀人回忆》中真凶没有被抓，案件结果令人挫败；但两个警察从互相否定走向彼此影响，最终交换立场，人物成长与作品对人的审视仍然成立。这个区分允许悲剧、开放结局和黑色结局存在，也要求创作者别把“坏人受罚”误当成唯一的价值表达。

> [!warning] 适用边界
> “主题必须正能量”是查理老师的教学主张。更稳妥的调用方式是：作品最终肯定或拷问的价值必须清楚，并通过行动与代价成立；不必把它机械理解成圆满结局、道德说教或单一价值答案。

## 剧本格式与协作

- 场景标题的基本信息是场号、场景、时间、内外景；它们帮助制片、场地、灯光和拍摄部门拆解工作。
- 场景正文由描述、行动、对白组成。描述交代当下可见状态，行动写人物具体行为，对白是人物行动的一部分。
- 场景边界以行动和阅读清晰为准。电话两端、办公室与相连阳台不必为了地点变化机械切成许多场。
- 好莱坞“一页约一分钟”与英文排版软件有关，中文信息密度更高，不宜机械照搬。课程给出的粗估是约 350 字一分钟。
- 120 分钟电影常见七八十至九十场，但动作和追逐可能少量文字对应较长成片；格式与字数都只是规划工具。
- 剧本写到镜头和演员调度时，往往已经进入拍摄脚本或导演工作范围；文学剧本优先交代能推动事件的可执行信息。

## 核心概念

### 梗概

梗概通常在一千到一千五百字左右，用来说明故事基本形态：主角是谁、想要什么、遇到什么阻力、发生什么变化、故事大致如何结束。梗概可以保留较多判断性语言，例如“他很落魄”“他们关系破裂”“他终于获得救赎”。

梗概的危险是太顺。它可能读起来像故事已经成立，但很多信息还没有被转换成可以拍的东西。写作者如果直接从梗概跳到剧本，容易一边写对白一边补因果，一边写场景一边发现人物动机不够。

### 大纲

大纲通常一两万字，是从梗概进入剧本前的施工图。它要把抽象判断翻译成具体事件：人物在哪里，做什么，不做什么，别人怎么反应，信息如何被看见或听见，冲突如何递进，场面承担哪个结构任务。

大纲不是给别人看热闹，也不是为了卖钱，而是创作者自己控制故事的工具。它应该帮助你看见缺口：哪个序列没有任务，哪个人物变化没有事件支撑，哪个情绪转折过快，哪个主题没有在动作里兑现。

### 剧本

剧本要进一步落实成场景、动作、对白、节奏和格式。剧本阶段会出现大量细节诱惑：一句好台词、一个漂亮场面、一段有趣调度，都可能把写作者带偏。大纲的作用就是先把骨架和因果立住，让细节服务整体。

### 拿事说话

“拿事说话”是这三集最重要的方法。它不是“多写事件”，而是把人物性质、关系状态、主题判断都交给事件表达。

错误写法：

- 他是一个冷漠的人。
- 她内心很痛苦。
- 这对夫妻貌合神离。
- 这个男人想重新做父亲。

大纲写法：

- 他看到身边有人被欺负，对讲机也响了，但他关掉对讲机继续喝酒。
- 她想说话，最后只是把电视声音调大。
- 两人坐得很远，桌上有摔过没收的杯子，客人进门后也不敢寒暄。
- 他拿着女儿学费单站在门口，发现女儿已经更信任另一个男人。

### 画面感

画面感不是漂亮修辞，而是可执行信息。大纲中的画面感要让人知道怎么拍：空间关系、道具状态、动作过程、对白功能、沉默意义、人物进退、视线方向、信息揭示顺序。形容词越多不代表越有画面，能被执行才算有画面。

## 十个序列

| 序列 | 功能 | 写作任务 | “想殉职的警察”示例 |
|---|---|---|---|
| 1. 开场 | 让观众进入世界，建立主角初始状态 | 用一件事同时交代职业、处境、缺陷和故事语气 | 夜市喝酒，目睹流氓欺负摊主一家，对讲机响起仍不管 |
| 2. 切入 | 延续设定，为激励事件铺垫 | 继续压主角，让关键需求浮出水面 | 宿醉后找前妻和女儿，被新伴侣家庭替代，又拿不出学费 |
| 3. 激励 | 核心问题发端 | 让主角产生新的欲望或解决方案 | 警局捐款让他意识到殉职能给家属带来抚恤金和荣誉 |
| 4. 进展 | 第一次行动，通常按错误动机推进 | 让主角用错误方法解决问题，并制造反讽 | 他反复冲向危险任务，想死却阴差阳错救人 |
| 5. 转折 | 重要局面改变 | 给主角一个看似有效的新状态，但不解决根本问题 | 他因“英勇”受表彰，甚至转正，获得虚假胜利 |
| 6. 再转 | 戳破虚假胜利，逼主角调整 | 让人物发现外部胜利无法解决内部问题 | 家庭仍不认可他，当初放走的人又犯重罪 |
| 7. 危机 | 最大考验或最痛位置 | 把人物推到必须面对核心问题的位置 | 他意识到自己仍是假丈夫、假父亲、假警察，决定承担后果 |
| 8. 导入 | 增强高潮前的情绪烈度 | 加倒计时、暴露、削弱装备、强化对手或压缩选择 | 对手提前知道他要来，炸弹或枪出现故障，局势更难 |
| 9. 高潮 | 核心问题解决 | 让人物用行动回答主题问题 | 他扑向罪犯，不再为逃避而死，而是为责任行动 |
| 10. 结局/收束 | 安放观众情绪 | 根据故事气口选择悲剧、温情、喜剧或反讽 | 牺牲后的追悼会，或重伤醒来听见女儿夸他是英雄 |

十个序列不是十场戏。序列是大的结构关节，每个关节可以包含多场戏。比如“激励”不是只有“捐款”一个动作，它可以包括回警局、被训、听同事议论、被要求捐款、想躲、被发现没捐、听到抚恤金信息等一组场面。

## 八要素如何进入大纲

课程里的八要素可以理解为纵轴。梗概阶段可能只是列出它们，大纲阶段则要让它们在十个序列中发生变化。

| 八要素方向 | 在大纲里的作用         | 检查问题                  |
| ----- | --------------- | --------------------- |
| 身份    | 主角如何从初始身份走向真正身份 | 他在每个关节中“是谁”的状态有没有变    |
| 欲望    | 主角想要什么，以及欲望如何转向 | 欲望是逃避、求生、求钱、求认可，还是承担  |
| 动作    | 主角实际做了什么        | 有没有只写心理，没有写行动         |
| 问题    | 这一阶段要解决的外部和内部问题 | 问题是否越来越具体             |
| 阻力    | 谁或什么阻止主角        | 阻力是否随故事升级，而不是重复       |
| 结果    | 每个序列结束后局面有什么变化  | 有没有“发生了很多事但局面没变”      |
| 正价值   | 故事要推向的价值        | 责任、承担、真正的父亲、真正的警察如何出现 |
| 负价值   | 主角初始或对立价值       | 逃避、不负责、假身份、用死亡逃债如何被暴露 |

把十个序列作为横轴，八要素作为纵轴，就得到一个大纲检查表。这个表不是为了填满格子，而是为了逼你发现：人物身份在哪里变化，欲望在哪里转向，动作是否真的推动问题，主题是否在事件里被兑现。

## 案例结论：想殉职的警察

- **反常起点**：一个因未能保护女儿而愧疚的警察，试图通过殉职去天堂继续保护她。
- **错误欲望**：他把死亡当作逃避现实、留下抚恤金和重新获得家人认可的办法。
- **进展反讽**：越想死越立功，外部身份不断上升，内部责任问题却没有解决。
- **虚假胜利与原罪回收**：表彰和转正把他抬高，开场不作为造成的后果再把假英雄状态打碎。
- **高潮回答**：他最后面对死亡不再为了逃避，而是为了真正承担父亲、警察和人的责任。

## 从人物共情到人物弧光

### 主角：推动故事并带住观众

判断主角优先看两件事：谁持续作出决定并推动局面，观众主要跟随谁经历情绪和信息。片名、演员咖位、外形、戏份多少通常与主角重合，但都不是定义。激励事件之前主角可以被动，事件之后必须逐渐掌握行动，否则故事会失去发动机。

主角也是观众的视角载体。共情最低限度不是“我赞同他”，而是“我理解他为什么这样做，也愿意看他是否成功”。共情必须贯穿行动线，不能只在开场用一次悲惨身世换取同情，后面却让人物无缘无故做出观众无法理解的选择。

### 三面共情检查

| 人物维度 | 加强方法 | 写作检查 |
|---|---|---|
| 身份 | 可怜、可信、可爱 | 处境是否让人同情？再强的人是否有缺陷或坏习惯？观众是否看到一件值得爱他的具体小事？ |
| 欲望 | 下钻到原始需要 | 不依赖专业背景，观众能否立即理解他为什么非要得到、保护或逃离？ |
| 动作 | 取得观众许可 | 尤其当人物越界时，前文是否给出了走投无路、对方恶行、人物善意或其他足够因果？ |

“可怜、可信、可爱”不是必须全部堆在第一场。弱者开场已经获得大量同情时，不必机械再安排“救猫”；强人开场离观众较远，则更需要缺陷、善意或危险处境。明星的既有公众形象可以替角色预支共情，但剧本开发不能把它当作结构条件。

### 英雄片的极限平衡

课程把英雄片拆为四项：技能、命门、对手、使命。技能越超常，越需要致命命门暴露脆弱；英雄越强，越需要旗鼓相当的对手制造真实危险；人物的私德可以复杂，使命却必须足以让观众理解他为什么值得跟随。可把它作为强人角色的压力测试，不必当成所有类型的固定配方。

### 配角：从事件功能中产生

1. 先写主角和序列事件，不在故事尚未成立时堆配角小传。
2. 某个事件需要帮助、阻碍、信息、见证、受害或选择压力时，让配角带着该功能出场。
3. 大纲跑通后列出全部配角，把功能、职业或属性相近者合并。
4. 尽量让留下的配角跨越多个序列，使他能累积关系、变化和记忆。
5. 最后增加一个能通过行动表现的习惯、偏执、仪式或反差，不把残疾当成廉价标签。

配角的判断标准不是“人物小传写得多完整”，而是他是否改变主角的行动条件。没有功能就不必进场，功能相近就考虑合并；少而精通常比每场出现一个新角色更容易形成关系和变化。

### 人物关系图：身份关系加作用力

人物关系图以主角和核心行动为中心，每条线至少写两项：社会或情感关系，以及对主角当前目标的作用力。作用力可以是推力、阻力，也可以在故事中改变方向。只与某个配角背景有关、却不直接影响主角行动的人物，可视为局部叙事工具，不必继续扩写第二层背景。

### 人物弧光：把变化落进事件

先写主角第一场的起点和最后一场的终点，再检查两端是否足够远；随后在中间事件中标出若干渐变点，让每一次选择都比上一次更靠近终点。人物弧光不是一句“他成长了”，而是缺陷、选择和代价逐步变化的轨迹。

边界也要保留：系列探案、章回体和情景喜剧常依赖稳定的人设与关系循环，不必每集完成不可逆的大弧光。配角从帮助转为背叛，或从阻碍转为支持，也可能只是功能和立场变化，不一定需要完整成长史。

### 角色命名

名字在人物和事件大体稳定后再定。先检查时代、地域、阶层、家庭文化和阅读辨识度，再追求独特。一个实用办法是从普通白话文本里挑“常见易读、但较少用于姓名”的字，避免生僻字、偶像剧式同质化和为了显得特别而脱离人物背景。

## 跨课模型

### 从可训练手艺到可加工材料

编剧作为可训练手艺，意味着学习不能停在学院理论的术语体系，也不能把速成公式当作固定答案：前者提供基本功与解释框架，后者提供结构提示和快速诊断，最终都要由一段真实写作或修改结果验收。稳定的训练入口是同时维护影视作品与真实生活两类素材，前者扩展未亲历处境，后者保留动作、语言、关系和情绪的直接证据；遇到冲突时，再从对方的资源、压力、目标和代价重做一次选择，把共情与认同分开。真实幻想作业则要求先诚实写下愿望，再展开用途、关系变化、风险和可见动作；这样得到的不是现成故事，而是一份能继续进入欲望、恐惧、八要素、人物行动与主题选择的原始材料。

### 复杂叙事四轴与多主角判别

复杂叙事不是一个单独公式，而是人物、事件、视角、时间四个变量同时增加后的管理问题。先分别检查：

| 轴 | 核心问题 | 常见假复杂 | 真正增加的任务 |
|---|---|---|---|
| 人物 | 谁持续决定、行动并承担后果？ | 演员多、性格多、短暂离队 | 多套独立目标、激励、选择、代价和弧线 |
| 事件 | 所有支线围绕哪一件大事汇合？ | 反派各有戏份就当成多主线 | 数条事件线都能独立改变全局，并彼此形成因果 |
| 视角 | 观众跟随谁，又比谁知道得更多？ | 快速切换镜头就叫多视角 | 信息位置改变悬念、共情和戏剧性反讽 |
| 时间 | 因果被打散，还是只调整了呈现顺序？ | 把结尾放到开头就叫非线性 | 不同时间线彼此补充、遮蔽或改写因果判断 |

多主角不能按戏份或角色数量判断。逐个候选人物检查五项：独立目标、独立激励事件、持续选择链、专属代价与结果、可辨认人物弧线。多人共享一个目标、主要视角和整体成长时，可以按复合型主角或团队主角处理；真正双主角即使共享场面，同一事件也应在两条弧线中承担不同功能。稳妥的双人物基础版是“两条弧线、一个主要视角、一个共同事件”，只有信息体验确有需要时再增加双视角。

复杂外观也可能由单线生长出来：先保留一个主角和核心目标，再把笼统阻力拆成数股力量，使它们提前出场并以物件、地点、关系或因果债务横向连接。随后用“角色 × 秘密”信息矩阵记录谁知道、谁误会、观众知道什么。每增加一次巧合，都要检查它是否只负责让人物相遇，还是替代了本应由选择完成的关键因果。

### 十类型故事发动机

类型至少有三个不同轴：商业／文艺偏向创作目的，动作／爱情／恐怖等市场标签管理观看承诺，金羊毛等十类型则描述故事靠什么持续发动。十类型不是互斥分类，而是八要素和结构之上的最低承诺检查：

| 类型 | 发动问题 | 最低承诺 |
|---|---|---|
| 金羊毛 | 人物怎样抵达目标并在旅程中变化？ | 路径、团队、奖品 |
| 伙伴之爱 | 为什么非对方不可，又为何不能结合？ | 双方残缺、相互补足、巨大沟壑 |
| 超级英雄 | 超常能力为何值得观众跟随？ | 能力、命门、对手、使命 |
| 鬼屋 | 人物为何逃不掉，又为何必须面对威胁？ | 封闭空间、致命力量、原罪或因果 |
| 侦探推理 | 究竟发生了什么，真相会伤害谁？ | 秘密、探秘者、牺牲或价值选择 |
| 如愿以偿 | 愿望成真后为什么不能一直享受？ | 共情愿望、规则／咒语、教训 |
| 麻烦家伙 | 普通人为何被迫采取非常行动？ | 无辜小人物、突降大事、生死考验 |
| 人生变迁 | 人物怎样停止逃避一个常见人生问题？ | 日常问题、错误处理、连锁后果、成熟回归 |
| 愚者成功 | 不适应规则的人怎样进入强机构而不丢掉自己？ | 愚者、机构／环境、伪装变化、真实转变 |
| 被制度化 | 个体如何在群体规则与自我之间选择？ | 群体、个人选择、抗争或牺牲 |

同母题迁移不是给原故事换职业、时代或美术皮肤。先保留主角、外部动作、真正欲望和核心价值，再选主类型，重写人物缺陷、伙伴功能、世界规则、对手和价值选择；最后用八要素与结构重新验证。动作是人物打算做什么，欲望解释为何非做不可，结果回答计划是否完成，奖励则是人物真正获得什么。好的迁移允许“动作失败、欲望以更深方式实现”。

### 十五节拍、A/B 故事与 Want/Need

十五节拍把十序列进一步细分为结构功能，不是新的唯一真理。开场画面、点主题、铺垫、推动、争执和第二幕衔接点建立旧世界与上路；B 故事、游戏时间和中点让外在任务与内在缺失同时显形；坏蛋逼近、一无所有和灵魂黑夜完成反噬与消化；第三幕衔接点、高潮和终场画面则用改变后的行动回答主题。

A 故事追踪人物意识到并主动追逐的 Want，B 故事追踪人物未必自知却必须补足的 Need。A 可以成功而 B 失败，形成空洞胜利；A 也可以失败而 B 完成，使人物得到更深结果。B 常由爱情、友情、亲情或伙伴关系承载，但不等于必须有感情线。一场有效事件最好同时改变任务进度和人物信念；若 B 线只能被概括成“他成长了”，就要逐场补出反馈、选择和行为变化。

中点的伪胜利应形成四步反噬链：获得阶段成果 → 误以为旧信念正确 → 为保住成果伤害关系或作出错误选择 → 该选择在坏蛋逼近和一无所有中兑现代价。外部重创之后还要留出灵魂黑夜，让人物真正消化失败；第三幕办法则应来自已经铺垫的能力、关系或人物终于接受的困难道路。

### 悬念、信息差与反转

悬念由未知性、可能性和压迫感组成。未知性要形成一个具体问题；可能性至少提供两个有证据的方向；压迫感规定不回答会付出什么代价。大悬念维持全片，中悬念维持一个序列或段落，小悬念负责眼前动作，三者可以嵌套，但不能把密度当成固定计时表。

信息差有三种：角色知道而观众不知道，观众知道而角色不知道，观众与角色都不知道。第一种让观众追问人物为何改变，第二种产生替角色着急的戏剧性反讽，第三种让双方共同调查。反转则有两条主要路径：组织可见信息形成合理误判，或暂扣一个足以改判的关键事实。揭示之后必须能解释前文，最好还能让早先细节获得新意义。

## 跨课方法

### 电视剧：整体编人物，单集编事件

1. 先按观看主动性、单次时长、商业模式和终端体验选择连续剧、单元剧、情景剧、限定剧或混合形态。
2. 建立“人物 × 集数”全剧表：每人写起点、终点、激励、阻力、选择、转折、危机和高潮。
3. 给主角群一个共同目标，让资源和能力彼此补足；另设人物关系曲线，记录结盟、分裂、误会、修复和权力逆转。
4. 使用“主线相生，副线相克”：共同事业迫使人物合作，爱情、家庭、忠诚、利益或成瘾不断改变合作方式。
5. 纵向切出单集人物任务，把它们压成两至三条有行动、冲突和结果的事件线；一个事件尽量同时完成人物登场、激励、选择和关系变化。
6. 每次重复激励、阻力或转折都必须改变方向、关系、代价或人物状态。连续剧补单集看点，单元剧补长期秘密或关系暗线。

### 场景检查与对白五法

场景是结构的执行单位，分场依据是完整故事场面，不是地点清单。每场先写一句“这场要办什么事”，再检查：

| 检查项 | 核心问题 | 常用修改 |
|---|---|---|
| 信息 | 观众得到什么有效信息？ | 分配给环境、动作、对白，删除无用背景 |
| 推进 | 怎样完成所属序列任务？ | 增加代价、减少退路、改变行动方向 |
| 变化 | 场尾与场头相比什么不同？ | 加入发现、选择、失败、获得或反转 |
| 对抗 | 环境、对手或自我阻力在哪里？ | 让阻力进入当前动作，不强行争吵 |
| 进出 | 是否停在静态说明和收尾？ | 从改变局面的动作进入，在最后一个有效动作后离开 |
| 效率 | 是否只为一条信息单独搭场？ | 迁移有效信息，合并或删除低价值场次 |

对白五法依次是：分角色单写，先进入一个人物再写另一个；建立地域、职业、年龄和关系位置的真实语言素材库；圈出连续问答，避免人物替作者搬运背景；先写“试探、炫耀、羞辱、控制、求助、遮掩”等潜台词动作，再翻成明台词；让主要人物分别写同一事件的角色日记，以注意点、称呼和自我辩护的差异形成声音。好对白优先贴人物或贴情境，经典感是结果，不是修辞指标。

### 七项新手坑

下表把原课七类问题转成便于使用的自检工具，诊断措辞和修改动作含整理者归纳，不逐项等同于老师原授；具体案例、条件和原课练习见[[17 - 第十七课 新手跳坑（P39）|新版第十七课]]。

| 坑 | 诊断信号 | 可考虑的修改动作 |
|---|---|---|
| 选材过度自我 | 只有作者熟人知道为什么有趣 | 删除私人前提后复述，补片内可见的关系与事件价值 |
| 苦难等于艺术 | 主角持续受害，没有行动出口 | 保留必要痛点，增加欲望、选择、希望或救赎路径 |
| 主角失去共情 | 优缺点抽象、目标莫名、结局靠外援 | 把性格写成行为，让主角亲手解决核心问题 |
| 对手薄弱 | 阻力分散、抽象或只靠环境 | 先具体成一个主动、立场自洽且能逼出成长的对手 |
| 铺垫过量 | 前半仍在讲童年和背景 | 只留与当前激励有关的现状，尽早进入事件 |
| 剧情不流动 | 多场坐聊，谈完局面不变 | 先设计事件和动作，再让对白在事件中工作 |
| 情绪单一 | 同一种体验连续覆盖全片 | 给场景标情绪色块，补有因果的反差与喘息 |

一种可选的整理者工作法是：如果陌生观众无法进入故事、主角也缺少有效行动，可先检查公共可理解性和主角行动，再处理与它们相关的对手、铺垫、事件流动和情绪问题，避免仅靠精修对白掩盖根因。具体优先级随问题依赖调整；这不是原课规定的固定返修顺序。

### 四种拿人开场

先判断项目是否真的需要更强开场：媒介给观众多少耐心，明星、IP、类型或世界观是否已经提供吸引力，作品是否主动追求平静写实，以及常规建制里是否已有足够有力的场面。常规开场可从世界、人物、现状和代表性建制戏四个抓手进入。

需要调序时有四种方法：

1. **激励事件提前**：先交付强事件，随后补回人物现状、事件意义和世界规则。
2. **前史开场**：只选会持续影响当下欲望、关系、选择或主题的过去事件。
3. **结局／大悬念提前**：结果揭示后，“如何到达、真实含义是什么”仍须有足够观看价值。
4. **中段代表场面提前**：前置的场面必须代表全片主题、价值、色调或核心关系，并明确补回正文起点和时间位置。

不拿人的开场不等于坏开场，能调序也不等于应该调序。非常规开场只是从后文借材料建立承诺，不能用与主体气质无关的假预告欺骗观众。

## 综合矩阵

| 开发层级 | 主要工具 | 解决的问题 | 进入下一层前的验证 |
|---|---|---|---|
| 灵感与完整性 | 素材包、三要素、八要素 | 有没有主角、欲望、行动、阻力、结果和价值 | 八要素能连成因果，不只是名词 |
| 吸引力与类型 | 五支点、十类型最低承诺 | 观众为什么继续看，故事靠什么发动 | 主类型由中段行动和高潮选择证明 |
| 人物与复杂度 | 三面共情、五项独立性、四轴还原 | 谁是主角，观众跟谁，多线是否清楚 | 删除支线后简单内核仍成立 |
| 长篇与结构 | 十序列、十五节拍、A/B 双线、人物编织表 | 外在任务与内在成长怎样递进 | 中点改变方向，后半压力来自前文因果 |
| 场景与对白 | 场景六项检查、对白五法 | 抽象判断怎样成为可拍、可演的信息 | 每场至少改变信息、行动、关系或价值 |
| 悬念与反转 | 三项悬念、三种信息差、两种反转 | 谁知道什么，观众为何等待揭示 | 揭示后能解释前文且不破坏人物逻辑 |
| 修订与开场 | 七坑自检、情绪色块、四种调序 | 初稿先修哪里，入口是否匹配作品 | 公共可理解、主角亲自解决、开场承诺被正文兑现 |

## 扩展开发工作流

以下是跨课整理的可选开发流程，步骤先后属于整理者安排，不是课程要求所有作品遵守的固定顺序。

1. 每学一个学院理论或速成规律，先写清它解决什么问题，再用一段真实文本验证它是否带来可见修改；无法落地时，不把记住术语当成掌握。
2. 同时维护影视素材与生活素材，记录动作、台词、关系和变化；从中挑一个真实幻想，补写用途、关系变化、风险，并通过换位共情增加另一套处境与选择。
3. 用欲望、恐惧、观察和共情建立素材包，再用八要素写出最简单的单线故事。
4. 选一到三个故事支点，确定主类型和至多一个副类型，写出不能缺的最低承诺。
5. 若需要多人物或多线，先用人物、事件、视角、时间四轴还原，再做五项角色独立性检查。
6. 用十序列搭大关节，再用十五节拍补铺垫、争执、游戏时间、灵魂黑夜等过渡；同时分写 A/Want 与 B/Need。
7. 长篇项目建立全剧人物编织表和人物关系曲线，再把每集人物任务压成两至三条事件线。
8. 将事件拆成场景，逐场检查信息、推进、变化、对抗、进出和效率，把抽象判断分配给环境、动作与对白。
9. 用对白五法区分人物声音；建立信息矩阵，设计大、中、小悬念，并检查反转是否能回头解释前文。
10. 完稿后用七坑自检，按实际问题和依赖安排返修；需要时可先修观众入口、主角和对手，再压铺垫、让事件流动、调整情绪色块，不把七项讲授顺序当成硬性次序。
11. 最后决定常规建制是否足够；只有确有媒介或类型需要时，才用四种调序改开场，并补回被延后的因果。
12. 做化繁为简复核：按时间顺序复述、合并角色、删除支线。若主角、欲望、动作、阻力、结果和价值仍成立，复杂度才有稳定内核。

## 第一个故事工作流

1. 从双源素材本中选一条最有真实反应的记录，或完成一份未经美化的真实幻想展开表。
2. 从其中一个欲望或恐惧开始，补上相反力量，并用换位共情写出另一方的资源、压力、目标与代价，建立素材包。
3. 用人物、事件、主题三要素确定故事方向，再写全八要素。
4. 检查身份是否有反差、欲望是否原始、动作是否具体、问题是否形成悬念。
5. 把阻力至少分成环境、对手、自我三层，并安排逐步深入的顺序。
6. 从身份、激励事件、过激行为、悬念、环境中选一个最强支点，先把它做清楚。
7. 检查故事对观众作出的类型承诺，决定哪些预期要兑现，哪些地方负责创新。
8. 设计一个“绕过动作实现欲望”的结果，不让结局只等于任务完成。
9. 区分结果与主题：人物可以失败，但作品通过选择和代价肯定了什么必须清楚。
10. 写成约一千到两千字梗概，再进入事件化大纲；不要提前用格式、台词或镜头掩盖故事缺口。

## 大纲写作工作流

1. 先写一句故事核心：这个故事最终要回答什么问题。
2. 写出主角结尾状态，再反推开场相反状态。
3. 用一件开场事件同时呈现职业、处境、缺陷、语气和原罪。
4. 写切入阶段，把主角的痛点压到激励事件可以自然发生。
5. 设计激励事件，让它同时提供外部信息和内在诱惑。
6. 让进展阶段按错误动机行动，外部看似有效，内部问题未解。
7. 设计中段虚假胜利：身份上升、荣誉上升、认可上升，但核心问题不解决。
8. 让再转和危机来自主角自己的原罪或缺陷，而不是随机空降灾难。
9. 在导入阶段压缩退路，让高潮前的选择更窄、更急、更痛。
10. 让高潮用行动回答主题问题。
11. 根据高潮后的情绪选择结局气口。
12. 用八要素逐序列检查身份、欲望、动作、问题、阻力、结果、正价值和负价值是否真的变化。

## 常见错误

| 错误 | 为什么有问题 | 改法 |
|---|---|---|
| 把灵感当作等待天启 | 没有稳定的素材来源，创作只能碰运气 | 持续记录欲望、恐惧、观察与共情，建立素材包 |
| 八要素只填名词 | 故事表面完整，实际没有因果和变化 | 把八要素连成“身份—欲望—动作—问题—阻力—结果—价值”的因果链 |
| 每个要素都求反常 | 类型承诺被全部打破，观众无从建立期待 | 保留一部分惯常兑现，只让一到三处成为强支点 |
| 欲望过于抽象 | “追求正义、获得成长”无法直接驱动场面 | 下钻到保护谁、夺回什么、避免什么，再写具体动作 |
| 阻力只有一个坏人 | 冲突只在外部重复，人物没有深入 | 依次加入环境、对手、自我三层阻力 |
| 结果等于动作成功 | 结局只能回答任务是否完成，缺少人物意义 | 尝试绕过动作实现更深层欲望 |
| 把黑暗结局当负主题 | 混淆外部输赢和作品价值 | 分开判断结果正义与主题正义 |
| 先迷恋格式 | 页面像剧本，故事仍可能不存在 | 先完成梗概和大纲，再让格式服务协作 |
| 直接写人物判断 | 观众看不见“他很冷漠”这种判断 | 写一个他应该行动却选择不行动的事件 |
| 只写心理不写动作 | 剧本无法拍“他内心很痛苦” | 找到痛苦对应的沉默、回避、失控、错误选择 |
| 旁白和闪回用太早 | 容易替代场面设计 | 先尝试用环境、动作、对白表达信息 |
| 配角一开始堆太多 | 主线还没稳定，关系网先复杂 | 先抓主角，配角从事件需要中出现 |
| 用戏份或片名判断主角 | 最显眼的人不一定推动故事 | 看谁在激励事件后持续决定、行动并承担后果 |
| 开场共情后任意越界 | 观众理解了欲望，却不接受人物的手段 | 在重大动作前补足因果，让人物取得观众许可 |
| 每场都新增功能配角 | 人物多而薄，观众难以记忆，关系也无法积累 | 大纲完成后合并功能相近者，让关键配角跨越多个序列 |
| 用残疾替代人物特点 | 容易工具化角色，也显得老套 | 用能被行动表现的习惯、偏执、仪式或反差制造记忆点 |
| 每个角色都强做弧光 | 配角支线挤压主行动线，系列人物无法维持 | 优先检查主角弧光，区分成长、立场变化和稳定人设 |
| 太早给所有角色命名 | 名字制造虚假完成感，创作者开始依恋无功能人设 | 人物与事件稳定后再命名，并检查时代、阶层和辨识度 |
| 进展段重复 | 每次事件都像同一件事换皮 | 让风险、认可、误解和代价逐次升级 |
| 中段胜利太真 | 一旦问题真解决，后半段失去动力 | 设计外部胜利、内部未解的虚假胜利 |
| 后半段打击随机 | 主角变化和因果断裂 | 让打击来自开场选择、缺陷或原罪 |
| 高潮只追求大场面 | 动作热闹但主题没解决 | 让高潮动作回答人物核心问题 |

## 可实践练习

1. 写下一个最真实的欲望和一个最不愿面对的恐惧，把它们组合成一句带冲突的故事种子。
2. 用八要素把种子讲完整，再挑出身份、激励事件、过激行为、悬念、环境中最强的一个支点。
3. 为人物设计环境、对手、自我三层阻力，并检查它们是否逐层逼近人物真正的问题。
4. 写一个“动作失败但欲望以更深方式实现”的结局版本。
5. 把梗概划成十个序列：开场、切入、激励、进展、转折、再转、危机、导入、高潮、结局。
6. 每个序列只写一句“这一段的任务”，再补一个可拍事件，禁止只写“他意识到”“她感到”“他们关系变差”。
7. 用八要素检查每个序列：身份有没有变，欲望有没有转，动作是否推动问题，阻力是否升级，结果是否改变局面。
8. 找出一个中段虚假胜利和一个开场原罪，让后半段用因果回收它们。
9. 写两个结局版本，比较外部结果不同后，主题是否仍然由人物行动清楚表达。
10. 为主角做三面共情检查：身份是否可怜／可信／可爱，欲望是否原始，越界动作是否获得观众许可。
11. 在大纲中圈出所有配角，写下各自的事件功能；合并两组功能相近者，并让一个关键配角跨越至少两个结构关节。
12. 画人物关系图，每条线同时写“身份关系”和“对主角核心行动的推力／阻力”。
13. 写出主角第一场与最后一场的相反状态，再补三个中间变化点，检查人物是否突然翻面。
14. 给三个主要人物暂时只用功能名，等行动线稳定后再起符合时代、地域和阶层的名字。
15. 从学院理论或速成公式中选一个概念，用一句话写清它解决什么问题，再把它用于一段真实文本；删掉术语说明后，检查修改是否仍然有效。
16. 连续七天维护双源素材本：每天记录一条影视素材和一条生活素材，只写动作、台词、关系、情绪与变化，第七天选出三条可继续发展为场景的材料。
17. 选一次低风险分歧，分别从自己和对方的目标、资源、压力、代价写两个版本，最后保留一句仍不可调和的分歧，避免把共情写成认同。
18. 写一份未经美化的真实幻想展开表：愿望、用途、一天的变化、谁会靠近或疏远、最怕失去什么，以及三个能让观众看见变化的动作。

## 我的理解、疑问与联想

> [!note] 我的理解
> 这组课程最有用的地方，是把创作从“等灵感”变成一串可以检查的动作：先找到真实冲动，再用八要素讲完整，用故事支点制造吸引力，最后把抽象判断事件化。以后写大纲时，不应该先问“写得漂不漂亮”，而应该先问“这一段承担哪个结构任务、人物哪一项八要素发生了变化、这件事能不能被拍出来”。

> [!question] 我的疑问
> 十个序列在短片里是否要压缩成更少的结构关节？如果压缩，哪些关节可以合并，哪些不能丢？

> [!idea] 创作联想
> 可以把“想殉职的警察”的结构换成其他职业：想被系统淘汰的医生、想被辞退的老师、想被销毁的机器人。关键不是职业，而是“用逃避换补偿”的错误欲望如何转化成真正承担责任。

## 关键问题
