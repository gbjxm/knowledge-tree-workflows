# 查理老师的编剧课 - 第六课 剧本的格式

> 导航：[[知识库/学习区/课程/查理老师的编剧课/00 - 课程总览|课程总览]]｜[[查理老师的编剧课|统一知识总结]]

视频：[P13 第六课-剧本的格式6](https://www.bilibili.com/video/BV1eE411F73t?p=13)。第六课只有这一P。

前面的课先教写故事，本课开始进入“把故事变成剧本”的阶段。查理把格式理解为给各部门共同使用的工作参考：先标清这一场在哪里、何时、在室内还是室外，再让人看清环境、人物行动和对白。格式要帮助阅读与拍摄准备，具体符号、分场疏密和排版也会受个人习惯影响。

## 时间线笔记

### 00:03–02:12｜为什么提前讲格式

故事是剧本的原材料，先有故事，再把它转成剧本。这一转换有步骤和方法，是课程第二阶段要处理的问题。

因为学员反复要求，老师把格式提前讲了。他回忆自己年轻时也觉得“故事已经有了，只差一个模子”，拿到格式就能生产剧本，因而理解学员急着看模板的心情。但看一份剧本未必能自行理解所有格式，所以还需要解释。

老师当时表示会在学习群中分享一份获奖的好莱坞剧本。本P没有展示这份完整材料，本次也未取得该附件；这段是课程当时的安排，不表示现在仍能领取。

### 02:12–04:53｜以“场”为基本单位，首行标清四项

剧本由一场一场戏组成。老师在白板上依次写出场号、场景、时间、内外，作为每一场的第一行。

| 项目 | 本课的写法与理由 |
| --- | --- |
| 场号 | 如第十七场写成“017”。老师建议留三位数：电影可能有七八十场，也可能超过一百场。 |
| 场景 | 如“办公室”。老师在此把场景解释为这一场摄影机所能覆盖的范围，随后又用阳台和电话例说明可以合写几个位置。 |
| 时间 | 一般从日、夜、晨、昏中选择，不必写具体几点；若炸弹等剧情依赖关键时间点，就需要把具体时间交代清楚。 |
| 内外 | 标内景或外景。办公室先以内景举例，走到阳台时还须判断真实拍摄条件。 |

这一行的作用是让读者先知道“第几场、发生在哪里、什么时间、内景还是外景”，再读具体的戏。

### 04:53–07:35｜通常随场景转换换场，但不必切得太碎

一般规则是场景变了，场号也跟着变。查理随即用两个例子限定这条规则。

**办公室接电话，走到阳台或走廊。**人物原本在办公室接电话，说到不方便让同事听见的事情，便走去相邻阳台。可以把阳台另列为018场，也可以仍放在017场，在场景处写“办公室＋阳台”或“办公室＋走廊”。老师不建议一味切碎：如果人物在阳台只说几句又回办公室，反复新增场号未必有必要。

**电话两端来回切换。**丈夫在办公室，妻子在家里沙发上，几个镜头在两人之间切换。老师建议归为同一场、同一通电话，在场景处注明办公室和家里，不必妻子说一句换一场、丈夫说一句又换一场。

查理在此给的是个人分场习惯：选择时考虑一段行动或通话的整体可读性。场景转换是通常规则，这两例则说明何时可以合写；它们不代表所有剧组唯一的分场标准。

### 07:35–10:03｜内外景标记，是给灯光与外联做准备

办公室是内景，露天阳台是外景。但老师又区分：如果阳台已经搭在摄影棚里，可以按他这里的口径归入内景；如果要到外面找一个真实、裸露的阳台拍，就要注明外景。

为什么不能觉得地点写清了，就省掉内外？因为这会改变拍摄准备。

内景中，灯光组可以模拟白天或晚上：打“小太阳”营造白天，把窗子遮住营造晚上；棚内阳台也可以做昼夜、阴天、雨天等效果。真实外景更多依赖天光和天气，外联、制片需要提前安排。剧本要求外景下雨，拍摄当天却没雨，就要准备水车等条件。

老师用“外景时灯光组相对少操一点心、外联制片多操一点心”说明准备工作的变化。这是相对的课堂解释，不能推出外景无需灯光。场号、场景、时间和内外四项，最终都服务于各部门开展工作。

### 10:03–12:23｜办公室电话例：描述、行动、对白分别写什么

场头下面，本课区分描述、行动、对白三类内容。它们不是只有名称，老师用同一场办公室戏串起来示范。

**描述**交代这个环境当下的样子：早上的办公室很忙，五六个员工分别做事，他们的衣着呈现某种风格；其中一个人接电话，对着电话大声嚷，旁边的人嫌吵，翻了个白眼，却没有制止。这些细节一起描述办公室的状态。

**行动**推进角色A的具体过程：电话响了，A看一眼来电号码，不想接，先放下；想了想又拿起来，看了看周围的人，然后一边接电话，一边往阳台走。这组行动包含了不接、改变主意、观察周围、走开的连续选择。

**对白**是角色说出的话，接在这个过程后，例如：“喂，打电话给我干嘛？”

这样，读者既知道身处什么环境，也知道人物做了什么、说了什么。

### 12:23–14:30｜小动作可放对白括号中，符号以区分清楚为目的

行动和对白不必永远完全分开。人物说话时点一支烟、深吸一口烟，这样简单的小动作可以放在对白附近的括号中，不一定每次另起一行。

描述和行动也可以用符号区分：老师举描述前加米字号、行动前加三角形的做法；板书实际示范的是星形标记和空心正三角。三角可实心或空心、正放或倒放，不同学校和老师的习惯不同；他强调没有必要把这些差异当作考试中的对错，读者看得清类别才是目的。

剧本是交给演员和各部门的一份工作参考，格式没有绝对正统。描述、行动、对白可以反复交替：对白后继续行动，再对白，再描述。不能将三种类型误解成每场只能各写一次的三个固定区块。

### 14:30–18:25｜两种对白排版，以及“一页一分钟”的前提

老师在白板上画出一张A4纸，顶端简写017场、办公室、晨、内，下面以米字号标描述、三角标A拿起电话的行动，再比较对白的位置。这里是板书中的排版示意，并非课内展示了一份完整可交付剧本。

按他的介绍，好莱坞式排版会把角色名单独放一行居中，下一行写居中的对白；中国编剧常写“角色A：对白”，直接接在同一行。前一种让对白集中在页面中间，寻找台词比较方便。

老师解释，好莱坞剧本软件会自动套用特定格式，在这种英文排版下，一页大约对应一分钟。因此，想把关键事件放在第45分钟，可以用第45页作粗略参照。他并未讲具体软件名称或操作步骤。

查理不建议中文剧本仅因为觉得那种形式“先进”就照搬；他也觉得这种写法比较费纸。更主要的理由是：语言不同，同样排版并不保持同样的计时效果；按他的估算，中文一页可能约一分半至一分四十五秒。既然不再具有相同的计量意义，就可以顶头写，用符号分清描述、行动和对白。

**页数估时长依赖语言、排版和内容，不能脱离这些条件成为精确换算。**后面追车、打斗的例子还会进一步限制这种估算。

### 18:25–25:32｜“音节效率”的插讲：保存解释，也保留其推测性质

老师用“音节效率”指单位音节能表达多少意思，或表达同一意思需要多少音节。他据此解释中文排版为何不必照搬英文，并说这种效率高低“有利有弊”，不是单纯的褒义评价。

他提出“文明越古老，音节效率越高”的概括，以“差／衙”一个音节、“警察”两个音节、英语police及西班牙语的相应词作比较：他先不算policeman、police officer等更长说法，又把西班牙语的相应词数作四个音节，认为表达同一意思用更多音节，篇幅就会变长。他还提到“警察”一词从日语传来的说法。**这些是课堂中的语言比较和词源说法，本课没有给出研究依据；不能由这个例子直接证明语言或文明的整体效率高低。**

接着，他把这一想法延伸到唱歌：认为表达快、音节少便不需要拉长成歌；日语音节较多、部分少数民族语言词少而同音多，因而更容易唱起来。他还据此概括不同民族的音乐和歌唱能力。这些带有民族概括的因果判断，是讲师的即兴解释，课中未提供足以支持它们的证据，本笔记不把它们当作民族能力事实。

**女孩喊父亲回家吃饭，是他为这套解释编出的假想场景。**他设想一个壮族农家女孩，父亲在山上耕地。用汉语喊一句回家吃饭即可；而在他假设的另一种语言里，“父亲”可能与“太阳”“大公鸡”“大山”同词或同音，单喊父亲未必能区分。于是女孩要加上“半山腰”“挥动双手劳动”“慈祥”等限定，再展开回到温暖家中吃饭的邀请。连“强壮的父亲”也被他假设可能听成“炽热的太阳”，所以修饰还要更具体。句子越说越长，他便把它演绎成容易唱起来的语言。

这个例子保存的是“用更多限定消除歧义，所以表达变长”的解释过程；其中的词语对应一直带着“假设、可能”，不是已经核实的壮语词汇知识。

**歌曲的对照也有确定程度之分。**老师听刘若英《很爱很爱你》，觉得重复很多、表达的意思较少，于是猜它来自日语歌曲；他先说得很肯定，随即明确补上“不知道是不是，只是感觉”。因此，本课只能支持“他作了这个猜测”，不能据此确认歌曲来源。

相对地，他举李宗盛、罗大佑、崔健为自己认为表达密集的创作者，又拿一段写到半年积蓄、跨海探望的歌词作例子：很短的文字已经包含长期准备、花费和远行等经历，他夸张地说展开拍戏可能拍十五分钟；同一旋律若填日文，可能只反复表达思念，是他的另一项假想。

这段插讲最后回到排版意见：老师认为不同语言的表达密度不同，中文无需机械模仿英文剧本的页面形式。语言、民族与歌曲的推断应与这条格式建议分开理解，不能把推断全当作已经证明的论据。

### 25:32–28:22｜字号、页数、字数、场数都只是工作中的粗估

字体和字号没有严格统一的要求。老师在这里说一般用“小四”，并解释不能一味缩小：年长演员可能看不清，需要另外印一套剧本。小四是他给的常用选择，不能据此认定所有剧本必须使用这一字号。

关于体量，他给了几种口头估计：

- 按他所谈的中文格式，一页约一分四十秒，但也要看编剧习惯与冗余文字多少；两小时、120分钟的电影，他又举了约八九十页的量级。
- 按字数，可先用每分钟约300至350字估算。他从正常说话每秒五六个字谈起；剧本虽不全是台词，办公室忙碌、争吵、扫地等描述也要拍出来，同样占银幕时间。
- 按场数，120分钟电影可能七八十场，也可能八九十场，取决于分场是否细碎。

这些数字是不同角度的课堂粗估，并不构成一套严格互相换算的公式。统一格式是为了方便工作，个人写作习惯、分场密度和描述详略都会影响最终体量。

### 28:22–29:58｜追车和大场面：字少，拍出来未必短

老师明确举反例：有时一行字能拍七八分钟，或五分钟。追车、打斗尤其容易出现这种情况。他举《头文字D》的一场山间追车为例。

老师说，编剧可以先把故事过程描述清楚：角色A先占优势，压制B；随后B反超；A气急败坏，使用阴招。这里写的是竞争关系与行动如何发展。至于整场追逐怎样呈现，导演组、摄影组能找到什么场景、现场条件如何，会在实际执行中作很多决定。

由这个例子可以看出，具体拍摄由导演处理，并不等于编剧只写没有进展的“追车”二字；普通对白的字数估算也无法准确推算这一场的成片长度。这里是对本课例子适用范围的整理。

他又用“大漠孤烟、万马奔腾”举例：纸上只有八个字，实际拍摄却可能花很大功夫、拍很久。编剧写作时也要装着一颗拍摄的心，少随手增加这样的场面；但如果剧情确实需要，就仍然可以写。这里要求考虑必要性和执行代价，并非一律禁止大场面。

### 29:58–30:43｜课末回顾与材料边界

剧本呈现给大家的基本单位是“场”。老师再给两个参考量级：44至45分钟一集的电视剧，可能三十几场；电影可能七八十至八九十场，剧本约四万字。具体还看描述细致程度，需要在实际写作中摸索。

本课只提供最基本的格式框架，没有展示完整分场剧本，没有演示写作软件，也没有另布置新写作题或给出标准答案。老师再次提到分享剧本，材料取得情况见开头说明。
