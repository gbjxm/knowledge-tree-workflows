# 《讲故事的艺术》教学图视觉规范

## 教学合同

- 受众：已经看过课程、希望把观点转成可判断写作问题的学习者。
- 总目标：第一眼看到课程的主关系，第二眼能够复述判断步骤与适用边界。
- 固定事实：只使用 P1-P19 当前课级笔记与统一总结中已复核的课程内容。
- 解释边界：编剧化拆解、四象限与“冰山”画法属于教学综合或教学隐喻，不冒充尼尔·盖曼的逐字模型。
- 阅读顺序：标题与一句话结论 → 主体关系 → 底部判断边界。
- 输出：五张确定性 SVG；不使用装饰性插图，不把真实比例、统计或必然因果画进隐喻。
- QA：1200px 全尺寸检查文字、箭头、对齐、颜色和边界；600px 缩略检查主关系与阅读顺序。

## 五张图各自回答的问题

1. `01-课程全景.svg`：P1-P19 怎样构成从经验、叙事到完成与责任的一条路径？
2. `02-故事双引擎.svg`：“然后发生什么”和“这关于什么”怎样共同约束故事？
3. `03-人物想要与需要.svg`：怎样区分目标、手段和需要，并理解四种结局落点？
4. `04-短篇冰山.svg`：短篇怎样用一个可见切片暗示未写出的人生与世界？
5. `05-完成与修改闭环.svg`：初稿怎样经过冷却、重读、修改与反馈，最终停止打磨并交付？
6. `06-分岔收窄与必然结局.svg`：开端的众多可能怎样被每次选择逐步关闭，使后段只剩少数诚实结局？

## 视觉圣经

- 画布：`viewBox="0 0 1200 H"`，外边距 30px，圆角白卡片置于浅灰背景。
- 字体：Microsoft YaHei / Noto Sans CJK SC / sans-serif；标题 34px，分区 21-23px，正文 16-18px。
- 语义色：深蓝 `#0F172A`（正文），蓝 `#2563EB`（推进/行动），绿 `#059669`（整合/完成），琥珀 `#D97706`（深层判断/需要），红 `#DC2626`（风险/边界），紫 `#7C3AED`（形式/媒介）。
- 线条：2px 边框，4px 主箭头；颜色必须同时由文字、位置或线型强化。
- 画面：每张 2-4 个主要区块；不使用纹理、写实人物、装饰道具、渐变噪点或无信息图标。
- 文件名：两位数字 + 中文主题；预览 PNG 仅用于 QA，不进入课程资产目录。

## 来源与简化说明

- `01` 是 P1-P19 的课程结构综合。
- `02` 的双轨排布是教学综合；两个核心提问及其作用来自 P5 与跨课总结。
- `03` 的目标/手段/需要分层与 2×2 是编剧化解释；“need 不只等于正向成长”来自 P5、P6、P10、P16 的跨课核对。
- `04` 明示为教学隐喻；“关键切片暗示完整人生与更大世界”来自 P7-P8。
- `05` 把 P17 的修改流程与 P18 的完成/投递循环合并为教学流程，不表示每个项目必须等待固定天数。
- `06` 直接对应 P8 `13:59-14:51` 的课程比喻：开头分岔很多，每个词与选择都会关闭路径，到四分之三处只剩少数可行方向；“必然”来自累计约束，不等于预先锁死。
