# 老白的分镜课 - 第七课 讲故事的基础三原则

> 导航：[[知识库/学习区/课程/老白的分镜课/00 - 课程总览|课程总览]]｜[[老白的分镜课|统一知识总结]]

视频：[P8 第七课 讲故事的基础三原则](https://www.bilibili.com/video/BV1QB4y1r73i?p=8)。本课用已有电影段落、文字剧本和截取画面，演示怎样选择画面，再把信息从“出现”推进到“被观众接收”。

## 来源可靠性

本轮完整阅读既有 `faster-whisper base` 转写 00:00—23:17，复用已核 BV/P8/CID 822635065 的来源身份，并取得同一P的360p原视频无声流。先查看全课48格分布静帧，再围绕剧本、人物名、主镜对照、反应顺序和识别空窗补看11格定点静帧及画内字幕。原剧本上可辨名称为“猪皮哥、埃克托、米格”；没有靠破损ASR恢复歌词。

正文的动作、镜头顺序与情绪理由按老师的课堂拆解保存；静帧支持其中的构图、文字和前后图像对照。本轮未听原声、未连续播放，未独立核验切点、节奏、声音撤去、表演及真实观众的接收效果。采样不保证穷尽所有短暂图示变化。原ASR把倒下位置写成“地”的部分，由可辨原剧本“摊倒在床上”修正；异常短词不承担核心结论。

## 分集脉络

- **第7课 P8**：三原则 → 把主镜与连接镜讲顺 → 景别趋势与前后对照 → 强调消失和能力伏笔 → 弱化非重点 → 留待后课决定景别与视高。本课是一个课级单元。

## 本课速览

| 原则 | 检查的对象 | 本课的区别 |
|---|---|---|
| 实际上发生了什么 | 剧本中的人、事、话和结果 | 是场景事实，不是每一瞬间都能全部交给观众 |
| 想让观众看到什么 | 创作者从同时发生的信息中挑选哪些元素，何时让它们出现 | 是画面选择，本课先把事实与画面对应 |
| 观众实际上看到什么 | 预期信息是否被接收、记住，是否参与理解与情绪 | 画面呈现过，不等于观众已有效接收 |

## 核心观点

同一时刻的环境中有很多信息，镜头只能把其中一部分放到观众眼前。分镜因此既要决定事实如何呈现，也要检查“我想强调的内容”与“观众可能注意到的内容”是否一致。老师用看电影时嗑瓜子、喝奶茶、走神等情况说明：细节即使出现，观众也可能漏掉；即使看见，也可能需要强调才能记住。

老师把接收信息、产生情绪、进入情境和觉得好看联系起来，这是他的分镜教学解释；本课没有提供观众测试或保证所有人反应一致。实际整理时也不能把“已经选了一个特写”当作观众体验已验证。来源：`00:00—02:32`。

## 方法与案例

### 先把事情讲清：主镜与连接镜

### 分格后先放必要主镜

老师先把猪皮哥一场戏的文字剧本分成格子，使一个内容可以对应一个画面。目前可先把一句话或一次反应理解为一个画面单位；细致拆剧本的方法留待以后讲，不能把这个入门办法当成每句对白都必须切一次。

已经选好的主镜先放进灰色格子，它们承担本场必要事实：埃克托走到猪皮哥床前、说明借吉他、猪皮哥激动地抓领子后身体发亮并倒在床上、米格的疑惑、埃克托拿起吉他、猪皮哥听歌后心满意足地躺好并消散只留帽子、埃克托举杯饮下并把空杯扣到桌上。主镜先提供骨架，尚未把中间每次说话与反应都设计完。

连接镜的作用，是把前一个主镜与后一个主镜接顺。画面素材来自老师拆解的既有影片，并非本课现场原创或实拍检验。选择机位的前提也沿用前课已经给出的画面选择范围；本课重点在“选哪一个”。来源：`02:33—04:17、11:29—11:46`。

### 借吉他的对话：常规反打与物件插入

埃克托走到床前问候，先从他身后看猪皮哥；这个画面已经能看猪皮哥的脸，所以猪皮哥的回答可以直接在同一画面说完。埃克托回复时再反打他，猪皮哥让他出去，再反打回来说明来意。老师以这种往返对拍把两个主镜间的对白接起来。

对白说到“借吉他”，再插入吉他画面，使观众先对被谈论的物件留下印象。这个插入的理由是信息出现到这里了，不是每段对话都要随机加道具特写。来源：`04:18—05:24`。

## 冲突的递进：整体趋势比逐镜变化更重要

猪皮哥对自己的吉他越来越激动，最后起身抓埃克托领子。老师先提出两种画面层面的手段：镜头时长越来越短，或景别越来越紧。本课暂把表演和摄影机运动放在考虑之外，时长与节奏以后再展开，先用景别说明。

猪皮哥从较松画面逐步切紧，埃克托的画面变化不大也可以，因为本段递进的主要是猪皮哥的情绪。**不必每个镜头都比上一镜更近，只要总体趋势在收紧。** 讲师还指出：机位与景别未再改时，猪皮哥自己向前靠，在画框中变大，也能延续变紧的感觉。之后再向下摇到他提到的大腿骨处，强调他越说越急的状态；老师在 `12:04—12:07` 回顾中还指认大腿骨已缺，本文保存这一课堂画面描述，不补造缺骨的剧情原因。原帧可见较近面部、下方身体部位的图像和相应剧本文字；本轮没有独立观看这个摇动过程。来源：`05:24—07:38`。

到猪皮哥出事、倒在床上的主镜，突然放成较全的画面。老师用前面紧、激动，后面松、突然安静的变化来解释强调：即使观众刚才分心，强烈变化也可能把注意拉回来。“声音突然没有了”在这里按老师描述保留，本轮未通过原声证实；本课也没有规定收紧几档或多少秒才有效。来源：`07:38—08:22`。

## 唱歌段：选反应、共享观看与前后对照

### 拿琴到开始演唱

米格先对猪皮哥的状态疑惑；猪皮哥说自己快不行了，想请埃克托弹点什么。埃克托拒绝，猪皮哥坚持，埃克托答应并拿琴。这里用米格的惊讶连接“说要弹”与“真正弹起来”；米格还找小板凳坐好，进入聆听状态。

歌曲开始后，老师认为氛围较舒缓，于是可以让埃克托与猪皮哥的正反打松一些。这是这一段的情绪选择，不是凡唱歌就必须远拍。来源：`08:22—09:10`。

### 为什么歌词改变时要切听者

埃克托弹唱中突然意识到米格在对面听，于是临时改歌词。要让观众理解变化，就先呈现埃克托的察觉，再给他注意到的米格，随后回到改唱内容；猪皮哥不满意，需有他的画面，埃克托再解释“这里还有小孩”。

这不是把对白按说话者机械分配：米格没有负责这句对白，但他是改词的条件，所以必须让观众知道这个听者在场。破损转写中的歌词未逐字恢复；原剧本及画面支持“察觉听者→改口→另一人的反应”的关系。来源：`09:10—09:52`。

### 消失之前，为什么再给一次双人主镜

歌还没结束时，可以再回到埃克托与猪皮哥所在的主镜角度。这不只是换个画面：观众先熟悉“这里还有猪皮哥”的构图，后面同一角度再出现时，就能比较“刚才有，现在没有”。复现的机位与画框为后来的有无变化准备了参照。

歌词提到“要不是我奇丑无比”时，老师选择切猪皮哥，因为这句指向他；最后一句回埃克托作演唱收尾，再切猪皮哥感谢、躺好。原字幕可辨这一歌词关键词；其他歌词不补成完整引用。随后进入发亮、消散、帽子落下、举杯饮下与扣空杯的主镜。先检查这些主镜能否直接接上，再决定是否补连接镜；不是默认每两个主镜中间都必须加画面。来源：`09:52—11:29`。后面的 `11:29—13:31` 回顾沿用这条链，也再次强调前倾、较全转折和画面有无对照。

## 从讲全到强调：两个不同层级的重点

### 本场最重要的事件：猪皮哥消失

上面的主镜和正反打已经把剧情信息对应齐了，却仍可能只是流水账。老师用这点区分前两原则与第三原则：事实清楚、画面也有了，观众是否真接收到本场重点仍须检查。

猪皮哥消失是本场“重点中的重点”。仅有发亮特写和他消失的全景，老师认为可能还不足，于是增加不同关系中的反应与变化：

1. 猪皮哥身体发亮，接埃克托反应，让“他将消散”被再次确认。
2. 再接米格的反应，从另一名在场者的感受强化这一件事。
3. 回到猪皮哥，再表现更亮的变化；切较全画面，让观众看到他不见了，只剩帽子落地。
4. 用小狗对落帽的反应，再接回后续行动。老师以小狗的难过描述情绪作用；静帧只能核落帽和狗的图像，不能独立证明其动态表演效果。

这里的反复不是同一特写无条件复制，而是主体、两名在场者、消失后的空间、道具和小动物从不同关系再次确认同一事件。转写 `15:24—15:54` 的异常词没有被猜成镜头名称；补看 `15:20、15:49` 原帧，可见落帽与小狗上下排列，正文只保存可支持的关系。来源：`13:31—16:10`。

### 对全片重要的伏笔：埃克托会弹、会唱

这个能力在本场是一个较小点，对后续故事却重要。老师用后段发现“原来你才是那个伟大的歌手”来解释：这里先让观众注意到他会弹、唱得不错，才为后面重新理解其身份作准备。这是老师对后续故事的解释，本轮没有核完整影片，不补身份揭示机制。老师因此把强调开始点放在正式演唱之前：猪皮哥说自己想弹吉他、却已经弹不动时，就切埃克托。一方面是对临终处境的反应，另一方面在提到吉他的时刻把人物与物件关联起来。

之后米格的反应不能只缩成“一次惊讶”，它沿着不同阶段逐次出现：

| 行动阶段 | 米格的反应及其作用 |
|---|---|
| 埃克托伸手拿吉他 | 第一次惊讶：原来他可能真的会弹 |
| 埃克托拿好琴，询问想听哪首 | 再一次不敢相信，暂时延后正式演唱，让能力信息继续被期待 |
| 吉他真正弹起来 | 米格找小板凳坐好，表示认真聆听的准备 |
| 唱完第一句 | 米格笑或作肯定反应，确认唱得不错 |
| 随后继续唱 | 再有埃克托与米格的互动，使能力信息不仅留在一人自称中 |

各次反应分别对应拿琴、准备、弹奏与唱得不错，不是规定能力伏笔一律必须有固定次数。老师希望这些阶段共同使观众接收到埃克托的隐藏能力；实际全片效果不在本轮独立验收中。来源：`16:11—19:00`。

## 弱化非重点：不一定靠继续加镜头

老师另外假设：如果这场戏重点其实是吉他，甚至它有某种神奇功能，该怎样强调？一条路是加各人的反应；另一条是把前面的非重点变弱。

后一方案删去早段零碎的正反打，用较长的全景容纳走到床前、问候、来回交谈等日常内容。直到埃克托说想借吉他，突然切一个吉他特写。前面长期不切、不强调，后面的尺度与选择变化便显得突出。这个假设不是原电影里真的有神奇吉他，也不是规定日常对白必须用长全景；它说明强调可以来自周围不被强调的基准。

本课把增加重点强调与弱化非重点并列为两种形式，没有要求每场同时用，也没有给出删除镜头的百分比。来源：`20:27—21:27`。

## 本课整理归纳与未展开部分

老师最后把过程归纳成：**分格 → 选最能表达内容的画面并对齐 → 检查跳轴和衔接、接顺 → 强调重点与弱化非重点。** 例如重要反应通常用较近画面，大动作则取较全，先做到内容与画面直观对应，再处理连贯与轻重。这是本例的工作顺序，不是规定重点只能有几项、必须删掉多少镜头，或只要按步骤就保证观众被打动。来源：`19:00—22:11`。

这次用了现成影片画面；如果自己设计，确定平面位置后仍要决定摄影机多高、俯仰如何，以及景别为何松或紧。老师把视高与景别留给后续课程，本课没有给完整高度、景别法则，也没有读取到明确课后作业。来源：`22:11—23:17`。
