# 老白的分镜课 - 第五课 主镜的概念

> 导航：[[知识库/学习区/课程/老白的分镜课/00 - 课程总览|课程总览]]｜[[老白的分镜课|统一知识总结]]

视频：[P6 第五课 主镜的概念](https://www.bilibili.com/video/BV1QB4y1r73i?p=6)

## 本课速览

拿到一场台词和动作很多的戏，先想每句该切谁，很容易让画面设计被台词牵走。老师用《寻梦环游记》（Coco）的一场借吉他的戏示范：先理解全片和这场戏的作用，再分段归纳内容，为各段选择讲述故事不可缺少的画面。本课把这些画面称为“主镜”。机位和轴线随后根据画面反推，本课还没有给出完整连接镜设计。

这里使用课堂文字中的姓名：埃克托、米格、猪皮哥；“米格”是本课的称呼。影片身份仅用 Pixar 官方角色资料辅助排除片名字幕和 ASR 错字；下面的方法、场景内容与解释均按课堂材料保存。

## 先读懂这场戏，而后设计画面

### 剧本发生了什么

埃克托带米格进房，想向躺在床上的猪皮哥借吉他。猪皮哥因过去的事情不愿借，并对埃克托生气；他抓住埃克托的领子，突然发亮、倒下。米格对此疑惑。老师特别强调米格的反应：他跟观众一样，还在认识这个亡灵世界，因此他的疑惑为观众引出新规则。

这条规则是“终极死亡”：现实中已经没有人记得一个亡灵时，他会真正消失。埃克托安慰猪皮哥。猪皮哥知道自己将消失，提出想听一首歌；埃克托先推托，后来抱起吉他弹唱。猪皮哥满意地躺好，发亮消散，留下帽子。

埃克托饮酒，把空酒杯倒扣在桌上；猪皮哥的酒杯仍有酒、正放着。米格询问刚才发生的事，埃克托解释终极死亡，两人离开，镜头留下杯子。

### 同一场景的两层作用

老师归纳这场戏有两层作用：介绍终极死亡的世界规则，以及暗示埃克托后续的命运。他认为一正一反、一个仍满一个已经空了的杯子，联系着猪皮哥的消失和埃克托可能遭遇的危险。

这是讲师结合前后剧情做的解释。老师也说，有些观众会想到这层暗示，有些观众只会为猪皮哥消失而难过；他自己初看时也是后者。因此画面承载的含义，并不保证每位观众都会即时、完整读出。

## 先找“主镜中的主镜”

老师先问：如果只用一个画面表达这场戏的整体内容，选哪一刻？他把场景概括为“二人借吉他、唱歌、猪皮哥没了、介绍世界观”，再选择猪皮哥消散的关键时刻：埃克托抱着吉他在旁边，米格在前景看着远处。

这一画面把核心事件和观看关系放在一起：消失发生了，埃克托与它直接关联，米格承担观众的观看与疑问。老师称其为“主镜中的主镜”。它是这场戏最有代表性的画面，选择它并不意味着整场只拍这一镜，其他必要内容仍要逐段寻找自己的画面。

## 分段归纳，保留有意义的变化

不要一行台词画一格。先把同一内容合并：不借吉他、因过去的事生气、两人争执，能归纳成一段拒绝借琴的内容。但抓领子后突然发亮倒下，是新的身体变化；米格疑惑是重要的观众反应；后来的消散与留下帽子也有各自的意义，不能在压缩时合并掉。

本例的内容顺序是：进来借吉他；猪皮哥不借且生气；抓领子、发亮倒下；米格疑惑；埃克托安慰，猪皮哥请求听歌；埃克托弹唱；猪皮哥消散、帽子留下；埃克托饮酒扣杯；向米格解释终极死亡；两人离开、杯子留下。这里是归纳这场戏的内容，不能换成每场都必须遵循的十步模板。

老师借这一步说明：剧本里的每句对白，不一定都有必须独立表现的信息。例如“滚”“不滚，我来办事”一类来回，如果没有新增具体内容，可以不为它们另找主镜。判断依据是讲述这段故事是否需要这个画面，而非台词行数。

## 核心观点

主镜是讲述这段故事不可缺少的画面。老师先为每段实质内容选一个画面，再得到一组主镜。画面不是机位编号：观众记住的往往是一个具体视觉时刻，创作者也常先出现画面灵感；轴线、机位则是把画面实现出来的工具。

这样安排工作，是先集中精力处理画面里的叙事元素和观看关系，再处理轴线、景别、切换等具体技术。本课讲到有限的十几幅图就能集中表达故事，体现的是本例的工作优势，没有规定每场必须只有多少节点或多少镜头。

## 方法与案例

### 本例怎样为各段挑画面

| 内容 | 老师选择的画面与理由 | 保留的条件或选择空间 |
| --- | --- | --- |
| 进房、借吉他 | 从米格的观看方向看借琴两人，再给吉他特写，明确借的是什么 | 米格的视角在这里组织观众的认识 |
| 猪皮哥不借、生气 | 从埃克托方向看猪皮哥，表现拒绝和情绪 | 先归纳这一段，不逐句切换 |
| 抓领子、发亮、倒下 | 动作幅度大，选较松的景别，从米格方向看 | 可以让米格在前景，也可以不挂他的前景；不是每次都必须有肩背 |
| 米格疑惑 | 米格表情特写 | 这反应引出观众对新规则的疑问，不能作为无用反应删掉 |
| 猪皮哥将死、请求听歌 | 用猪皮哥的画面表现其状态与请求，接埃克托抱吉他弹唱 | 本次未独立审听歌声和演奏效果 |
| 猪皮哥消散 | 回用前面选出的代表性画面，米格在前景看远处 | 核心是事件与观看关系；具体前景在左或右稍后再决定 |
| 帽子留下 | 通常给帽子特写 | 全景也能留下帽子，但它可能太小看不见；老师认为留下东西比完全空无更伤感 |
| 饮酒、空杯倒扣 | 用道具动作特写表现空杯倒扣与另一杯仍有酒 | 老师说这一画面给他很强的感受；这里保存其判断，未独立评价连续效果 |
| 解释终极死亡 | 米格在前景，埃克托在后面解释，使我们像跟米格一起听 | 相比单独一个解释者特写，画面还包含听者与观众的观看关系 |
| 两人离开 | 杯子前景、人物后景离开，可把留下的道具和相关人物同置一画面 | 也能拆为出门画面与杯子特写；老师在此更喜欢同画面表达 |

### 特写的理由要落实到这一内容

帽子特写的理由不是“重要道具一律特写”，而是全景可能让观众看不见消散后留下的帽子。米格特写的理由也不是平均给每人反应，而是他的疑惑代表观众，需要引出世界规则。饮酒扣杯则把讲师关注的道具动作与命运暗示集中出来。这些理由各不相同，应随具体内容判断。

### 主镜阶段可以暂不确定左右与角度

杯子放左还是放右、从什么角度看，此时没有必要都定死。课堂插图中，杯子的银幕左右也随观察方向变化；保存的是一杯正放仍有酒、一杯空了倒扣的关系，不给它们固定左右编号。

结尾可以先画两人离开，再画杯子特写。老师提出另一种选择：杯子在前景、两人在后景离去，让命运暗示所涉及的人与道具同时在画面里。两种都可讲述，选后者是本例的画面取舍，不是禁止拆镜。

## 从主镜进入下一步

老师把选出的主镜按内容顺序走一遍，认为这组有限画面已经能说明故事，并集中起情绪和氛围。这里借完成影片反推教学，不等于记录了影片实际创作团队从零设计的全过程，也未检验本次连续剪辑效果。

主镜确立后才反推机位与轴线。例如米格作为前景看着远处的消散，画在左边或右边都能保留这个意思，但会影响机位和轴线关系，下一步需要核对。本课末预告下一课从画面推导机位与轴线，连接镜之后再讲；不能提前把尚未讲解的补镜条件写成本课定论。

## 分集脉络

P6由读懂借琴场景和世界规则，进入代表性画面、分段归纳、主镜定义和逐项画面取舍；课末把左右选择与机位轴线核对留给下一课。

## 时间线笔记

- `00:00–02:52`：读懂剧本、米格的观看作用、终极死亡和杯子解读。
- `02:52–04:44`：用一幅图代表整场，寻找“主镜中的主镜”。
- `04:44–07:17`：归纳段落，保留异变、反应、消散和道具变化。
- `07:17–09:38`：主镜定义与先画面、后技术的工作顺序。
- `09:38–13:36`：逐项选画面，解释特写、前景与结尾合画面的理由。
- `13:36–16:42`：回走有限画面；左右选择留到后续轴线核对。
