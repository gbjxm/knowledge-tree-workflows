# 《视听语言》教学图统一规范

## 目标与边界

- 目标：让学习者第一眼看见核心关系，第二遍能凭标识、箭头和结论复述或应用。
- 质量顺序：事实正确 → 对应完整 → 第一眼清楚 → 可直接使用 → 视觉简洁 → 趣味与润色。
- “专业、详细、完整”指教学链与映射完整，不指写实质感或元素数量。
- 所有图均为教学简化；未由课程确认的距离、焦距、比例、年代和参数不得伪造。
- 趣味内容统一标为“教学延伸（Codex 综合）”，不能伪装为课程原话或外部事实。

## 视觉系统

- 格式：确定性 SVG；宽度 1200，优先高度 720–900；白色卡片置于浅灰背景。
- 结构：标题 + 一句阅读目标 + 2–4 个主要区域 + 结论栏。
- 字体：`Microsoft YaHei`, `Noto Sans CJK SC`, sans-serif。
- 字号：标题 32–34 px，分区标题 20–22 px，正文 16–18 px。
- 调色：正文 `#0f172a`；主蓝 `#2563eb`；琥珀 `#d97706`；成功绿 `#10b981`；警示红 `#ef4444`；补充紫 `#7c3aed`；颜色必须同时由文字、位置、线型或形状加强。
- 图形：使用几何人物、摄像机、画框、箭头、时间线、声波和简化光束；不用 Emoji，不追求真实器材外观。
- 每张图只回答一个主要问题；不得用装饰性背景、纹理或无关道具填满画面。

## 笔记写入模板

在 `## 本课速览` 与 `## 来源可靠性` 之间插入：

```markdown
## 直观教学图与趣味理解

![本课教学图](_assets/teaching-visuals/文件名.svg)

> [!tip] 怎么读
> 用 1–2 句话说明阅读顺序、核心关系和适用边界。

> [!example] 教学延伸（Codex 综合，不是课程原话）
> - **反直觉点**：……
> - **一分钟实验**：……
> - **创作口诀**：……
```

## QA

- 每张 SVG 通过 `validate_visual.py`。
- 渲染 1200 px 全图，并制作真正等比的 600 px 检查图；不得把裁切误当缩放。
- 检查标题、阅读顺序、中文字符、文字重叠、裁切、箭头端点、颜色映射和教学结论。
- Markdown 使用相对路径，资源位于本目录；修改后检查 19/19 嵌入均存在且可解析。
