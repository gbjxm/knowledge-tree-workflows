## 原有教学延伸、实验和口诀

```text
> - **反直觉点**：制造“更大空间”不一定要换更大的场地；一次画外声音、一次人物出入画或一次视点变化，就可能让观众意识到画框之外仍有世界。
> - **一分钟实验**：面对同一房间不移动机位，先让人物看向画外，再加入门外脚步声，最后让另一人从不同入口出现；记录空间想象每次增加了什么。
> - **创作口诀**：场景给边界，视点和调度开门，时间与声音扩窗。
```

## 旧稿五项整理方法

```text
1. 为每场戏写清“内/外—地点—日/夜—事件”，再补一行“场景为何只能/最好发生在这里”。
2. 勘景时同时记录可控制项与风险项：自然光、噪声、机位、人物运动范围、改造成本、许可和连续性。
3. 用九项清单核对场景：主体、陪体/群体、景别、构图、距离、角度、色彩、光线、开放/封闭形态。
4. 将整场戏画成场景链，注明每个场景进入与离开的视觉、动作或声音依据，提前消除穿帮。
5. 反向检查风格：如果替换地点后戏仍完全不变，说明当前场景可能尚未参与叙事。
```

## 原有实践练习

```text
1. 选一个两人冲突场景，分别放入狭窄电梯、空旷广场和拥挤餐厅，写出人物行动、景别与声音将如何变化。
2. 对当前项目做一张场景链：每场景写明叙事任务、人物变化、进入/退出方式和连续性风险。
3. 拉片比较一段封闭空间戏与一段开放空间戏，记录镜头尺度、主客观视点、剪辑率和画外空间提示。
```

## 原有一分钟摘要

```text
场景是“在某时某地发生某事”的可见单元，也是人物、光线、构图和调度的综合系统。具体场景通过连续排列、画外暗示和开放/封闭形态，让观众建立远大于画框的影视时空。选景不是找背景，而是在选择影片的叙事条件和风格条件。
```

## 原有自测问题

1. 场景与影视时空为什么不能当成同义词？

3. 怎样判断场景已经参与人物塑造，而不是只提供地点信息？
