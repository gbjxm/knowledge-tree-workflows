## 原有教学延伸、实验和口诀

```text
> - **反直觉点**：灯越多不一定层次越清楚；没有共同基准和叙事方向，新增光线反而可能互相抵消。
> - **一分钟实验**：用一盏可安全移动的灯照一个物体，先只改变方向，再用白纸轻微补暗面，观察主体与背景何时最容易分开。
> - **创作口诀**：先定时空和基准，再分重点与层次。
```

## 旧稿五项整理方法

```text
1. 给每个时空写一份光线规则：主色温、主要光向、光质、光比、运动程度和允许的例外。
2. 勘景时把机位、人物调度和灯位画在同一张平面图上，提前发现灯具穿帮、运动遮挡和曝光突变。
3. 先选定中间灰/基准主体作为定光点，再检查窗户、门口、灯具等高亮区域和需要保留信息的暗部。
4. 用光比回答叙事问题：谁被看见、谁被隐藏、空间是否安全、人物处在控制还是失控中。
5. 拍完全景后再设计近景和特写，允许为脸部造型微调，但对照全景的光向、色温和环境反差。
```

## 原有实践练习

```text
1. 为同一房间设计现实、回忆、危险三个版本，只改变光线规则，不改变美术和机位。
2. 勘察一处有窗内景，列出基准曝光、高光风险、暗部保留、人物调度和反打连续性方案。
3. 拍摄一组全景—近景—特写，允许重新布光，但要求观众看不出光向和时空发生跳变。
```

## 原有一分钟摘要

```text
布光从来不只是曝光充足。先按时空和场景建立色温、光向、光质与光比规则，再结合机位和调度定光，控制高亮和暗部，并用明暗变化推动人物与叙事。近景可以为造型调整，但必须服从全景建立的氛围；自然光最终也要经过创作选择。
```
