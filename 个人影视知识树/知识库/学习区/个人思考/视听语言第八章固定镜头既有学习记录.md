## 原有理解文字

> [!note] 我的理解
> 固定镜头的难点不在“稳住”，而在稳定之后，画内是否有变化、纵深是否有关系、上下镜是否有逻辑。

## 原有一分钟实验和口诀

```text
> - **反直觉点**：摄影机越稳，画面越需要真实的内部变化；否则稳定不会自动带来客观与沉浸，反而可能只剩“照片延长”。
> - **一分钟实验**：固定手机不动，让一人完成“入画—被前景遮挡—看向后景—出画”，回看时检查是否有起点、变化和结尾。
> - **创作口诀**：框架稳，画内动；有纵深，前后通。
```

## 原有实践练习

```text
1. 拍一个 20 秒固定镜头，必须包含清楚的起点、变化、结尾和一次不可预知反应。
2. 对同一举手动作分别制作二分之一、三分之二、三分之一剪辑版，比较时长、强调和人物气质。
3. 设计一个小景深拉焦镜头和一个大景深关系镜头，分别说明观众的观看权归谁。
4. 用六个以内固定镜头表现一个人物从醒来到发现目标的过程，只用光线、动作、视线和物件连续连接。
```

## 原有一分钟核心摘要

```text
固定镜头不是“机器不动”，而是相对主要内容静止，并以稳定画框让观众专注内容。它必须拍变化、用纵深、精确构图、控制光效和景深，并通过成组拍摄与外部剪辑完成动作、逻辑和节奏。
```

## 原有自测问题

```text
1. “三不动”和“相对主要内容静止”为什么必须同时使用？
2. 平稳画面如何支持客观表达，歪斜和晃动又怎样变成主观手段？
3. 二分之一、三分之二、三分之一剪辑法分别改变什么？
4. 小景深和大景深把观看权交给谁？
5. 什么才算固定镜头组的内在连贯？
```
