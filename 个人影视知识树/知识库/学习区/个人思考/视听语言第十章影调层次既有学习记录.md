## 原有教学延伸、实验和口诀

```text
> [!example] 教学延伸（Codex 综合，不是课程原话）
> - **反直觉点**：低调并不是把所有东西压黑；真正有效的低调仍要让主体、空间和关键细节彼此分开。
> - **一分钟实验**：把一张剧照临时转成灰阶或眯眼观看，依次指出最亮、最暗和视觉中心；若三者难辨，先查层次而不是先套滤镜。
> - **创作口诀**：高低看面积，软硬看过渡，重点靠分离。
```

## 旧稿六项综合观点

```text
- 影调是层次关系，不是单个曝光数值。高调需要浅色占比和较小反差，低调仍需保留可读层次，不能用过曝或死黑替代。
- 高/低调描述整体明暗面积，硬/软调描述反差和过渡；两个维度可以组合，例如低调不必然等于硬调。
- 对比物能建立视觉中心：高调画面中的暗色、低调画面中的浅色，既丰富层次又引导注意。
- 影调的情绪倾向不是固定公式。明亮可快乐也可虚假，低调可危险也可沉静，必须结合人物、场景和叙事判断。
- 光线是影调最直接的推手，但物体材质、服装色彩、背景亮度、烟雾、镜头和后期同样改变层次。
- 后期调色无法完全替代前期控制。场景本身若缺少亮暗、色彩和材质关系，后期很难凭空生成可信层次。
```

## 旧稿五项整理方法

```text
1. 在影调方案中分开写两个维度：整体明暗面积（高/中/低）和反差过渡（硬/中/软），避免术语混用。
2. 先确定主要面积与视觉中心：画面大部分处于什么亮度，哪个主体需要用相反亮度跳出。
3. 用直方图/波形辅助曝光，但最终检查仍包括肤色、材质、空间层次和叙事情绪，而非只追求技术均匀。
4. 勘景时记录墙面、服装、木材、玻璃、水面等反光率和色彩，判断它们会让光更散、更硬、更亮还是更暗。
5. 前期同时拍摄参考静帧和灰卡/色卡，后期按既定影调意图统一，而不是每个镜头各自“调得好看”。
```

## 原有实践练习

```text
1. 用同一人物、同一构图拍高调、低调、硬调、软调四版，分别记录背景、服装、光向、光质和光比。
2. 找一张低调剧照，检查是否仍有主体、环境和细节层次；尝试修正“全黑但没有重点”的版本。
3. 勘察木材、玻璃、水面、白墙和黑布五种材质，记录同一光源下的反射、明暗和色彩差异。
```

## 原有一分钟摘要

```text
影调是画面明暗、色彩和过渡的层次系统。高低调看整体亮暗面积，软硬调看反差与过渡，两者不能混为一谈。光线、背景、服装、材质、曝光、烟雾、镜头和后期共同塑造影调；真正的目标不是“亮”或“暗”，而是用层次引导注意、建立质感并表达人物与叙事。
```
