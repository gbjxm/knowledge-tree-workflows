## 原有教学延伸、实验和口诀

```text
> [!example] 教学延伸（Codex 综合，不是课程原话）
> - **反直觉点**：镜头短不等于节奏快；连续快切若没有新动作、新关系或新信息，仍会显得疲惫和拖沓。
> - **一分钟实验**：匀速拍桌四次，再把第三次改为停顿后重拍，同时口头改变强弱，感受“规律中的变奏”如何产生重音。
> - **创作口诀**：先看有没有变化，再问要不要变快。
```

## 旧稿六项综合观点

```text
- 节奏的核心是“变化”，而不是持续快速。完全规律会机械，完全无规律会混乱，规律与变奏共同构成可感节奏。
- 内部节奏来自单镜头中的人物动作、摄影机运动、光影、色彩和声音；外部节奏来自镜头之间的时长、景别和剪辑组织。
- 故事密度与情绪张力能让长镜头有节奏；缺少事件和情绪时，单纯把镜头剪短只会得到表面速度。
- 镜头长度没有固定情绪。长镜头可以沉静，也可以因调度和空间探索而紧张；短镜头也可能因信息重复而显得疲惫。
- 视听双轨可同向强化，也可一快一慢产生张力；声音速度、密度和音乐情绪必须纳入节奏设计。
- 信息量是节奏的内容基础。变化的动作、关系和结果越清楚，节奏越有推进；形式变化无法替代内容设计。
```

## 旧稿五项整理方法

```text
1. 诊断节奏时分四栏：故事事件、人物情绪、镜头内部变化、镜头外部剪辑；先找哪一栏缺少变化。
2. 对每个段落画“快—慢—快”或其他起伏曲线，并写明每次变化由事件、情绪、镜头还是声音触发。
3. 镜头长度与景别一起看：远景长停留、特写快切、长镜头内快速调度都会产生不同心理速度。
4. 用化简为繁强调困难、程序或危险；用化繁为简省略观众能自行补全的过程。
5. 检查快切镜头是否带来新信息。若连续镜头只重复同一结果，先丰富动作与反应，再谈剪辑率。
```

## 原有一分钟摘要

```text
影视节奏是叙事、情绪、画面和声音的有规律变化。它既在镜头内部，也在镜头之间；既来自镜头长短与景别，也来自事件密度、人物张力、摄影机运动、色彩、光影和声音。真正的节奏设计要有快慢、有变化、有新信息，而不是把素材简单加速或无限快切。
```
