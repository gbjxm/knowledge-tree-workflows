## 原有教学延伸、实验和口诀

```text
> - **反直觉点**：运动镜头不一定比固定镜头传递更多新信息；它有时正是用较长的过程积累压力、权力、疏离或落幕感。
> - **一分钟实验**：对桌上一件小物做一次缓慢靠近、一次缓慢退远和一次原地横向转看；每次只写“新出现的信息”和“产生的情绪”。
> - **创作口诀**：推找点，拉见面，摇勾连，移换空间；起落要稳，过程要赚。
```

## 旧稿六项整理方法的历史版本

```text
1. 为每个运动镜头填写四格：起幅信息、过程新增、落幅重点、核心情绪；任一格为空都应重审。
2. 推镜只推难以自然发现且值得强调的细节；拉镜必须让新增环境改变对原细节的理解。
3. 摇镜按“浏览”或“勾连”二选一设计：浏览要求全程持续信息，勾连要求两端关系明确。
4. 移镜先画空间剖面，安排至少一个前景穿越、一次层次改变和一条贯穿线索，再决定器材路径。
5. 跟镜每经过一个节点都写出新增信息；若连续数秒只有人物背影，考虑变线索、改角度或改固定镜头。
6. 运动镜头结束后停稳落幅，让最终信息被读完，不把停止动作当成剪掉即可的技术尾巴。
```

## 原有实践练习

```text
1. 拍一组“推入开场—拉出结束”，要求推的细节原本不易发现，拉出的环境必须改变细节含义。
2. 设计一条 30 秒移动路径，至少穿过两个前景、切换一次线索、组合两种运动，并标注每段新增信息。
3. 将一个纯跟背镜头改拍三版：侧跟、超越后回看、由人物切换到物件线索，比较信息量。
4. 为同一人物制作缓推、急推、缓拉三版预演，只讨论情绪，不先讨论“高级感”。
```

## 原有一分钟核心摘要

```text
运动镜头必须回答为什么动：推拉改变环境与细节关系，摇负责浏览或勾连，移负责空间体验和综合调度。有效运动还要有情绪、纵深、贯穿线索与新增信息，并以清楚的起幅和落幅形成完整镜头。
```
