# 新增与替代对白怎样选对ADR、旁白或角色配音模式并保持表演与同步

> 本主题研究一条新声音究竟是在替代既有表演、第一次建立角色声音、承担旁白叙述，还是替换语言。只有先选对生产模式，才能决定声音应先于还是晚于画面、口型要多严格、表演参考是什么、怎样建立空间，以及AI语音需要保存哪些来源与同意证据。

## 快速认识

- 核心问题：中文“配音”常把ADR、原始角色声音、旁白、译制和AI合成混成一步，导致错误时序与验收标准。
- 主要结论：声音所有权归D，不等于所有声音都在C之后制作；AI／动画角色的原始声音可能成为画面节奏和口型的上游基准。
- 学习价值：学会先判断这条声音是什么，再决定voice-first、picture-first或迭代路线，避免把静音角色初次发声误标为ADR。
- 适用环节：有对白角色的生成前接口、Rough／Fine中的临时声音、Picture Lock后的ADR／VO、AI语音制作和可混音交付。

## 核心命题

“后录”只描述时间，不足以定义声音工艺。

同一句角色台词可能属于：

- Production dialogue：角色原始表演；
- ADR：对已有表演的同语言补录、替换或新增；
- Original character voice：第一次建立角色声音；
- Voice-over：独立叙述、内心或评论层；
- Localization dubbing：更换语言后重建表演；
- Walla／Group ADR：人群背景表演；
- Scratch：驱动画面或审看的临时参考。

AI语音只是一种生成手段，可以承担上述多种叙事角色。它不能用“AI配音”一个标签掩盖功能、表演、口型、空间和权利差异。

## 适用边界

- 本主题不负责已有同期对白的寻源和修复；那属于对白编辑主题。
- 本主题建立声音模式、表演、同步、空间和来源原则，不指定录音棚、麦克风、TTS服务商或口型软件。
- D拥有最终对白与声音产物，但原始角色声音可能需要经A转交给C驱动画面；本轮只保留知识接口，不修改v0.7或设计v0.8。
- 译制配音只保留专业概念和接口，不把多语言、PLDL、KNP、M&E和国际交付设为每支短片必做。
- AI声音的授权、标识与平台条款会变化；真实采用和发布时必须重新核对。本主题不提供法律意见。
- 最终空间、响度、声道和母版留阶段6。
- Agent没有完整听过真实声音、看过口型和身体动作时，不得宣称表演或同步通过。

## 内容导览

### 整体脉络

- 分流：先确定声音模式，而不是先选工具。
- 时序：判断声音驱动画面、画面约束声音，还是两者迭代。
- 表演：给出角色行动、潜台词、上下文、相邻对白、身体与情绪参考。
- 同步：按嘴部可见程度、身体动作与叙事目的确定严格度。
- 空间：让干净录音重新属于画面中的距离、方向、移动和环境。
- AI：把合成声音作为可追溯表演资产，保存模型、文本、版本、授权和标识。
- 交付：保留原始take、主选、Alt、Line／Cue、空间状态和CUT依赖。

## 知识单元

### 一、八种声音模式

这里是任务入口清单，不是八个互斥、同层级的学术类别：Dialogue edit是工序，ADR是补录工艺，VO是声音与叙事的关系，Scratch是采用状态。同一条声音可以同时是“原始角色旁白、AI生成、临时参考”，之后又接受对白编辑。已有原始角色表演也不必等于已有可用录音；ADR可能补录现场没录到的句子，不能只按文件是否存在分流。专业命名有地区差异，首要任务是把实际用途说清楚。

| 模式 | 本质 | 可见口型 | 主要任务 |
|---|---|---:|---|
| Production dialogue | 与原始表演同时或作为动画原始生产录制的角色对白 | 常有 | 保留第一表演与时序 |
| Dialogue edit | 对已有语音寻源、选择、修复与平顺 | 视画面 | 形成可混录对白 |
| ADR | 对既有表演进行同语言补录、替换或新增 | 通常有 | 匹配或有意改变既有表演 |
| Original character voice | 第一次为AI／动画／静音画面建立角色声音 | 可有可无 | 建立角色声音与画面时基 |
| VO／Narration | 叙述、内心或评论层 | 通常无 | 组织视角、信息、节奏和画面关系 |
| Localization dubbing | 用另一语言重建原意和角色表演 | 多数有 | 改编、选角、表演、口型和本地化 |
| Walla／Group ADR | 人群语言或非语言背景表演 | 松散 | 建立群体与空间 |
| Scratch／Temp voice | 驱动预演、口型、节奏或审看 | 可能有 | 临时参考，必须可替换 |

三个容易误判的情况：

- 角色在画外说话，仍可能属于场景对白，并不自动成为旁白。
- 静音AI角色第一次获得声音，不是“替换既有对白”，因此不应自动叫ADR。
- 英国语境的dubbing mixer通常指re-recording mixer，不等于中文“配音演员／译制配音”。

### 二、声音所有权与生产时序分开

D可以拥有最终声音事实源，但制作时间可能有三种路线：

| 路线 | 适合条件 | 风险 | 必须保留 |
|---|---|---|---|
| Voice-first | 音频驱动画面、动画prelay、明显嘴型或表演节奏依赖声音 | 后续改词会牵动C和剪辑 | 角色声音版本、文本、时长、发音、guide／final状态 |
| Picture-first | 旁白、画外声、弱口型或画面动作已经稳定 | 口型和身体动作可能限制表演 | 当前CUT、嘴部可见、动作／呼吸约束 |
| Iterative | AI口型、声音和画面需要往返试验 | 版本容易失控 | 每轮声音／画面配对与采用基线 |

上述接口保留为原知识建设期的设计问题。实际采用时读取当前项目的声音／画面责任约定，不凭本文派工；三条路线说明依赖关系，不限定哪一岗位或阶段必须独占录制。

### 三、共同表演准备

无论真人录制还是AI生成，都不应只提供孤立台词。至少提供：

- 角色当前行动和想从对方身上得到什么；
- 潜台词、关系、情绪起点与终点；
- 前后句、抢话、停顿和场景节拍；
- 画面、口型、手势、姿态和身体用力；
- 空间、距离、遮挡、运动和声源位置；
- 发音、专名、数字、方言或口语要求；
- 当前声音是临时、候选还是最终；
- 画面与剧本文本版本。

### 四、ADR

ADR适用于：

- 同期对白无法挽救；
- 台词说错、缺失或需要修改；
- 所有已有take都无法完成表演目标；
- 需要新增同语言画外台词或努力声；
- 画面与声音确需重新同步。

ADR Cue至少记录：

| Cue ID | CUT版本 | 角色／文本 | 替换原因 | 原表演参考 | 行动／潜台词 | 口型／身体／呼吸 | 同步严格度 | take／采用 | 空间／Conform |
|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |

录制时：

- 让演员看到完整上下文和原表演；
- 匹配情绪起点、终点、重音、能量与发声投射；
- 观察开口、闭口、可见辅音／元音、眼神、手势和身体；
- 保留完整take、Select与Alt，不只留下剪好的一句；
- 原始录音尽量干净可逆，不预烘焙强处理；
- 不为逐帧口型牺牲可信表演。

### 五、原始角色配音

这是AI短片最容易被误称ADR的部分。

先建立角色声音基线：

| 维度 | 记录 |
|---|---|
| 身份 | 演员、预设声音、授权克隆或其他来源 |
| 音色与声龄 | 明暗、厚薄、年龄感、性别表达和独特质感 |
| 能量与节奏 | 常态能量、语速、停顿、重音和句群 |
| 吐字与发音 | 专名、多音字、口音、方言和习惯 |
| 身体 | 呼吸、喊叫、哭笑、疲劳、运动和距离变化 |
| 情绪范围 | 平静、压力、愤怒、脆弱等可用范围 |
| 参考与版本 | 参考文件、模型／演员版本、guide／final状态 |

角色跨镜头、跨批次录制或生成时，应比较声龄、能量、情绪、发音和身体状态，不只比较音色相似度。

### 六、旁白／VO

旁白先回答它与画面是什么关系：

- 重复：画面已经说明，旁白是否多余；
- 补充：提供画面无法自然给出的信息；
- 压缩：跨越时间、背景或因果；
- 主观：进入人物记忆、判断或内心；
- 反讽／对位：声音与画面不一致，生成新意义；
- 连接：跨段落、时空或主题。

表演重点：

- 句群而不是孤立句；
- 与镜头转折、停顿、环境和音乐空间配合；
- 语速和情绪不要逐句平均；
- 不把本应由画面、声音和沉默完成的内容全部解释；
- 保持全片叙述视角、语气和能量连续。

### 七、译制配音

译制不是“把中文换成另一种声音”，而是：

原意与文化语境 → 翻译／口语化改编 → 选角 → 配音导演 → 录制 → 对白编辑 → 口型与表演 → 与M&E融合 → 目标语言审看。

判断：

- 原意和自然口语通常高于机械逐字对应；
- 关键可见嘴型提高同步权重；
- 呼吸、反应、努力声和身体状态也属于表演；
- 原版画面、对白清单、专名表、M&E和版本必须对应；
- 当前个人短片没有本地化需求时，可明确标记不适用，不必建立完整国际管线。

### 八、口型只是表演同步的一部分

至少同时检查：

- 开口与闭口；
- 明显辅音、元音和嘴形；
- 眼神、手势、姿态和身体用力；
- 呼吸、停顿、哭笑和动作起止；
- 情绪起点、终点与相邻句；
- 声音与角色距离、移动和遮挡；
- 正常速度带上下文播放。

只对齐波形可能忽略身体；只追求口型又可能把语句拉伸得失去表演。可见嘴型越少，声音表演通常可以更自由；关键近景嘴型越清楚，同步权重越高。

### 九、录得干净不等于完成

后录或AI合成声音常过近、过亮、过干，像浮在画面前方。进入可混音状态前至少保留：

- 干净原始声音；
- 近／远、正／背、移动、遮挡和媒介状态；
- 室内外、车内、走廊、电话、广播等空间意图；
- 句首、句尾、呼吸、反应和动作接口；
- 可调整而非唯一烘焙的空间处理；
- 同一地点和角色跨镜头的连续性说明。

最终频谱、混响、声像、动态和响度由阶段6混音完成。

### 十、AI语音是表演资产

#### 创作与技术

- 文本、数字、专名、多音字和语义是否正确；
- 潜台词、行动、情绪、重音和句群是否成立；
- 多句之间音色、声龄、能量和情绪是否漂移；
- 呼吸、迟疑、哭笑、用力和身体动作是否存在；
- 拼字、拉伸、降噪和增强是否损伤辅音、齿音、尾音和声纹；
- 口型、手势、动作与画面速度是否可信；
- 声音是否属于当前空间；
- 输出文本是否与已确认剧本一致；
- 原始输出能否在模型更新或声音下架后定位。

#### 来源、同意与标识

至少记录：

- 真人、预设合成声音、授权声音克隆或其他来源；
- 表演者／声音身份、服务商、模型、版本、voice ID；
- 参考音频来源与允许用途；
- 输入文本、发音控制、生成日期、任务ID和可用复现信息；
- 原始输出、编辑派生和最终采用版；
- 同意证据、适用范围、期限和二次生成权限；
- 文件内已有AI标识、元数据或来源凭证。

D保存事实，不得擅自删除、伪造或隐匿已有标识。发布规则、人格、隐私、许可与地区法律由后续权利／发行环节按当时有效规则复核。

### 十二、声音模式完成条件

一个新增／替代声音进入阶段3WIP前，至少：

- 模式与来源正确，不再用“配音”笼统代替；

## 方法与案例

### 同一条声音要分开记录功能、工艺与状态

本库综合使用四个问题，补充上方入口清单：

| 维度 | 判断什么 | 不应误推什么 |
|---|---|---|
| 叙事功能 | 场景对白、内心、叙述、群体背景，来自哪个时空 | 看不见嘴不等于旁白，旁白也可能属于故事中人物 |
| 生产任务 | 原始表演建立、补录替换、语言本地化、已有素材编辑 | 后录不必都叫ADR；首次有声音也不能只凭“没有原音”排除post-sync语境 |
| 实现手段 | 真人录制、素材编辑、合成、授权声音转换 | AI不是叙事类别，也不是采用许可 |
| 当前状态 | Scratch、候选、采用、待替换，绑定哪版画面与文本 | 好听的临时声不会自动成为正式表演 |

例如，片中成年人物讲述童年往事：声音可以是“人物回顾性旁白”，由演员初次录制，暂用于粗剪。后来译制成另一语言，它仍是旁白，同时属于本地化制作；不能要求在VO与Dubbing之间只能选一个。这个例子是分类练习，不是新项目决定。

[ScreenSkills ADR岗位页](https://www.screenskills.com/job-profiles/browse/post-production/sound-studios/adr-editor-post-production/)的本次可读搜索摘录支持“补录既有或新增台词”的宽范围，正文直读受阻；本库四维记录法是综合方法，不归为该机构标准。

### 表演同步与嘴形同步怎样分别检查

先看全句的行动与关系，再标确实可见的关键锚点：发声起止、显著闭口／开口、身体用力、一次吸气或转身。正常速度的声画可信是终点，逐帧检查只是定位工具。不能要求每个中文汉字对应一个固定嘴形，也不能把原语音波形当目标语言唯一时值模板。

[Netflix译制指导](https://partnerhelp.netflixstudios.com/hc/en-us/articles/11747624732947-Guiding-Principles-of-Creative-Excellence)的Key Moments、Voice Acting与Adaptation栏目强调以画面检查同步，并兼顾自然措辞、身体能量和呼吸。其英语嘴形示例及重点段落要求属于具体译制语境，不是本库给中文AI短片设定的统一容差。

本库诊断：若起止吻合、中间却“像赶字”，先定位重音和停顿是否挤错；若嘴形可接受但角色刚跑完仍像静坐朗读，问题是身体与呼吸表演；若整句相对画面等量偏移，先查播放、版本和处理延迟，不急于重演。

修改按受损对象分流：可以先改停顿分配或选另一条完整表演；若需要改词，先回到文本批准；若必须改嘴形或镜头，回到画面责任人。时间拉伸、改词、换镜没有固定万能顺序，也不要求把整句处理到“波形完全相同”才算通过。

### 原始角色声音基线不等于固定一种情绪

角色连续性要保护“这个人怎样发声和行动”，而不是让每一句都具有相同音高、速度与强度。同一角色耳语、远距离呼喊、疲惫、克制怒气时本就会变化。跨句比较应在相近身体、距离和情境下进行；声音身份稳定与表演状态变化可以同时成立。

本库最小参照包可保留一段有上下文的中性句群和当前场景所需的反差状态，而非只有孤立的招呼语。参照附文本、角色行动、发声距离、版本与用途；这些不是强制增加的资产字段，能清楚回溯即可。后续挑选take时比较相邻句、聆听反应和情绪转折，不只听单句“像不像同一个音色”。

给配音表演的反馈宜具体到行动：“让对方留下，但不暴露你在害怕”比“更复杂、更悲伤”更可执行；不过配音导演仍需与演员探索，不能把行动动词当保证结果的按钮。若采用AI生成，提示词表达了意图不等于输出完成了表演。

### 改词、改表演、改时值怎样影响voice-first

声音先行的依赖不是只有总时长。本库构造例：原句“别开门”改成“先别开门”，两版都长两秒；字头、重音和闭口位置仍可能不同。已生成的嘴形、角色停点、反应镜头与字幕都可能受影响，不能因同长就覆盖原音。

先比较文本、发声锚点、身体锚点、情绪节拍四类差量，再由实际依赖决定回查范围。可保留旧采用声音与旧画面配对，让新声音作为候选；只有新配对被正常速度审看后才替换。并非每次音色微调都必须重做整段画面，也不能把“时长没变”当免检依据。

### 干净声音怎样接回空间与群体

“在远处说话”包括表演者怎样投射声音与听者听到的距离，两者不能靠音量旋钮完全互换。低声近讲录音加混响，未必能成为穿过街道的呼喊。先判断声源表演，再交由声音编辑／混音匹配遮挡、音色、反射和背景；原始声音和处理版本均保留。

Walla中的可辨识句子可能泄露线索、地点或态度。需要观众理解的一句不宜只当无内容的人群底；应检查文本和具体出现位置。反过来，不能让每个人群声都成为抢夺前景的清楚对白。是否需要另录群体、做本地化或拆独立轨，由实际叙事与交付需求决定。

本轮未刷新原文法律或平台条款，也未验证任何声音服务、声音克隆或授权；原链接仅保留历史依据，实际采用前仍须单独核验。

### 声音模式分流法

1. 这条声音是否已有原始角色表演？
2. 如果有，是编辑已有素材，还是同语言替换／新增？
3. 如果没有，它是在第一次建立角色声音，还是承担旁白？
4. 是否更换语言？
5. 是否只是临时驱动画面或审看？
6. 可见口型、身体动作和声音驱动画面的程度如何？
7. 选择voice-first、picture-first或迭代路线。
8. 建立Line／Cue、表演目标、来源、版本和空间状态。
9. 录制／生成多个完整take并保留原始输出。
10. 正常速度看画面、听上下文，用户决定采用。

### 静音AI角色案例

角色画面没有原声，用户首次为其生成一句台词。这不是替换既有Production dialogue，因此不应写成ADR。如果生成音频将用于驱动嘴型，它可能需要先于最终C画面；若画面已稳定，则可post-sync。无论哪条路线，都要建立角色声音基线和声音／画面版本配对。

### 画外对白与旁白反例

人物走出画框后继续与屋内角色争吵，这仍是场景对白；它来自当前行动和空间。旁白则是叙述、内心或评论层。仅仅“看不见嘴”不能把所有画外角色台词变成VO。

### 口型过拟合反例

一句AI语音被强行时间拉伸以贴近嘴型，结果辅音模糊、重音错位、情绪被拉平。应比较重新录制／生成、调整停顿、重新口型、改变镜头选择或受控解锁，而不是把技术同步自动放在表演之上。

## 对我的创作有什么启发

- “配音”不是一个专业问题，而是一组完全不同的生产模式。
- 声音可能是画面的上游表演基准；把D理解成永远最后做声音会伤害AI口型和节奏。

- 口型只是表演同步的一部分，身体、呼吸、重音和空间同样重要。
