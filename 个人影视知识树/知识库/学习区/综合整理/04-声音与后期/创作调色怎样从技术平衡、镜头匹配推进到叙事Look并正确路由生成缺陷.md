# 创作调色怎样从技术平衡、镜头匹配推进到叙事Look并正确路由生成缺陷

> 本主题研究已经进入D后期的真实画面怎样先通过版本、Conform和色彩解释检查，再完成技术平衡、场景内镜头匹配、叙事Look、局部塑形、纹理统一和审看批准；同时判断AI画面问题究竟属于Grade、VFX、Online还是必须返回C重新生成。它不替代前期光线、材质、美术、表演和镜头设计，也不宣称尚未发生的真实项目验证。

## 快速认识

- 核心问题：怎样避免把调色压成“套一个滤镜”，既不让技术偏差破坏连续性，也不把有意的光线、天气、时空和主观色彩全部中性化。
- 主要结论：专业创作调色依靠“权威画面基线—正确色彩解释—技术平衡—场景匹配—叙事Look—局部校正—纹理统一—协同审看—阶段QC”逐层推进。
- 学习价值：能区分修正非意图偏差与创造叙事外观，能选择Hero或多个参考锚点，也能判断AI缺陷何时不应继续靠调色遮掩。
- 适用环节：Picture Lock或明确先行基线之后的调色准备、镜头匹配、创作Grade、VFX／Online协作和阶段5交接。

## 核心命题

创作调色不是把每个镜头独立“调得好看”，而是在正确色彩管线中保护并发展整部作品的视觉意图：

~~~text
唯一画面基线与Conform
→ 输入、工作、输出色彩关系明确
→ 修正非意图性的曝光、白平衡和色彩偏差
→ 按场景、光线与叙事状态建立镜头连续
→ 形成可描述、可比较、可批准的叙事Look
→ 对人物与关键物体做必要的局部塑形
→ 统一真实、VFX与AI素材的纹理和时间表现
→ 逐镜、逐场和全片审看
→ 输出可继续Online与最终汇合的阶段5交接
~~~

技术平衡提供可靠起点，不要求所有画面变成中性；创作调色建立有意差异，也不能把错误解释、错误Conform或生成缺陷美化成风格。

## 适用边界

- 本主题以唯一CUT、正确源媒体和明确VFX版本为前提；画面顺序、时长或素材身份仍不稳定时，只能做Look测试或先行Grade。
- 调色可以重组已有图像的亮度、反差、饱和度、色相、局部注意力和纹理，不能可靠补造不存在的光源方向、阴影几何、材质反射、天气物理、动作或表演。
- 已经真正裁切的高光、死黑、严重压缩和缺失像素未必能够恢复；工具显示“可拉回”不等于信息真实存在。
- 高低调、软硬调描述画面关系，不是固定数值、LUT名称或情绪公式。
- 肤色、白平衡、曝光、对比、饱和和色相都没有脱离人物、光源、场景与叙事的唯一正确目标。
- 局部校正和跟踪必须在运动中验证；单帧蒙版正确不等于整段可用。
- Day-for-night、天气转换和主观段落可以在Grade中推进，但需要新物体、新阴影、新粒子或复杂合成时必须路由VFX；根本内容错误则返回C。
- ACES、ASC CDL、LUT和AMF都是条件性工具，不是每个个人短片必做，也不互相替代。
- 阶段5不完成字幕、图文、声音汇合、最终母版、平台转码或发行QC。
- 本主题尚未在用户真实AI短片、真实校准显示器或真实跨软件管线中验证。

## 内容导览

### 整体脉络

- 准备：确认CUT、源媒体、VFX、时间线和色彩变换都可复核。
- 意图：用Look Bible、参考静帧和反例把摄影、美术与导演目标转成可审看的约束。
- 平衡：先修正非意图偏差，再决定叙事色彩；不机械中性化。
- 匹配：以Hero或多个锚点维护场景、人物、关键物体和时间连续。
- 塑形：用全局和局部调整引导注意，跟踪必须全时长验证。
- 转换：把日夜、天气、时空和主观变化当成有状态、有转变点的叙事设计。
- 路由：区分Grade可解、VFX／Online可解和必须返回C的AI缺陷。
- 完成：在明确监看条件下完成版本化审看、批准、QC和阶段5交接。

## 知识单元

### 一、调色开始前先证明画面基线正确

正式Grade最低需要：

- 唯一CUT ID、帧率、起始时码和时长；
- 已Conform到正确高质量源，而不是仅凭代理外观判断；
- 镜头ID、源内容版本、VFX版本和时间线事件能够对应；
- 裁切、缩放、重构图、变速、稳定和临时效果状态明确；
- Input、Working、Output色彩关系及LUT／CDL／AMF的应用位置明确；
- 临时烘焙Look、代理显示Look和最终Grade之间没有重复套用；
- 参考画面能够与调色时间线逐镜核对。

如果时间线事件错误、素材重连错误或VFX版本过期，继续精修颜色只会把错误版本做得更漂亮。阶段5发现这类问题应先返回Conform，不用Grade遮住。

### 二、前期Look、美术与后期调色共同塑造画面，但责任不同

| 前期／现场建立的物理事实 | 后期调色可继续发展的关系 | 后期不能可靠补造 |
|---|---|---|
| 场景、服装、妆发、道具与材质 | 色彩层级、材质分离、主体与背景关系 | 不存在的材质反射、湿润感或表面结构 |
| 光源方向、光质、光比与阴影 | 明暗重心、反差、局部注意和色温关系 | 新光源方向、复杂阴影几何和真实遮挡 |
| 曝光、镜头、滤镜、雾气和天气 | 高光／阴影分配、色彩密度、空气感 | 已丢失动态范围、新天气粒子和环境运动 |
| 表演、动作和摄影机运动 | 通过局部亮度与色彩引导观众看见关键表演 | 缺失动作、错误身份、口型、手部和表演转折 |

调色是摄影、美术和导演意图的后期延续，不是对前期失败的无限补救。中传P73-P74也强调：影调由光线、材质、色彩、场景、曝光和后期共同形成，不能只靠末端滤镜。

### 三、技术平衡与创作调色是两种判断

| 层级 | 核心问题 | 典型动作 | 通过条件 |
|---|---|---|---|
| 色彩解释 | 软件是否在正确理解素材 | 明确Input、Working、Output、范围和烘焙状态 | 同一素材在约定管线中可重复显示 |
| 技术平衡 | 是否存在非意图性的曝光、白平衡、色偏或机位差 | 调整曝光关系、白平衡、对比、饱和和通道平衡 | 镜头可作为可靠的创作起点 |
| 镜头匹配 | 相邻镜头是否属于同一场景和状态 | 围绕参考锚点统一亮暗、色温、肤色、物体和纹理 | 剪切时无意外跳变，有意差异仍保留 |
| 创作Grade | 画面怎样服务人物、时空、情绪和主题 | 设计影调、色彩弧、局部注意和段落变化 | Look能被描述、比较并由用户批准 |

“平衡”不是把夕阳、霓虹、绿色荧光、主观眩晕或低调场景校成白墙中性；它只移除与已确认意图无关的偏差。

### 四、曝光、白平衡、对比、饱和与色相没有固定目标

| 维度 | 技术检查 | 创作判断 |
|---|---|---|
| 曝光 | 是否误解释、意外漂移、裁切或无法与源对应 | 人物和空间应落在哪个亮度关系，哪里允许看不清 |
| 白平衡 | 是否有非意图色偏、机位或批次不一致 | 光源本来是暖、冷、混色还是主观偏色 |
| 对比 | 是否出现非意图性压黑、爆白或相邻镜头断层 | 高低调和软硬调怎样塑造力量、亲密、危险或距离 |
| 饱和 | 是否因变换、编码或机位产生异常跳变 | 哪些颜色应活跃、克制、衰退或只在关键物体保留 |
| 色相 | 是否发生错误偏移、肤色或物体身份不连续 | 主题色、对照色和时空状态怎样发展 |

Scopes用于稳定测量和发现异常，但不会知道一个暖色偏是错误还是落日，也不会替用户决定低调画面该保留多少黑。冻结单帧也不能替代运动和上下文审看。

### 五、Look Bible是人可读的创作契约

Look Bible没有统一行业模板。OPC的一页式版本至少写清：

| 维度 | 最小内容 |
|---|---|
| 作品命题 | 色彩和影调怎样服务人物、关系与世界，不承担什么 |
| 影调坐标 | 主要段落的高／中／低调与硬／中／软调组合 |
| 色彩关系 | 主色、辅色、对照色、肤色与关键物体的保护原则 |
| 场景状态 | 日夜、天气、时空、客观／主观及其转变点 |
| 视觉重点 | 观众此刻首先看见谁或什么，哪些区域应退后 |
| 纹理 | 噪声、颗粒、锐度、柔化、真实／生成层的统一目标 |
| 参考 | Hero／Multiple Anchors、参考静帧、反例和禁止模仿项 |
| 技术上下文 | 参考画面的Input／Output、是否烘焙、显示目标和版本 |
| 批准 | 唯一创作批准者、当前版本、开放问题和停止条件 |

Look Bible回答“为什么和应当看起来怎样”；CDL、LUT或节点工程回答“部分变换怎样实现”。二者不能合并成一个文件。

### 六、P73-P74的高低调与软硬调必须分轴

| 维度 | 主要观察 | 常见误解 |
|---|---|---|
| 高调／中间调／低调 | 画面大面积亮度分布与整体明暗重心 | 高调等于过曝，低调等于死黑 |
| 硬调／中间调／软调 | 最亮与最暗的反差及中间过渡方式 | 硬调等于锐化，软调等于模糊 |

两个维度可以组合：

- 高调硬调：整体明亮，但明暗或色彩边界强烈；
- 高调软调：浅色面积大、过渡柔和；
- 低调硬调：暗部占主导，以强方向光和亮点分离主体；
- 低调软调：整体偏暗，但层次和过渡平缓；
- 中间调：不等于没有风格，而是亮度和反差保持相对均衡。

任何影调都要保留叙事所需的主体、空间和材质层次。亮处或暗处成为视觉中心，取决于它与大面积基调的关系，而不是某个固定曝光值。

### 七、Hero Shot与Multiple Anchors提供匹配坐标

Hero Shot通常应：

- 能代表当前场景主要光源、背景、人物、服装和美术；
- 曝光与白平衡没有极端技术问题；
- 靠近最终创作方向，不需要其他镜头为匹配它而严重扭曲；
- 具有足够可比较元素；
- 绑定明确镜头、时间码、CUT、源／VFX和Grade版本。

宽景往往包含更多光源与场景信息，适合成为Hero，但不是强制。如果场景跨窗边与室内深处、晴转阴、火光与普通照明，或正反打存在合理方向差异，就应使用多个锚点：

| Anchor | 代表状态 | 用来约束 |
|---|---|---|
| A | 日间外景主状态 | 天空、地面、人物与环境亮度关系 |
| B | 室内主状态 | 墙面、窗光、肤色与暗部层次 |
| C | 叙事转折／主观状态 | 色彩偏移、反差变化与回归点 |

Multiple Anchors避免把一个极端镜头强行复制到所有机位，也让有意变化保持可追踪。

### 八、Shot Match匹配的是场景逻辑，不是图表完全相同

逐场匹配至少比较：

1. 黑位、白位和中间亮度的相对关系；
2. 主光、环境光和有意色温；
3. 反差、软硬过渡与主体分离；
4. 肤色、服装、道具和关键叙事物体；
5. 天空、墙面、地面、植被等稳定环境；
6. 饱和密度、色相家族和主题色；
7. 锐度、噪声、颗粒和VFX纹理；
8. 前后镜头中的动作、视线和时间连续。

自动Shot Match可以提供起点，但算法无法知道天气变化、光源方向和故事状态。真正验收发生在正常速度、带前后镜头的场景中；直方图或RGB完全相同反而可能抹掉景别、角度和光线方向应有的差异。

### 九、肤色与关键物体是连续锚点，不是固定色卡目标

肤色检查同时考虑：

- 人物真实肤色与底色差异；
- 光源颜色、环境反射、妆容和服装污染；
- 景别、面部转向、阴影和运动；
- 曝光、色相、饱和和面部内部层次；
- 同一人物跨镜头、跨场景和跨时间的连续；
- 当前叙事是否有意让肤色偏冷、偏暖、衰败或不自然。

Vectorscope肤色指示线只能帮助发现明显绿、洋红或黄色偏移，不能规定所有人物必须落在同一条线。关键物体也类似：血迹、手机屏幕、药瓶、信号灯或角色服装应保持身份与叙事可读，但不必在每个光源下显示成同一RGB值。

### 十、局部校正用于引导注意，跟踪决定它是否成立

适合局部校正的情况：

- 提亮或压暗人物面部与重要动作区域；
- 保护肤色，同时允许整体Look发生偏移；
- 控制过度抢眼的背景、天空、服装或道具；
- 让关键物体在不破坏场景光线逻辑时可读；
- 平顺局部曝光、颜色或VFX接缝。

跟踪后必须完整播放检查：

- 遮挡、转身、快速动作和出入画；
- 蒙版边缘、羽化、漏选和颜色污染；
- 画面抖动、缩放、透视变化和变形；
- 局部亮度或饱和是否出现“贴在物体上”的人工感；
- 处理是否跨过剪点或错误跟随另一个对象；
- 降噪、锐化或纹理是否让边缘闪烁。

当局部修正开始重建物体、替换天空、制造阴影或大面积逐帧修补时，应重新判断它是否已经属于VFX或Online。

### 十一、时间连续既包括稳定，也包括有意变化

| 状态 | 调色目标 | 不能做什么 |
|---|---|---|
| 同一连续场景 | 让光线、人物、关键物体和纹理保持可信 | 把相邻镜头独立调成各自最漂亮 |
| 日到夜／夜到日 | 建立明确转变点、亮度层级、色温和可读性变化 | 只压暗加蓝，忽略光源、阴影和人物反应 |
| 晴到阴／天气变化 | 统一天空、环境、材质和人物受到的光线逻辑 | 只改天空颜色，却保留矛盾地面与阴影 |
| 不同时空 | 让每一时空有可辨规则，同时保留作品共同语言 | 每场任意换滤镜而无回归逻辑 |
| 主观／梦境／记忆 | 明确进入、内部发展和退出，允许偏离客观连续 | 用“主观”解释无意闪烁、失配或错误变换 |

创作连续不等于视觉完全不变。真正要连续的是规则、变化原因和观众能否理解当前状态。

### 十二、纹理是运动中的画面关系

纹理包含：

- 原始噪声或胶片颗粒；
- AI生成的塑料感、过度平滑、局部细节漂移；
- VFX与实拍之间的锐度、噪声和边缘差；
- 去噪、锐化、上采样、压缩和重编码产生的派生痕迹；
- 有意的颗粒、柔化、光晕或模拟介质质感。

处理原则：

1. 先保留原件和派生关系，不把降噪烘焙进唯一源。
2. 先解决会干扰Key、Tracking和VFX的技术噪声，再完成合成。
3. 在真实交付分辨率和正常运动中判断纹理，不只看放大静帧。
4. 若移除原始颗粒，VFX或合成后可能需要受控恢复，使画面重新属于同一介质。
5. 颗粒强度、尺寸和颜色没有通用配方；来源、景别、缩放、亮度和输出都会改变感受。
6. “有颗粒”不等于电影感，“无噪声”也不等于高质量。

### 十三、AI生成缺陷必须通过路由门

| 症状 | Grade可处理 | 路由VFX | 返回C重生成／补镜 | 路由Online |
|---|---|---|---|---|
| 非意图色偏、曝光或饱和跳变 | 有足够信息且不破坏人物与材质时平衡 |  | 根本光线和材质逻辑在所有版本中都错误 |  |
| 人物与背景分离不足 | 合理局部塑形与跟踪 | 需要复杂Roto、重光或新阴影 | 缺少可信光线、表演或构图基础 |  |
| 手、脸、道具身份漂移 | 只能减弱注意，不能伪造修复 | 局部重建、替换或合成可控时 | 漂移持续、改变角色或动作事实时 |  |
| 闪烁、纹理游走、局部融化 | 轻微亮度／色彩波动可尝试 | 时间修复、清理或重投影 | 整段运动和物理均不可信 |  |
| 天空、雨雪、雾、反射错误 | 统一已有元素的色彩与密度 | 新天气、天空替换、粒子、反射合成 | 场景状态和角色反应根本不成立 |  |
| 错误裁切、缩放、重构图或版本 | 只检查Grade没有掩盖问题 | 复杂画面扩展时 | 缺少必要构图和镜头功能时 | Conform、重构图、缩放和版本汇合 |
| 图文、字幕、法律遮挡 | 不应在Grade里永久烘焙 | 特殊图形合成时 |  | Online建立、替换与最终检查 |

判断顺序不是“哪个工具能做”，而是：

1. 问题是否只改变颜色、亮度、局部注意和纹理；
2. 修复是否需要补造原画面没有的内容、重建物体／阴影或逐帧修补，而非仅改变已有像素的颜色数值；
3. 问题是否改变人物身份、动作、表演、空间或镜头功能；
4. 问题是否只是时间线、缩放、图文和版本汇合；
5. 哪个岗位拥有最终修改、版本与复核责任。

### 十四、Reference Still、CDL、LUT与AMF各自只保存一层

| 载体 | 保存什么 | 使用前必须知道 | 不能替代 |
|---|---|---|---|
| Reference Still | 某镜头在特定观看管线下的目标外观 | Shot／TC、CUT、Grade、Input／Output、是否烘焙、批准者 | 可重建的完整色彩配方和运动连续 |
| ASC CDL | Slope、Offset、Power、Saturation等基础主校正 | 工作空间、应用顺序、镜头对应和版本 | 局部蒙版、跟踪、复杂Look、纹理、时间线和notes |
| LUT | 对输入数值做固定映射 | 预期输入／输出色彩空间、范围、顺序、显示目标 | 逐镜平衡、环境识别、局部修复和批准 |
| ACES AMF | ACES Input／Look／Output等管线“配方或回执” | ACES版本、外部Look文件、applied状态和镜头关联 | EDL、镜头状态、VFX版本和完整调色工程 |
| Look Bible | 人可读的创作目的、规则、参考、反例与批准 | 当前版本、适用段落和开放问题 | 精确运算和媒体文件 |

参考静帧可能已经烘焙全部变换，只能告诉人“目标看起来怎样”；LUT可能只描述一个固定映射，却不知道当前镜头是谁。真正可追溯的Look交接需要视觉参考、变换上下文、镜头身份和人类批准共同存在。

### 十五、导演、摄影指导与调色师审看的是同一精确版本

专业协作的功能可以压缩，但不能消失：

| 角色功能 | 核心责任 |
|---|---|
| 导演／用户 | 判断人物、叙事、时空、主观性和最终创作采用 |
| 摄影指导／视觉意图持有人 | 说明曝光、光线、镜头、材质和现场Look原意，识别被后期误改的关系 |
| 调色师 | 把意图转成连续、可实现、可审看的Grade，并指出技术与素材限制 |
| VFX／Online／后期统筹 | 处理各自问题、维护版本、Conform和最终汇合 |

审看记录最低包含：

Grade版本｜CUT／VFX版本｜显示与Output状态｜时间码／镜头｜可观察症状｜意图判断｜修改方案｜复看结果｜采用／拒绝／待定｜批准者。

IMAGO强调摄影指导参与调色的重要性，但现实审批权仍受合同、地区和项目结构影响；OPC不把某一地区职业主张写成全球统一权力规则。

### 十六、停止条件是已批准、可复核，不是“再也调不动”

阶段5可以停止时：

- 所有镜头都属于正确CUT、源媒体和VFX版本；
- 色彩空间、变换、LUT／CDL／AMF与烘焙状态明确；
- 关键场景有Hero或Multiple Anchors，匹配与有意例外有记录；
- 肤色、关键物体、局部校正和跟踪已在运动中复核；
- 日夜、天气、时空和主观段落的规则、转变与回归成立；
- 纹理、锐度、噪声与VFX接缝无未声明跳变；
- 逐镜、逐场和全片在约定观看条件下完成审看；
- Grade版本notes已经关闭、接受或明确待决；
- 用户批准精确版本，残余风险和监看限制有记录；
- 实际渲染与时间线参考核对，交接文件可定位和可恢复。

期限迫使停止时，应写“因期限停止及残余风险”，不能把未解决问题改名为创作选择。阶段5批准也不等于最终图文、声音、母版和发行QC通过。

### 十七、阶段5交接面向Online与最终汇合

最小交接包含：

- 唯一CUT、Grade版本、帧率、时码、时长和参考画面；
- 已Conform源、VFX版本及镜头／时间线身份；
- Input／Working／Output关系和所有应用／烘焙变换；
- Look Bible、Hero／Multiple Anchors和批准状态；
- 调色工程或可恢复配方，以及项目真正使用的CDL／LUT／AMF；
- 镜头调色状态、局部校正、跟踪、纹理和已知限制；
- Grade WIP／审看导出与最终阶段5参考导出；
- VFX／Online问题、Reconform状态和开放notes；
- 文件Manifest、必要哈希、依赖和恢复说明；
- 目标端导入、同步、变换与画面一致性检查。

没有使用ACES就不伪造AMF，没有使用CDL／LUT就不为“专业感”额外制造文件。交接目标是让下游知道哪个版本、怎样观看、怎样恢复和哪些问题仍开放。

## 方法与案例

### 平衡、匹配与Look是判断层，不必是固定节点顺序

前文流程用于区分问题，不要求先把所有镜头调成中性、关闭Show Look后逐镜完成，再到最后加风格。若创作从前期已经通过特定Look观看，调色可以在该Look下做平衡和匹配，并反复往返；关键是记录哪些修正属于镜头，哪些属于场景／全片规则，避免重复烘焙。

本库比较法：固定同一管线和Output，保留参考版本，分别检查“仅单镜修正”“共享Look影响”“局部选区影响”。若每个镜头都需要反向大幅补偿共享Look，先问Look或输入是否不适合这批源，而不是继续加更多局部修正。正常操作会改变许多数值；岗位路由应看是否重建内容、时间或创作事实，不能用“产生新像素”这句话把所有调色都判为VFX。

### 匹配先找可比对象，再比较剪切感觉

宽景与近景的面积构成不同：近景中一张脸占大部分画面，宽景可能主要是黑墙与窗户。即使同场照明完全连续，整体直方图也不会相同。先选相同或具有可解释关系的区域，区分漫反射表面、镜面高光、阴影和不同方向的受光，不能拿背光侧脸去追正面高光的数值。

[Blackmagic官方Color页](https://www.blackmagicdesign.com/products/davinciresolve/color)说明自动匹配、曲线、参考与局部工具的功能；下面是本库的比较顺序，不是软件保证：先看整场亮暗与色温关系，再用同对象／同受光区域确认差异，最后回到实际切点判断观众是否感到无意跳变。没有可靠中性物或色卡时，不凭“墙应该是白的”建立白平衡事实。

教学构造：暖窗前A近景与冷走廊B近景反打，匹配目标可以是面部可读性和各自环境关系，而非把两人改成同一肤色数值。若B镜头偶发一帧变绿，要另查帧间变化或源错误，不能用“走廊本来冷”解释突变。

### Qualifier与Tracking解决不同问题

Qualifier（颜色／亮度选区）按当前像素特征选中范围；Window（空间窗口）限定画面区域；Tracking（跟踪）让区域随运动变化。窗口位置跟上脸，并不证明颜色键稳定；角色转头、阴影掠过或压缩噪声变化，可能使选区忽然漏掉皮肤或选中背景。

本库检查：先看Matte本身，再看合成结果；检查遮挡前后、运动峰值、出入画和切点。若蒙版边缘呼吸，先区分跟踪位置、颜色键抖动、羽化与源纹理游走；不要只把羽化拉大掩盖问题。修正须同时保护动作、眼神和面部层次，不能只看选区是否整齐。

### 时间降噪与纹理统一要看“保留了什么”

Blackmagic官方说明区分：时间降噪分析多帧，空间降噪处理单帧邻域。本库据此要求不同的风险检查：前者重点看移动细节、遮挡与新露出的区域，后者看细纹理和边缘是否被磨掉。它们可能改善噪声，却不能保证修复AI身份或材质在帧间改变的问题。

把皮肤平滑后再加颗粒，并不会找回先前丢掉的细节；颗粒只是新的视觉层。对比应包括原片、最小处理与候选终版，在交付尺度和正常速度观察眼睛、头发、织物、天空渐变及VFX接缝。没有颗粒或噪声并非错误，有意颗粒也不免除对闪烁和重复图案的检查。

### 缺陷归因要比较变化首次出现的位置

本库最小隔离法：固定同一帧段，比较父源、无创作Grade的已正确解释版、带Grade版及实际渲染。若绿边只在半透明元素经颜色处理后出现，先查预乘与通道处理；若在父源就有形变，不能怪输出标签；若只在最终编码出现条带，回查编码／位深与上游渐变，不能直接要求重做表演。

不同显示设备的差异也不全部是成片错误。先核对同一文件和观看路径，再记录显示限制；修正主参考版本和做消费设备兼容检查是不同动作。当前没有实际媒体、显示测量或观众测试，以上只形成可执行检查方法。

### 跨软件创作调色法

1. 接收唯一CUT、参考画面、源媒体、VFX清单和变更记录。
2. 逐镜核对Conform、裁切、缩放、变速和效果，先解决错误版本。
3. 明确Input、Working、Output、显示目标和所有烘焙／旁挂变换。
4. 从摄影、美术、导演意图与P73-P74影调框架制作一页Look Bible。
5. 按场景和光线状态选择Hero或Multiple Anchors。
6. 先做技术平衡，修正非意图曝光、白平衡、色偏和机位差。
7. 在场景上下文中完成Shot Match，保留有意光线方向和状态变化。
8. 建立叙事Look，再对人物、关键物体和背景做最少必要局部校正。
9. 全时长检查跟踪、边缘、闪烁、纹理和VFX接缝。
10. 对残余AI缺陷执行Grade／VFX／C／Online路由，不用一种工具承包所有问题。
11. 用版本化notes完成导演／摄影／用户审看，逐镜、逐场和全片复核。
12. 完成实际渲染QC，输出阶段5交接，不宣称最终母版完成。

### 对话场景的Multiple Anchors案例

同一场对话一侧人物靠近暖窗光，另一侧处于冷色走廊，宽景同时包含两种光源。若只把宽景当唯一Hero并复制其平均白平衡，两个近景都会失去合理方向。

更合适的做法是：

- 用宽景约束空间总体亮度、背景和两种光源关系；
- 用人物A近景约束暖窗光下的肤色与面部层次；
- 用人物B近景约束冷走廊下的肤色与环境分离；
- 在正反打中保持人物身份连续，但不把两侧校成同一色温。

### 低调不等于死黑的案例

AI夜景素材整体很暗。若继续压黑以制造“电影感”，人物手部、门口和关键道具全部消失。应先依据P73-P74判断：低调看暗色面积，仍需用亮点、材质和空间层次引导注意。若源文件没有任何可恢复层次，则应返回C重生成或由VFX补光／重建，而不是把缺失信息称为风格。

### Day-for-night反例

白天素材简单压暗、加蓝后，人物脚下仍有正午硬阴影，天空和地面亮度关系没有改变，皮肤与眼神也缺少夜间光源逻辑。这不是完整夜景转换。Grade可建立亮度和色彩方向；新天空、阴影重建、灯光和环境元素需VFX；若人物表演、构图和曝光从源头都不支持夜景，应返回C。

### 肤色线反例

人物处于绿色荧光灯下，Vectorscope显示肤色偏绿。若机械拉回肤色指示线，人物会像被单独贴在场景上，也会破坏灯光叙事。正确判断是先确认绿光是否有意，再维护人物内部层次、可读性和跨镜头连续；只有非意图污染才修正。

### AI身份漂移路由案例

角色脸部在镜头中段逐渐变成另一张脸。局部色相或面部提亮最多只能降低注意，不能恢复身份。若漂移只在数帧且VFX能够安全替换，可路由VFX；若贯穿表演并改变角色事实，应返回C重生成。把脸压暗并宣称修复，会把叙事问题藏进Grade。

### 双套LUT反例

剪辑代理已烘焙Show LUT，调色工程又按Log素材再次套用同一LUT，画面出现过度反差和饱和。继续逐镜“救颜色”会制造大量无意义修正。应先确认调色使用的是OCF还是代理、Look是否烘焙、变换顺序和Output状态，再重建正确管线。

## OPC与Agent分工

| 工作 | Agent可主做 | 必须由用户确认 |
|---|---|---|
| 版本与Conform | 比较CUT、源媒体、VFX、时码、裁切和变更候选 | 哪个画面版本是权威基线 |
| 色彩管线 | 读取标签、列Input／Working／Output和双套变换风险 | 未知来源如何处理、采用哪条真实管线 |
| Look Bible | 整理影调、色彩、参考、反例和状态候选 | 作品视觉命题、禁止项和最终Look |
| Hero选择 | 按场景、光线和共有元素推荐一个或多个锚点 | 哪个镜头最代表创作意图 |
| 技术平衡 | 用Scopes和画面对比定位曝光、白平衡、色偏和跳变 | 偏差是错误还是有意光线／主观状态 |
| Shot Match | 生成镜头差异、匹配候选和连续性问题单 | 匹配到什么程度，哪些差异必须保留 |
| 局部与跟踪 | 草拟区域、自动跟踪、检测漂移和边缘问题 | 人物、物体、视觉重点和处理代价 |
| AI缺陷路由 | 按像素、时间、身份、叙事和版本列路由候选 | 是接受、VFX修、返回C还是停用 |
| 纹理 | 检测噪声、锐度、颗粒、闪烁和VFX差异 | 介质质感、颗粒强度和作者性 |
| Notes与QC | 定位版本差异、未调镜头、跟踪异常和渲染差异 | 创作批准、残余风险与停止 |

Agent只有在实际读取完整媒体、知道色彩管线、对照正确参考并留下可复核证据时，才能报告“已检查”。普通屏幕、未知显示模式或未校准环境下的判断必须注明限制，不能声称专业色彩批准。

## 常见误区

- LUT就是作品Look。
- 技术平衡就是去掉所有色偏。
- Shot Match就是让直方图、RGB或所有镜头完全相同。
- 所有人物肤色都必须贴同一条Vectorscope肤色线。
- 高调等于过曝，低调等于死黑，软调等于模糊，硬调等于锐化。
- 压暗加蓝就能把白天变夜晚。
- 局部蒙版单帧正确就代表跟踪成功。
- 调色可以修复AI人物身份、动作、表演和物理错误。
- 降噪越干净越专业，颗粒越明显越电影。
- Reference Still获批就等于整场运动和最终渲染获批。
- Colorist、VFX和Online谁能做就由谁顺手做，不必记录责任。
- 阶段5Grade批准等于最终母版和发布QC通过。

## 不能泛化的规则

- 没有通用曝光、白平衡、对比、饱和、色相和肤色数值。
- 没有通用Day-for-night、天气转换、梦境或记忆配方。
- 宽景通常适合Hero，但不是强制；一个场景也不一定只有一个锚点。
- 没有固定Look Bible格式、Grade轮数、节点结构、LUT尺寸或跟踪方法。
- ACES、CDL、LUT、AMF和专业参考显示器不是每个项目同时必需。
- Grade、VFX、Online的先后和职责会随预算、团队、软件与交付变化。
- 颗粒尺寸、强度、颜色和处理顺序服从源材、缩放、VFX与输出。
- 导演、摄影指导、制片和平台的批准权受合同、地区与制作结构影响。
- 广播Legal、PSE、HDR和平台QC阈值不能外推到所有公开短片。
- “艺术已经完成”没有客观数值；可验证的是版本、开放问题、批准、期限和残余风险。

## 对我的创作有什么启发

- Look真正的上游是人物、光线、材质和场景，不是调色软件中的预设名称。
- 技术平衡与创作偏色并不矛盾；先排除非意图错误，才能知道有意差异是否成立。
- 一个Hero Shot不能承包所有光线状态，多个锚点反而能保护真实方向和叙事转折。
- 肤色和关键物体最有价值的不是固定数值，而是人物身份、光源关系和跨镜头连续。
- AI画面越容易被工具“局部改善”，越需要先问它是否已经改变人物、动作或世界事实。
- 调色停止的证据不是画面变得更重，而是意图、版本、连续、路由和批准形成闭环。

## 复习区

### 一分钟核心摘要

创作调色从正确的CUT、Conform和色彩解释开始。技术平衡只修正非意图曝光、白平衡和色彩偏差；Hero或Multiple Anchors帮助Shot Match维持场景、人物、关键物体和纹理连续；叙事Look再用高低调、软硬调、色彩关系、局部注意和有意状态变化表达作品。Reference Still、CDL、LUT、AMF与Look Bible各自只保存一层证据。任何需要新像素、新阴影、物体重建或改变人物／动作事实的AI缺陷，都不能继续靠Grade遮掩，而应路由VFX、Online或返回C。
