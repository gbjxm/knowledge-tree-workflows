# 用过程质量而不是单次结果复盘创作决策

> 当创作结果受模型随机性、平台环境、协作者选择和观众反馈影响时，用“当时掌握的信息—假设—概率—推理—行动”评价决策过程，再把结果作为更新判断的新证据。

## 快速认识

- 核心问题：一次镜头、方案或项目成功/失败，能否直接证明当时的选择正确/错误？
- 主要结论：不能。单次结果混合了过程质量与不可控波动；稳定学习需要冻结事前判断、事后拆因并积累样本。
- 学习价值：防止把幸运参数固化成标准，也防止因一次坏结果频繁换方向。
- 适用环节：方案评审、生成测试、镜头或剪辑取舍、项目复盘、继续投入或止损。

## 核心命题

结果是证据，不是对全部过程的判决。先按当时可获得的信息评价选择，再用新结果更新判断。概率性效果需积累可比较证据；但一个明确反例足以推翻“必然成功”等绝对命题，一个确定性错误也可立即修正，不能为等待样本而延误。

## 适用边界

- 适合：结果包含随机性、信息不完整、反馈延迟或多个因素共同作用的创作判断。
- 不适合直接套用：文件损坏、参数写错、版权不清等可确定验证的技术或合规错误，应直接修正。
- 不能被误解为：只要“过程看起来理性”就不用为坏结果负责。重复失败会成为新证据，必须降低置信度、修改假设或停止投入。
- 概率限制：主观百分比是对不确定性的显式表达，不是伪装成精确统计；必须同时写依据和更新条件。

### 详细导览

#### `00:48-03:23`｜结果为什么不能单独评价决策

主要讲什么：单次结果混入运气与外部变量；高概率选择仍可能失败，低概率选择也可能获胜。

关键内容：

- 复盘对象应是当时的可得信息和推理，而不是事后已知答案。
- 频繁根据短期结果换方法，会让人永远积累不到足够样本。

复盘提示：回看一次“结果很好但过程混乱”和一次“过程扎实但结果不佳”的真实创作测试。

#### `03:24-08:42`｜把判断变成可检查的记录

主要讲什么：用置信度、信念树和决策日记保存事前判断，并暴露剩余风险与关键假设。

关键内容：

- “为什么不是更高/更低”比孤立百分比更能暴露证据。
- 记录必须发生在结果出现前，否则记忆容易被结果重写。

复盘提示：检查笔记里是否真的保存了预测、理由和改变立场的条件。

#### `08:42-14:25`｜如何抵抗自我辩护和错误坚持

主要讲什么：让可信的反方挑战决策，用未来时间尺度检查情绪，并把既有投入从继续/停止判断中剥离。

关键内容：

- 求真反馈针对决策和假设，不针对人格。
- 若没有任何证据能改变观点，就不是开放分析。
- “若今天从零开始还会不会投”可以检查沉没成本。

复盘提示：在项目评审前指定一人寻找反例，而不是所有人只优化同一方案。

## 知识单元

### 概念

- **决策质量**：在当时信息条件下，目标、选项、假设、概率、推理和行动是否合理。
- **结果质量**：最终产出是否达到目标；它受决策、执行、环境和随机性共同影响。
- **结果导向**：已知结果后倒推“当时一定对/错”，抹去不确定性。
- **信念树**：把结论拆成假设与推理节点，便于定位分歧和验证证据。
- **动机性推理**：围绕想要的结论挑选证据，使复盘变成自我辩护。

### 原则

- 决策前记录，结果后拆因；不要让结果重写事前判断。
- 概率必须连同依据、风险和更新条件一起写。
- 一次结果只增加一个样本，不轻易把偶然经验升级为规则。
- 直觉可以作为输入，但要接受概率、反证和边界审查。
- 继续或停止只看未来增量，不用已投入成本替未来做决定。

### 方法

#### 一张创作决策卡

| 时点 | 字段 | 要写什么 |
|---|---|---|
| 事前 | 问题与目标 | 这次到底要解决什么，怎样算有效？ |
| 事前 | 方案与基线 | 当前方案、备选方案和比较基线是什么？ |
| 事前 | 信息与缺口 | 已知什么、还不知道什么？ |
| 事前 | 假设与推理 | 哪几个假设支撑当前选择，链条哪里最脆弱？ |
| 事前 | 概率与风险 | 成功把握多大，为什么不是更高/更低，剩余风险是什么？ |
| 事前 | 更新条件 | 出现什么证据时改变、暂停或停止？ |
| 事后 | 结果与拆因 | 结果如何；可控过程、执行、环境和随机性分别贡献了什么？ |
| 事后 | 判断更新 | 保留、降低或提高哪个假设的置信度；下一次只改什么？ |

#### 三个偏差检查

1. **反证检查**：什么证据会改变我的看法？若答案是“没有”，先停止辩护。
2. **时间旅行**：10 分钟、10 个月、10 年后的我会如何评价这次选择？
3. **从零开始**：如果此前没有投入时间、钱和情感，我今天还会继续吗？

#### 求真评审规则

1. 先建立信任，明确目标是发现漏洞而非证明谁更聪明。
2. 评审只针对信息、假设、概率、推理和行动，不评价人格。
3. 指定反方追问剩余风险、证据来源和遗漏环节。
4. 被挑战者必须给出可改变立场的条件，并感谢有效反证。

### 案例

- **AI 镜头生成**：一条画面偶然很好，不立刻把整段提示词固化；先比较基线、随机种子、参考资产、动作约束与模型波动，再做重复测试。
- **剪辑取舍**：一次试映反馈差，不立即否定剪辑策略；检查样本是谁、核心问题是否一致、信息还是节奏导致理解偏差，再更新判断。
- **项目止损**：已经做了很多资产不是继续制作的充分理由；从当前节点比较继续、重构和停止的未来成本与收益。

### 反例、边界与开放问题

- 反例：作品播放量高，就把所有创作选择都视为正确；播放量低，就推翻叙事、视觉和发布方法。
- 反例：给判断随手写一个“70%”，却没有依据、剩余风险和更新条件。
- 开放问题：在 AI 影视工作流里，至少需要多少个可比较样本，才能把一次提示词或镜头经验升级为默认方法？
- 待核验：不同模型版本和随机种子对结果方差的实际影响，需要由项目数据而不是视频类比验证。

## 方法与案例

### Outcome bias与合理使用结果的区别

[Baron与Hershey 1988研究摘要](https://pubmed.ncbi.nlm.nih.gov/3367280/)描述，在既有决策信息相同而结果不同的情境中，评价者会因好坏结果改变对思考质量的评价。本轮只读摘要，不把其实验任务直接等同于AI短片生产。

避免结果偏差，不是把结果排除在学习之外。先冻结事前目标、可选方案、可得信息与理由；再把实际执行、未预料事件和结果分别记录。若事前承诺的关键前提被推翻，就应改判断；不能把所有坏结果归于运气以保护原方案。

### 样本、选择和不确定性要一起报告

本库构造：五次生成选中一条，观察到的是本次5条中的1条满足当前标准，不是已经知道长期成功率就是20%。只保存赢家会看不到选择偏差；同一批参考、同一服务状态产生的输出也未必完全独立。

有多少样本才够，取决于要发现多大差异、失败代价、结果波动和决策用途，没有统一“生成三次就稳定”的门限。可报告原始数量、条件、失败类别和不确定性；样本很少时不伪造精确置信。制作中需要及时选片时，可以在明确限制下采用，不将其提升为普遍方法。

### 止损比较未来增量，不抹掉现存资产价值

沉没成本不该强迫继续，但已经得到的可复用资产、知识、合同义务和当前撤出成本会影响未来选项。问“若从零开始还做不做”有助打断情绪辩护，却不能真的把这些现时条件全部删掉。

本库比较继续、局部改法、换工具、缩减范围与停止的未来收益、成本和不可逆风险。一次试验若不能改变任何选项，也不能提供关键新信息，就未必值得追加。停止条件应针对现实任务，不是为了维护某个好看的成功率。

### 评审先区分观察、解释与处方

“观众第12秒误认人物”是观察；“因为反打缺共同参照”是原因假设；“加一个全景”是方案。多人同意一个方案，不证明原因已确定；一人指出可核对的道具矛盾，也不必等待多数票。

先收集相对独立的观察再讨论，记录反证和未采纳意见。熟悉创作意图的人与初看观众任务不同；模型自评、同上下文问答和真人盲看也不是同一证据。新补充见[[知识库/创作区/岗位共用/创作实践专业优化/01-知识迁移、实验比较与决策复盘]]，仍不升级原有个人掌握或实践状态。

把决策卡和已有“问题—基线—主要改动—结果—判断—回写”迭代记录配合使用：决策卡保存结果出现前的依据，迭代记录保存结果出现后的证据。前者防止事后合理化，后者让概率和假设能够持续更新。

## 复习区

### 一分钟核心摘要

单次结果由决策、执行、环境和运气共同造成。重要选择要在事前记录信息、假设、概率、风险、推理和更新条件；事后再拆开过程与结果，用多个样本更新方法。概率不是精确伪装，复盘也不是为坏结果开脱：重复失败必须降低置信度或触发止损。

### 关键概念

- 决策质量与结果质量
- 结果导向
- 概率表达
- 信念树
- 决策日记
- 动机性推理
- 沉没成本
