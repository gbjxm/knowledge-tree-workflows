# 从梗概到可拍大纲

> 当故事已经能被讲清楚，却还不能直接写成场景时，用这篇笔记把人物判断、关系状态和主题变化翻译成可见、可听、可推进的事件。

## 快速认识

- 核心问题：梗概和正式剧本之间缺少怎样的翻译层。
- 主要结论：大纲的价值不在文采，而在于把抽象判断转换成场面、行动、因果和结构关节。
- 学习价值：能在写对白和细节前发现动机、递进、转折和人物变化是否成立。
- 适用环节：故事骨架完成之后、分场和剧本正文之前；写作卡住时也可反查。

## 核心命题

大纲把故事构想组织成可继续写作、讨论和检查的行动与信息顺序。关键抽象判断应说明将由哪些可见、可听的事件让观众理解，以及如何影响后续；概括性说明仍可帮助读者理解意图，不要求每一句都写成镜头或动作。篇幅和详细程度按使用目的决定。

## 适用边界

- 适合：人物目标和故事结局已有大致方向，需要把结构转成场面。
- 不适合：核心前提、主角欲望和主要阻力仍未确定时，过早扩写只会制造细节债务。
- 常见误解：可拍不是堆视觉形容词；十个序列也不是十场戏或必须遵守的唯一公式。

## 知识单元

### 概念

- **梗概**：讲清主角、欲望、阻力、变化和结果，允许保留概括性判断。
- **大纲**：把判断翻译成事件、场面、动作和因果，用于检查故事能否继续写成剧本。
- **可拍信息**：环境、动作、对白、沉默、视线、道具状态和信息揭示顺序等可执行内容。

### 原则

- **拿事说话**：不要写“他冷漠”，要写他在应该行动时选择了什么。
- **从结果反推开场**：采用成长型结构时，可比较开场与结尾选择；也允许稳定立场被考验、负向变化或观众认知改变，不要求开场永远与结尾相反。
- **后果来自选择**：后半程的重要打击优先回收主角早期的不作为、缺陷或错误决定。
- **高潮回答主题**：动作规模不是核心，人物用什么行动完成价值转变才是核心。
- **先有简单内核，再增加复杂维度**：人物、视角或时间线增多之前，先确认谁持续作出决定、所有线围绕什么核心事件、因果按什么顺序成立。
- **分场服务上级任务**：场景不是地点清单；每场都应知道自己替哪个序列办事，并用信息、推进或变化证明存在价值。
- **结构表是诊断坐标**：十序列保持阶段推进的主骨架，十五节拍用来发现功能缺口；二者都不要求一格对应一场，也不替代具体事件。

### 方法

1. 写出故事最终要回答的问题和主角结尾状态。
2. 根据预期终点选择开场基准，明确是人物变化、坚持还是观众重新理解；用必要事件交代处境，不机械制造相反人设。
3. 先用主角、Want、核心动作、主要阻力和结果写出简单内核；多人物故事再检查每个角色是否真有独立目标、选择链和变化。
4. 先列十序列的阶段任务，再用十五节拍检查是否漏掉铺垫、旧办法失败、内在线启动、反噬、低谷消化或最终选择，不按分钟数硬填。
5. 为每个结构关节设计能改变局面的事件，检查身份、欲望、动作、问题、阻力、结果和价值是否逐段变化。
6. 分开复述 A 外在行动线和 B 内在成长线，用 Want/Need 检查两条线是否都由事件推进，再合并能同时服务两线的事件。
7. 把事件拆成连续的故事场面，为每场写清任务、对抗、场头与场尾的变化，以及有效的进入和离开动作。
8. 把“意识到、感觉、关系恶化”等抽象句逐一改成环境、动作、对白或信息揭示顺序。
9. 删除、合并没有有效信息、推进、变化或整体节奏功能的场次，避免被对白和局部灵感带散。

### 案例

“想殉职的警察”从逃避责任出发：开场不作为埋下原罪，家庭失败和经济困境触发错误欲望，越想送死越获得英雄声誉，中段形成虚假胜利；后半程由原罪反噬，高潮才把“求死逃避”转成“承担责任”。

### 反例、边界与开放问题

- 反例：每个序列只是换一种危险任务，风险和人物状态没有变化。
- 边界：7 分钟短片不必机械保留十个完整序列，但开场状态、触发、升级、危机选择、高潮回答和情绪收束仍要清楚。
- 开放问题：短片中哪些结构关节可以合并，合并后如何避免人物转变显得突兀。

## 方法与案例

### 大纲事件化检查

| 检查项 | 要问的问题 |
|---|---|
| 人物判断 | 观众通过哪件事得出这个判断？ |
| 关系状态 | 两个人的距离、动作、回避或选择怎样表现关系？ |
| 因果 | 这一场结束后，后面有什么事情因此不得不发生？ |
| 递进 | 风险、代价、误解、身份或关系至少哪一项升级？ |
| 主题 | 高潮中的关键行动怎样回答故事真正的问题？ |

### 复杂叙事：简单内核、角色线与视角矩阵

先把复杂大纲压回一句话：**谁为了什么采取什么核心行动，受到哪些主要力量阻止，最后付出什么代价或得到什么结果。** 如果删掉支线、合并相似角色并按因果顺序复述后，主线仍不能成立，复杂形式很可能正在遮盖结构缺口。

再逐个检查角色线。戏份多、性格鲜明、短暂离队或发生一次变化，都不自动等于独立主角；当一个人物的经历、选择、知情或关系需要单独追踪时，可以单列。目标、激励、代价与变化是比较维度，不要求五项独立且全部有成长。团队故事可暂压成一个行动单位作测试，但合并若抹去核心关系与观看路径，就应保留多中心组织。

多角色共同经历一场戏时，用双栏或多栏标注它对每个人分别是什么结构功能；同一事件可以是甲的日常、乙的转折。随后建立视角矩阵，控制信息而不是只统计出场：

| 场景／事件 | 角色 A 知道、误判与选择 | 角色 B 知道、误判与选择 | 观众知道什么 | 叙事效果 |
|---|---|---|---|---|
| 待填写 | 这场前后有什么变化 | 这场前后有什么变化 | 跟随一人、局部知情或掌握全局 | 共情、悬念、误会或戏剧性反讽 |

矩阵用于检查观众站在哪里：视角增加会带来信息快感，也会分散单主角共情。若某条人物线和信息切换既不改变选择、不增加阻力，也不改变观众判断，应考虑合并或删除。

### 十序列与十五节拍的双层诊断

十序列仍负责观察故事是否分阶段升级，以及开场、激励、转折、危机、高潮之间的因果是否连贯。十五节拍不替换十序列，只在已有骨架上提供更细的诊断坐标：

| 阶段 | 十五节拍坐标 | 诊断重点 |
|---|---|---|
| 建立与上路 | 开场画面、点主题、铺垫、推动／激励、争执、第二幕衔接点 | 常态是否可感，旧办法是否失败，主角是否主动跨过门槛 |
| 展开与转向 | B 故事、游戏时间、中点 | Need 是否通过事件显形，类型承诺是否兑现，中点成果是否携带代价或反噬 |
| 压迫与低谷 | 坏蛋逼近、一无所有、灵魂黑夜 | 前文伏笔是否兑现，外部损失与内部消化是否都发生 |
| 重选与回答 | 第三幕衔接点、结局／高潮、终场画面 | 最难方案是否来自铺垫与人物变化，终局行动是否回答主题并证明新状态 |

使用顺序是先填“这里缺什么功能”，再从人物、环境和素材中寻找事件。分钟数只用于理解长片模型，短片可以压缩、合并或省略节点；同一事件能承担多个节拍时不必拆场，也不能为了填满十五格制造空事件。

### A/B 故事与 Want/Need 交叉检查

本表沿用查理课程及Snyder的外在／内在教学映射，不是所有影视开发中A/B命名的唯一含义。《救猫咪》官方词汇表确有此对应，B Story也可由承担主题的关系故事实现。使用时先说明当前谈的是“外在目标／内在需要”两条分析维度，还是“主要情节／次要情节”两组事件；两种划分不能直接互换。独角短片不因没有独立B支线就失败，同一行动也能同时检验目标与价值。[体系原定义](https://savethecat.com/glossary)

| 检查层 | A 故事 | B 故事 | 交叉检查 |
|---|---|---|---|
| 驱动力 | Want：人物自觉追逐的外在目标 | Need：人物未必自知的内在缺失 | Want 与 Need 是否既有关联又不只是同义改写 |
| 事件变化 | 接任务、受阻、换方案、获得或失去结果 | 被触动、旧信念受挫、关系反馈、新选择 | 每个重要事件标记 `A`、`B` 或 `A+B`，标签必须对应真实变化 |
| 完成判断 | 外部行动是否实现 | 人物是否以新行为证明成长 | 高潮是否同时检验行动能力与价值选择 |
| 常见断裂 | 事件很多但意义不累积 | 只在结尾宣布“成长了” | 单独复述任一条线时，能否说出连续的因果和渐进节点 |

在采用外内双轨的故事里，分别说明目标进展和信念／关系变化，再检查两者如何由同一批事件相互影响。若只能说“他逐渐成长”，检查是否有触动、压力、选择与结果等证据；节点多少依篇幅与变化幅度决定，不硬凑三次。稳定人物可以通过承受更高代价仍坚持，显示其价值，而不必得到新信念。

### 从大纲拆场与逐场复核

1. 为每个序列写一句阶段任务，再把其中的事件拆成连续故事场面，不按地点名称机械切分。
2. 为每场写一句“这场要办什么事”，标记它传达的有效信息、对上级序列的推进，以及场头到场尾的变化。
3. 把必要信息分派给环境、动作或对白；若一场只交代一条背景，先把信息迁入已有冲突场，再考虑合并或删除。
4. 从改变局面的动作进入，在最后一个有效动作后离开；动作可以是选择、递出物件、移开视线、挂断电话或停止某种行为。
5. 对抗型场景检查环境、对手或自我如何施压；观察、余波和过渡段也可以通过信息、关系、时间或形式积累承担功能。没有对抗时应说明其作用，而非强加争执。

| 检查项 | 自问 | 常见修正 |
|---|---|---|
| 信息 | 观众在这场获得什么有效新信息？ | 让环境、动作、对白分担，删除无用背景 |
| 推进 | 这场怎样完成所属序列的阶段任务？ | 增加代价、减少退路或改变行动方向 |
| 变化 | 场尾相比场头，局面、认知、关系或决定变了什么？ | 加入发现、选择、失败、获得或反转 |
| 动作进出 | 是否从静态说明开始，又以沉思、收拾或离开拖尾？ | 从有效动作切入，在最后一个有效动作后离开 |
| 对抗 | 人物正在对抗环境、对手还是自己？ | 让阻力进入当前行动，不强行制造争吵 |
| 效率 | 是否只为一条信息单独搭了一场？ | 迁移有效信息后合并或删除 |

### 从文件名称判断到使用目的

前面的十序列、十五节拍及事件化清单是本库既有训练路径。用于非成长型、非因果主导或观察性作品时，先调整验收问题；“每场对抗”“相反开场”等简化不能充当一票否决。

Synopsis（故事梗概：概述主要人物和故事走向）、Outline（大纲：安排段落、事件与推进的工作文档）、Treatment（故事处理稿：用连贯叙述传达故事、人物、语气与观看体验）没有全球统一的篇数或长度。John August明确指出不同作者会交叉使用outline与treatment；先问文件给谁、要帮助决定什么，再确定详细程度。[作者说明](https://johnaugust.com/2003/specs-treatments-and-pitches)

个人探索稿可以保留跳跃和待定；多人讨论稿需要读者看懂关键因果；进入正式剧本还要把必要行动、对白和场景条件落实。大纲“完整”只说明该轮问题有可判断材料，不等于故事采用、预算可行或拍摄释放。

### 事件化要补的是因果和可感知证据

`[本体系综合方法]` 对一个关键变化，检查场头条件、人物想争取什么、触发或阻力、选择／拒绝、行为后果及场尾状态。事件不仅是身体动作；信息获得、公开承诺、隐瞒被识破也可以改变行动条件。动作多但结果不累积，仍可能只有活动没有推进。

“他终于信任妹妹”目前是作者结论。下一步先确认信任指什么、此前为什么不能信、这次哪件事改变了判断、信任将带来何种风险，再选择观众能接收到的表现；不能随手补“交出钥匙”就宣布完成，因为交钥匙也可能是敷衍、被迫或试探。没有前后情境时，应返回待确认项而非生成新事实。

### 一个贯穿例子：保管权发生变化

`[构造教学例子；非用户项目]` 已确认姐姐一直独自保管账本。她看到弟弟主动承认一笔对自己不利的账目，之后让弟弟独立核对下一页。这里“诚实证据—承担不利—权限改变”可以让观众推断信任增加；尚需实际表演和声画确认。若弟弟只是照抄正确数字，信任变化的理由更弱，不能靠姐姐一句“我信你了”自动补足。

反例：姐姐交出账本是因为双手拿不住东西，随后立刻收回。在同样“交物件”的表面下，没有相同的关系结论。检验应追问行为在当下条件中排除了哪些其他解释，而非只检查有没有动作。

### 顺序、删场与导演接管

因果顺序说明事情如何发生，叙述顺序说明观众何时接收到它；非线性作品需要两套记录。人物的决定要符合其当时认知，不能借用观众后来才得到的信息。删场时查后面的选择是否仍有原因，以及情绪、等待、风格和主题是否失去必要支撑；“删了仍看懂剧情”并非唯一标准。

John August《How to Write a Scene》强调先确定本场任务，再试进入方式与草拟；这是作者工作法。他也说明《Big Fish》的一份序列大纲是在初稿后整理的，用来观察篇幅分配。大纲可以参与反向诊断，不必一开始就写完所有格子。[场景方法](https://johnaugust.com/2007/write-scene)、[实际大纲用途](https://johnaugust.com/2011/outlines-arent-essential)

给导演的故事输入要清楚列出采用事实、事件结果、人物知情、必要可见/可听信息和仍待定内容。此处不替导演指定全部镜头或演员内部过程；导演发现故事层矛盾时，应带证据返回编剧讨论。
