# 王煜全访谈：AI泡沫将在2029年破裂

## 材料简介

这是一场由“易论AI”发布、亚婷主持、王煜全作为嘉宾的 AI 产业访谈。它没有围绕某个模型或工具展开，而是借工业革命、移动互联网、平台经济、登月工程和生物进化等类比，回答“AI 的可持续机会究竟在哪里”。

## 一分钟总结

王煜全认为，AI 泡沫破裂并不等于 AI 技术失败，而可能来自“真实收益增长速度赶不上市场预期”。真正的机会也不只是生成内容，而是把大模型像电力一样接入由多个 Agent 组成的工作流程，让人从逐项执行转向设定目标、编排流程、处理异常和校正结果。他进一步区分平台侧应用与用户侧应用：前者主要替平台增收，后者应掌握用户自己的数据、跨平台调用工具，并代表用户利益。商业落点是把过去只有富人才能获得的专家服务规模化为普惠服务。与此同时，语言模型仍不等于能理解复杂现实、文化语境和人类目标的完整智能；未来人的价值会更多集中在选择、综合判断、探索和定义问题。

## 整体结构

- `00:00–08:38`：以历史技术周期解释“2029 泡沫”假说，再从固定互联网与移动互联网的差异推演内容模型、行为模型和中国的可能机会。
- `08:38–18:18`：把工业革命的核心从“蒸汽机”改写为“连续动力 + 流程化”，并用福特流水线类比以 Agent 为核心的企业流程。
- `18:18–28:39`：从个人赋能、平台围墙、隐私与信任谈到分布式智能，提出个人 Agent 应掌握个人数据并代表用户利益。
- `28:39–35:43`：区分供给侧平台应用与用户侧应用，把 AI 的商业价值归纳为“服务平权”和一人一套的个性化服务。
- `35:43–45:43`：讨论语言模型、世界模型、领域智能和“文化 AI”的差异，再用文化与技术共同进化解释人类为何不会被简单地视为过渡物种。
- `45:43–53:47`：把技术优势转成四步社会扩散模型，最后通过快问快答讨论创业、协作、教育、工作和探索能力。

## 分章节／分集导览

### 00:00–05:00｜技术周期与 2029 泡沫假说

主要讲什么：用工业革命、互联网泡沫等历史模式区分技术真实进步、社会恐慌、市场狂热和泡沫破裂。

关键内容：

- 技术能力会叠加上升，但技术改变社会的过程常出现相似节奏：先恐慌被替代，再因看见机会而过度狂热。
- 王煜全判断当前仍在“低谷孕育狂热”的阶段，推测 2028 年可能形成高预期，2029 年因兑现速度不足而出现市场下跌。
- 在他的定义里，泡沫并不说明方向错误，而是正确方向被人性和资本提前透支。

复盘提示：重点回看 `03:37–04:58`；注意这是历史类比驱动的预测，不是可直接验证的时间表。

### 05:00–08:38｜中美路径与行为模型

主要讲什么：从美国偏固定网络、中国偏无线与移动互联网的路径差异，推演内容数据和行为数据的不同商业价值。

关键内容：

- PC 和固定互联网主要沉淀知识与内容，生成式 AI 延续了“内容聚集—内容生成”的路径。
- 手机把人的连续行为数字化并集中记录，使大规模、连续的社会行为观察成为可能。
- 他由此提出“行为模型”的机会：理解并预测下一步行动，比只给建议更容易形成可收费的服务。
- 以移动通信中的开关机与出行数据为例，说明行为数据可以支持订票、出行等主动服务，但也隐含明显的隐私风险。

复盘提示：回看 `06:20–08:36`；区分“行为数据有价值”和“平台有权无边界使用行为数据”。

### 08:38–11:26｜工业革命的能力本质

主要讲什么：把蒸汽机、阿克莱特工厂和福特流水线串成“连续动力如何转化为规模化生产”的历史类比。

关键内容：

- 王煜全认为，工业革命的核心能力不是某台蒸汽机，而是可持续、可传导的连续动力。
- 阿克莱特用水力纺纱机（water frame）和工厂组织把动力变成生产系统；福特又用电力和流水线把动力送到每个工序。
- 技术只有进入流程、被各行业学会并稳定复制，才真正释放生产力。

复盘提示：重点回看 `08:40–11:26`；历史细节是嘉宾用于解释产业规律的论证材料，尚未逐项事实核验。

### 11:26–14:02｜以 Agent 为核心重构流程

主要讲什么：将大模型类比电力、Agent 类比工作站，把企业从“以岗位和人构建流程”改成“以 Agent 构建流程”。

关键内容：

- 内容生产可拆成选题、脚本、画面、视频和连续性等 Agent 环节，每个环节由大模型提供能力。
- 人的职责从持续亲自执行，转向看护流程、发现异常、介入修复和恢复运行。
- “人很勤奋、长期加班”不再是最优业务模式；真正的效率来自流程在无人盯守时仍能可靠运行。
- 模型基础设施一旦被大量 Agent 调用，会像电力系统一样产生稳定性、切换成本和平台锁定。

复盘提示：回看 `11:30–13:46`；把“人可以睡觉”理解为可靠性目标，不是忽略监督、责任和质量控制。

### 14:02–18:18｜数字革命仍在中场

主要讲什么：把 AI 视为数字革命的中场，而不是工业革命的简单重复或数字革命的尾声。

关键内容：

- 数字革命的核心是数字经验的积累、提取和使用，既包括内容经验，也包括行为经验。
- 福特流水线出现后，各行业仍需很长时间学会规模化；AI 也需要行业知识和流程改造才能普及。
- 编程工具变易用只是前提，真正稀缺的是有人理解某个行业，并知道如何用编程和 Agent 改造它。

复盘提示：回看 `16:03–18:10`；重点不在“人人都会写代码”，而在“谁能把行业流程重新表达成可运行系统”。

### 18:18–23:30｜个人赋能、平台围墙与隐私

主要讲什么：从“文明级认知能力”推演个人如何借 AI 对抗信息不对称和平台围墙。

关键内容：

- 互联网平台通过支付、广告、商家和数据形成封闭生态；用户贡献行为价值，却缺少议价权。
- 个人 Agent 若能跨平台比较和调用服务，就可能代表用户而不是代表某个平台。
- 操作系统和手机厂商可能成为跨应用 Agent 的入口，因为它们能观察跨应用行为并协调工具。
- 这种能力同时带来更深的隐私风险；可信的关键不是口头承诺，而是利益约束、数据边界与可追责机制。

复盘提示：回看 `19:18–23:16`；把“赋能个人”与“操作系统获得更完整行为数据”同时放在一张风险图里。

### 23:30–28:39｜集中式智能、分布式智能与个人 Agent

主要讲什么：质疑少数公司集中掌握 AI 权力，提出由多个专业智能、个人数据和协作网络组成的分布式智能。

关键内容：

- 嘉宾认为，即使掌权者自认善意，过度集中的智能权力仍然缺少可靠制衡。
- 他用大脑不同系统、群体智能和登月工程类比：复杂智能不一定来自一个包办全部任务的中心。
- 个人 Agent 应掌握个人数据，并能切换模型和服务，而不是被单个平台锁定。
- 他据此判断美团、阿里等传统平台在下一代用户侧应用上“站错位置”；这是利益结构判断，不是对其技术和资源的客观清零。

复盘提示：重点回看 `24:10–28:39`；追问分布式智能如何处理协调成本、安全、身份和责任。

### 28:39–34:01｜用户侧应用与服务平权

主要讲什么：区分供给侧平台和用户侧代理，并把 AI 商业机会归结为规模化专业服务。

关键内容：

- 平台侧应用以提高平台收入为主要目标；用户侧应用由用户付费，理论上更有动力替用户省钱和争取利益。
- 互联网商业常受信息不对称和差异定价影响，个人 Agent 的价值是获得更接近“上帝视角”的比较能力。
- 工业革命降低商品成本，带来“物质平权”；AI 若把专家经验固化为服务，则可能带来“服务平权”。
- 健康、理财和私人顾问是访谈中的例子，但这些领域同时具有较高的监管、责任和安全门槛。

复盘提示：回看 `28:47–34:01`；判断一个 AI 产品究竟代表用户利益，不能只看宣传语，要看付费关系、数据权和失败责任。

### 34:01–35:43｜一人一套的个性化服务

主要讲什么：用私人导购和个性化虚拟商店说明 Agent 如何从“千人一面”走向“一人一面”。

关键内容：

- Agent 根据个人历史、停留和购买反馈持续更新服务，而不是只把用户分进一个粗粒度标签。
- 其价值来自跨站搜索、价格比较和理解偏好，而非单个平台内部推荐。
- 个性化越深入，越需要明确个人数据的存储、迁移、删除和授权方式。

复盘提示：回看 `34:28–35:42`；不要把“更懂你”自动等同于“更为你着想”。

### 35:43–40:44｜语言模型、世界模型与文化 AI

主要讲什么：给当前 AI 能力划边界，并区分单领域能力、综合协调、物理世界理解和文化语境理解。

关键内容：

- 嘉宾认为语言模型已很强，但世界模型仍处于早期；现实世界比语言空间复杂得多。
- AI 可以在单一领域超过人类，复杂任务则需要多个领域 Agent 和一个负责综合的系统。
- 物理 AI 只能识别物体和因果还不够；与人协作还要理解象征、礼仪、价值和冒犯等文化语境。
- 模式识别需要正反样本；过度清洗训练材料可能削弱对边界和错误模式的辨别。

复盘提示：重点回看 `35:43–40:40`；“语言模型 100 分、世界模型二三十分”是嘉宾的比喻性评分，不是测评数据。

### 40:44–45:43｜文化与技术的共同进化

主要讲什么：借达尔文、华莱士和文化人类学讨论人类进化，反驳“人只是硅基生命过渡工具”的宿命论。

关键内容：

- 嘉宾认为单纯自然选择不足以解释人类持续扩张，文化积累和技术选择共同推动人类演化。
- 这一段的功能是把 AI 放回人类文化选择之中：技术能否延续，不只取决于性能，也取决于人怎样组织和扩散它。
- 关于达尔文性选择理论、华莱士声誉和人类进化的具体论断存在较强争议，不能只凭本访谈定论。

复盘提示：回看 `41:40–45:43`；把它作为嘉宾的解释框架，而不是生物学教材结论。

### 45:43–48:18｜从技术优势到文化扩散

主要讲什么：提出技术进入社会的四步模型，并把 AI 的“生存策略”定义为智能服务。

关键内容：

- 四步链条是：技术优势 → 能把技术转成利益的生存策略 → 率先受益的赢家群体 → 对赢家特征的文化模仿与扩散。
- AI 只是第一步；决定产业胜负的是谁能把它变成直接服务或增强个人能力的赋能型服务。
- 未来文化可能从工业时代的标准化，转向差异化、目标导向和解决问题。

复盘提示：回看 `45:29–48:17`；这段最适合转化成项目复盘框架。

### 48:18–53:47｜工作、协作、教育与探索

主要讲什么：用快问快答讨论 AI 时代人的位置，强调人从执行者转向创业者、编排者和探索者。

关键内容：

- “没有工作”不是没有价值创造，而是减少由别人定义任务、以工资交换执行的传统方式。
- 机器承担固定、可流程化的部分；人继续负责目标、选择、安排、跨领域协作、结果校验和修正。
- 教育需要从只训练单项专业角色，转向训练像“元帅”或“刘邦”一样的综合编排能力。
- 是否成为 AI 原住民与年龄无必然关系，更取决于是否持续与 AI 共同思考和做事。
- 自动化实验室说明 AI 与自动化可能把人从重复执行中移开，释放更大的探索空间。

复盘提示：回看 `49:12–53:47`；把“人人创业”理解为自主定义价值，而不是要求所有人立刻注册公司。

## 核心观点总览

| 观点 | 访谈中的论证 | 可调用的判断 |
|---|---|---|
| 泡沫来自预期与兑现速度错位 | 恐慌 → 看见受益 → 狂热 → 兑现不及预期 | 不要把市场回撤直接等同于技术路线失败 |
| 技术能力必须进入流程 | 连续动力只有经过工厂与流水线才释放价值 | 评估 AI 项目时先画完整流程，不只比较模型 |
| Agent 原生组织替代岗位堆叠 | 多个领域 Agent 执行，人处理异常与综合 | 人力投入多少不再是效率的正向证明 |
| 用户侧应用与平台侧应用利益不同 | 谁付费、谁掌握数据、谁承担失败决定代理方向 | 判断产品是否真正代表创作者或用户利益 |
| AI 的大机会是服务规模化 | 将稀缺专家经验转成大众可用服务 | 寻找过去只有高净值人群才能购买的认知服务 |
| 当前 AI 仍缺复杂现实与文化理解 | 单领域强，综合、物理与文化语境仍弱 | 保留人在目标、边界、语境和责任上的控制权 |
| 人从执行上移到选择与探索 | 固定任务交给机器，人做编排、校正和新问题 | 学习重点从单点操作扩展到系统设计与判断 |

## 关键主张与证据边界

| 主张 | 当前证据状态 | 不应误解为 |
|---|---|---|
| AI 泡沫可能在 2029 年破裂 | 嘉宾依据历史类比的预测，时间点高度不确定 | 2029 年必然发生股灾，或 AI 技术届时失效 |
| 中国可能在行为模型上有优势 | 基于移动互联网和行为数据积累的产业推演 | 数据越多就必然领先，或可以忽略隐私与监管 |
| 美团、阿里做下一代应用“已经没机会” | 对平台利益位置的强判断，具有修辞性 | 这些企业缺乏技术、资本或转型能力的事实结论 |
| 最好的公司由 Agent 工作、人处理异常 | 组织设计目标，需要可靠性、可观测性和责任机制支撑 | 当前 Agent 已能无人监督地承担所有关键业务 |
| AI 会带来服务平权 | 商业机会假说，在低成本复制专家能力时可能成立 | 服务质量、责任和收益会自动平等 |
| 人类进化来自文化与技术双向选择 | 嘉宾的综合解释，涉及有争议的生物学与历史论述 | 已获学界一致认可的单一因果模型 |

### 内化检验记录

#### 2026-07-16｜能迁移

- 问题：如果把“用户侧 Agent”转译到 AI 影视工作流，哪些控制权必须留在创作者一侧？
- 核心回答：AI 可以在故事结构、整体编排、分镜、镜头和声音等技术层面提供方案，但作品讲什么、核心表达是什么、希望观众产生何种情绪，以及是否采用这些方案，必须由创作者决定。AI 是协同创作的能力层，不是替代创作意图的自动流水线。

## 复习区

### 一分钟复述

这场访谈用历史类比说明：模型只是能力源，Agent 流程才是生产系统；泡沫破裂可能来自预期跑得比真实应用快。最值得追踪的商业机会不是继续替平台卖更多东西，而是构建代表用户、掌握个人数据、能跨工具行动的用户侧 Agent，把稀缺专家服务变成大众服务。人的位置则从固定执行上移到目标、选择、编排、语境、责任和探索。

### 关键概念

- **Agent 原生流程**：先按机器可运行的方式设计流程，人负责目标、异常和校正，而不是把 AI 塞进原有岗位。
- **用户侧应用**：付费关系、数据控制和行动目标以用户利益为中心的代理。
- **服务平权**：借 AI 复制专家认知服务，降低普通人获得高质量服务的成本。
- **文化 AI**：不仅识别物体和规则，还要理解价值、象征、关系和语境的智能设想。
