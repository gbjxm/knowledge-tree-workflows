# 大学生在校资源与机会清单

这是一篇持续追加的主题笔记，用来记录“在校期间更容易获得、毕业后可能失效或成本上升”的资源、身份窗口与低成本尝试。以后遇到同类短视频或文章，优先追加来源和核验结果，不再为每条材料单独建文件。

## 一分钟总结

视频的核心不是泛泛劝人“珍惜青春”，而是提醒大学生尽早使用六类有时限的机会：教育邮箱、图书馆数据库、软件教育授权、以学生身份联系从业者、创业扶持，以及低成本试错。真正有用的做法不是收藏清单，而是马上查资格、记截止时间，并把资源转成一个可展示的项目、一次信息访谈或一次小实验。

## 可执行清单

| 机会 | 现在可以做什么 | 可能失效或变贵的节点 | 核验边界 |
|---|---|---|---|
| 学校邮箱与学生开发资源 | 确认学校是否提供教育邮箱；查看 GitHub Student Developer Pack 等官方学生计划 | 毕业、邮箱停用或学生资格过期 | 不是所有学校邮箱都能通过所有平台认证，权益清单也会变化 |
| 图书馆数据库 | 登录学校图书馆，查询行业报告、论文和专业数据库；保存检索式与必要笔记 | 校园网、统一身份认证或毕业账号失效 | 数据库采购范围由学校决定；下载和使用须遵守授权规则 |
| 软件教育授权 | 到软件官网查找 Education／Student 页面；挑一款真正需要的工具完成实际项目 | 学生认证过期，转为个人或商业付费 | 免费范围、地区、专业和用途限制各不相同；不要把教育许可默认当作商业许可 |
| 学生身份的信息访谈 | 选 3 位相关从业者，发一封简短、具体、低负担的请教邮件或私信 | 毕业后身份语境改变 | “学生更容易获得回复”是创作者经验，不是保证；应尊重对方时间和隐私 |
| 创业与孵化支持 | 查询学校就业创业中心、当地人社部门和官方政务平台；核对贷款、补贴、场地与导师计划 | 毕业年限、注册时间、地区和项目条件变化 | 贷款与补贴不是普遍自动获得；必须以当期官方政策和个人资质为准 |
| 低成本试错 | 从比赛、实习、跨专业课程、社团或小项目中选一项，预先写明试验目标和退出条件 | 工作后时间与机会成本通常上升 | 试错也有时间成本；重点是留下作品、数据、联系人或判断，不是无目的地频繁切换 |

## 复习区

### 关键概念

- **期限资源**：会因毕业、邮箱停用或资格变化而失效的访问权和优惠。
- **身份窗口**：学生身份让某些学习请求、访谈和政策申请更自然或更容易进入。
- **低成本试错**：在后果可控时，用小实验换取作品、经验和方向判断。
