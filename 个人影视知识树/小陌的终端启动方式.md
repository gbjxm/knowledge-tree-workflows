## 1. OpenCodex ^open-codex

### 日常启动

1. 先启动 Clash，并保持运行。
2. 打开 PowerShell，复制并运行：

```powershell
ocx start
```

3. 再启动 Codex。

> 如果出现 `Proxy already running`，表示 OpenCodex 已经启动，不需要重复启动，直接使用 Codex 即可。

### 打开 OpenCodex 仪表盘

```powershell
ocx gui
```

也可以在浏览器打开：

```text
http://127.0.0.1:10100/
```

仪表盘网页可以关闭，不影响 OpenCodex 代理运行。

### 查看运行状态

```powershell
ocx status
ocx health
```

### 重启 OpenCodex

```powershell
ocx restart
```

如果 Codex 一直显示“正在重新连接”，先确认 Clash 正在运行，再执行上面的重启命令。

### 正常关闭

建议先退出 Codex，然后运行：

```powershell
ocx stop
```

`ocx stop` 会停止本地代理，并把 Codex 恢复为官方直连配置。

> 不要直接结束 `bun.exe`，也不要用关闭终端窗口代替 `ocx stop`，否则 Codex 可能仍然指向已经停止的本地代理。

### 出现故障时

```powershell
ocx health
ocx restart
```

如果仍然出现 `502 Provider unreachable`，检查 Clash 是否正在监听 `127.0.0.1:7897`。

## 2. OpenClaw ^open-claw

### 普通启动

```powershell
openclaw
```

### 启动 Web / Gateway

```powershell
openclaw gateway
```

### Gateway 异常时重启

```powershell
openclaw gateway restart
```

### 查看状态与检查配置

```powershell
openclaw status
openclaw doctor
```

## 3. DeepSeek Harness ^deepseek-harness

每次新开 PowerShell 后，按顺序复制运行：

```powershell
$env:DSH_HOME="D:\DSH\dsh-home"
$env:npm_config_cache="D:\DSH\npm-cache"
cd D:\DSH
npx --yes @deepseek-ai/dsh web
```

如果普通启动卡在转圈，使用详细日志模式：

```powershell
npx --yes --loglevel verbose @deepseek-ai/dsh web
```

启动后通常打开：

```text
http://127.0.0.1:3080
```

## 4. IndexTTS 配音 ^indextts

复制下面整段到 PowerShell：

```powershell
Set-Location 'D:\codex\IndexTTS'

# 仅清除当前窗口的代理，避免本地 Gradio 启动检查被代理拦截
$env:HTTP_PROXY = $null
$env:HTTPS_PROXY = $null
$env:ALL_PROXY = $null
$env:http_proxy = $null
$env:https_proxy = $null
$env:all_proxy = $null
$env:NO_PROXY = '127.0.0.1,localhost,::1'
$env:no_proxy = $env:NO_PROXY

& '.\.venv\Scripts\python.exe' '.\webui.py' `
  --version 2.5 `
  --model_dir '.\checkpoints' `
  --host 127.0.0.1 `
  --port 7860
```

启动后打开：

```text
http://127.0.0.1:7860
```

IndexTTS、DeepSeek Harness 等前台服务需要保持终端窗口打开；在对应窗口按 `Ctrl + C` 可停止当前服务。

## 5. 学习终端／个人终端 ^personal-system

这是在浏览器中使用的本地个人系统。个人终端首页、学习小岛、领航室、素材观察室和信息收集共用一个服务，启动一次即可。

### 日常启动

打开 Windows PowerShell 或 PowerShell，复制下面整行后按 Enter：

```powershell
& 'D:\codex\小陌的学习系统\启动个人终端.cmd'
```

启动成功后会自动用 Edge 打开个人终端首页；服务在后台运行，启动完成后可以关闭 PowerShell 窗口。也可以在文件夹里双击 `D:\codex\小陌的学习系统\启动个人终端.cmd`。

如果浏览器没有自动打开，点击下面的入口：

| 入口 | 网页 |
|---|---|
| 个人终端首页（四岛） | [打开个人终端](http://127.0.0.1:8787/) |
| 学习小岛 | [打开学习小岛](http://127.0.0.1:8787/learning/) |
| 领航室 | [打开领航室](http://127.0.0.1:8787/navigation/) |
| 素材观察室 | [打开素材观察室](http://127.0.0.1:8787/observatory/) |
| 信息收集 | [打开信息收集](http://127.0.0.1:8787/information/) |

已经启动时，再运行同一条命令会复用当前服务并打开首页，不会重复启动一套服务。

### 关闭和停止

关闭网页或 PowerShell 窗口不会停止后台服务，随时可以重新打开网页。

要停止整个系统，先确认需要保留的内容已保存，再运行：

```powershell
& 'D:\codex\小陌的学习系统\停止个人终端.cmd'
```

也可以双击同一文件夹里的 `停止个人终端.cmd`。后台服务应使用这个停止入口关闭。

### 下次重新打开

电脑重启或服务停止后，重新运行上面的启动命令，即可打开个人终端并继续使用。

## 常用键位 ^common-keys

- `↑`：调出上一条命令。
- `Tab`：自动补全命令或路径。
- `Ctrl + C`：中断当前正在执行的前台命令。
- `Ctrl + L`：清空 PowerShell 当前屏幕显示。
