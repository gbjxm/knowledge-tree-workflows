# 小陌的视觉案例参考库

这里专门收藏可浏览、可检索、能看到实际画面或提示词结构的视觉案例库，用于寻找人物、角色设定、海报、UI、光线、构图、色彩、镜头和动态技法参考。

> [!important] 参考不等于复制
> 本页只保存入口和使用判断，不批量搬运他人的图片或提示词。真正用于项目时，要重新核对来源、作者、模型版本、肖像与商标风险、平台条款和商用授权；从案例中提取视觉关系，再按自己的剧本、资产和连续性要求重写。

## 怎么使用这页

- **找 GPT‑Image‑2 提示词结构**：先看 ZeroLu 和 erickkkyt；想看大量方向时再看 YouMind。
- **找官方 AI 社区成图与参数**：看 Midjourney Explore 或 Adobe Firefly Community。
- **找电影光线、构图、色彩和场景参考**：看 ShotDeck、FilmGrab 或 Flim。
- **找运镜、转场和动态视觉技法**：优先看 Eyecandy。
- **遇到真正想采用的提示词**：明确说“放进百宝箱”后，再精选写入 [[小陌的AI百宝箱]]；不要把整库直接复制进去。
- **遇到需要安装的 Skill 或工具**：继续放进 [[小陌的仓库]]，本页只保留视觉案例入口。

## GPT‑Image‑2 提示词与成图案例

### ZeroLu｜Awesome GPT Image 2

- **入口**：[打开 GitHub 仓库](https://github.com/ZeroLu/awesome-gpt-image)
- **简介**：社区维护的 GPT‑Image‑2 提示词与成图案例库，提供简体中文等多语言 README。官方页面按摄影写实、游戏娱乐、UI 与社交媒体、视频拼贴、文字海报、信息图、角色一致性和图片编辑分类。
- **最适合**：先看成图，再拆解提示词中的主体、环境、镜头、光线、材质、版式和文字约束。
- **可靠性**：中。仓库会标注部分 X/Twitter 来源，但案例效果受模型版本影响，社区说法不能当作官方能力承诺。
- **核验状态**：2026-07-30 可访问；页面显示最近更新为 2026-07-29。

### erickkkyt｜Awesome GPT‑Image‑2 Prompts

- **入口**：[打开 GitHub 仓库](https://github.com/erickkkyt/awesome-gptimage2-prompts)
- **简介**：结构化提示词画廊，仓库说明包含 326 张来源卡与 404 个整理结果，提供预览图、作者与来源信息、可复制提示词和 JSON 数据。
- **最适合**：寻找较完整的提示词正文，比较同一视觉方向在主体、构图、材质和文字上的写法。
- **可靠性**：中。来源标注比纯搬运库更清楚，但仍要点回原始作者核对，不能只看整理页。
- **核验状态**：2026-07-30 可访问；图库构建日期标为 2026-04-27。

### YouMind｜Awesome GPT Image 2

- **入口**：[打开 GitHub 仓库](https://github.com/YouMind-OpenLab/awesome-gpt-image-2)
- **简介**：强调数量和多语言浏览的大型 GPT‑Image‑2 案例库，仓库主页宣称收录 2000+ 提示词和预览图。
- **最适合**：需要快速扫大量题材、版式和商业视觉方向时作为灵感搜索池。
- **可靠性**：中低。数量大、自动同步痕迹明显，文档曾出现模型归属等事实错误；只把它当灵感入口，不把说明文字当技术事实。
- **核验状态**：2026-07-30 可访问。

### wuyoscar｜GPT Image 2 Prompt Gallery

- **入口**：[打开 GitHub 仓库](https://github.com/wuyoscar/GPT-Image2-Skill)
- **简介**：小规模精选提示词画廊，同时包含 Codex / Claude Skill 和 CLI。案例覆盖论文图、海报、UI mockup、游戏 HUD、漫画、摄影、字体、地图和参考图编辑。
- **最适合**：研究“提示词案例怎样进一步变成可调用工作流”。
- **可靠性**：中高。范围较小但结构清楚，仓库主动提醒不要盲目覆盖已有 Skill 或 API Key。
- **使用边界**：当前只浏览案例，不安装 Skill，不配置 API Key。

## 官方 AI 社区视觉画廊

### Midjourney Explore

- **入口**：[打开 Explore](https://www.midjourney.com/explore)
- **官方说明**：[Midjourney Website Overview](https://docs.midjourney.com/hc/en-us/articles/33329460426765-Website-Overview)
- **简介**：Midjourney 官方社区展示页，可查看其他用户的图片和视频；打开作品后可看到创作者、提示词和参数，也能按热门、随机、时间范围或相似画面寻找参考。
- **最适合**：寻找成熟的构图、风格、色彩与材质方向，以及 Style Reference 代码。
- **注意**：访问详情、复用提示词或生成通常需要登录；提示词对 Midjourney 版本高度敏感，不能原样移植到所有模型。

### Adobe Firefly Community

- **入口**：[打开 Firefly Community](https://firefly.adobe.com/community)
- **官方说明**：[Adobe Community Gallery 说明](https://helpx.adobe.com/uk/firefly/web/share-and-download/share-in-the-firefly-community-gallery/firefly-community-overview.html)
- **简介**：Adobe 官方社区图库，包含用户图片、视频和教程；悬停或打开作品可查看提交者和提示词，并进入 Firefly 编辑器进行 Remix。
- **最适合**：广告、设计、合成与可编辑工作流参考，尤其适合观察提示词与最终商业视觉的对应关系。
- **注意**：社区界面目前以英文为主；Remix 不等于获得原作者素材的再发布权。

## 电影画面与动态技法参考

### ShotDeck

- **入口**：[打开 ShotDeck](https://shotdeck.com/)
- **官方介绍**：[关于 ShotDeck](https://shotdeck.com/welcome/about)
- **简介**：由电影摄影师 Lawrence Sher, ASC 创办的可检索电影与商业影像静帧数据库，强调按镜头、构图、色彩、光线和场景表达检索。
- **最适合**：前期 lookbook、色彩方向、摄影参考、场景气氛和导演沟通。
- **注意**：账户、免费额度和价格可能变化；静帧用于参考不等于获得影片画面的商用授权。

### FilmGrab

- **入口**：[打开 FilmGrab](https://film-grab.com/)
- **官方介绍**：[关于 FilmGrab](https://film-grab.com/about/)
- **简介**：由一位电影摄影师长期手工维护的免费电影静帧参考库，官方说明覆盖近 4000 部影片，可按影片、导演或摄影指导查找。
- **最适合**：按整部电影浏览光线、构图、色彩和场面调度的连续视觉语境。
- **注意**：网站明确将图片作为教育与参考用途展示，不是商业图库；不要把静帧直接当成可发布素材。

### Eyecandy

- **入口**：[打开 Eyecandy](https://eyecannndy.com/)
- **简介**：按视觉技法组织的动态案例库，包含 Dolly Zoom、Match Cut、Split Diopter、Snorricam、Whip Pan、Datamosh、遮罩、第一人称、硬光等大量分类，并以 GIF 或短片段展示效果。
- **最适合**：不知道某种镜头或动态效果叫什么时，用画面反查技法；也适合为分镜、镜头计划和视频提示词找运动参考。
- **可靠性**：中高。分类由创作者社区整理，网站也说明命名并非始终百分之百准确，适合学习与启发，不代替正式术语核验。
- **费用**：网站说明免费使用。

### Flim

- **入口**：[打开 Flim](https://flim.ai/)
- **简介**：面向导演、设计师、广告公司和美术指导的综合视觉搜索与 moodboard 平台。官方主页显示其数据库覆盖电影、广告、MV、动画、剧集和大量静帧。
- **最适合**：跨电影、广告、时尚和 MV 搜索视觉方向，并把参考整理成 moodboard。
- **注意**：属于商业平台，搜索额度、导出能力和价格会变化，正式付费前重新核对；平台内图片仍受原作品权利约束。

## 收录标准

后续新增视觉案例库时，优先保留满足以下条件的来源：

1. 能直接看到图片、视频或动图案例，而不是只有宣传文案。
2. 尽量展示提示词、参数、作者、作品或影片来源。
3. 分类和搜索方式对人物、场景、色彩、镜头或资产设计有实际帮助。
4. 当前链接可访问，付费、登录和下载限制写清楚。
5. 明确区分“用于参考”“允许下载”和“允许公开或商业使用”。
6. 不因数量大就默认质量高；优先来源清楚、案例有代表性、能转化为创作判断的库。
