### video-shotcraft

- **原始仓库**：[Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)
- **动态样片画廊**：[video-shotcraft Gallery](https://vincentwei1021.github.io/video-shotcraft/)
- **类型**：第三方 Codex / Claude Code Skill，基于 Remotion 制作产品宣传视频
- **当前状态**：待评估，未安装
- **收录日期**：2026-07-27

#### 它能做什么

它不是直接生成真人电影画面的 AI 视频模型，而是一套产品动效制作工具箱。Agent 可以根据网页、桌面软件界面或产品截图，设计分镜并生成 Remotion 视频工程，包含真实页面截图、2.5D 运镜、UI 动效、文字包装、节奏卡点和声音设计，最后渲染为产品宣传片或功能演示视频。

比较适合：

- 软件、App、网站和 AI 工具的发布宣传片
- 产品功能演示与 UI 动效短片
- 科技感片头、HUD、数据可视化镜头
- 普通影视项目中的电脑、手机或系统界面段落
- 单独借用某个转场、数字滚动、卡片飞入或聚光特写效果

不适合直接承担人物表演、写实场景或叙事镜头生成，也不能替代可灵、Veo、Runway 等生成式视频工具。

#### 简要使用方式

未来完成安全审查并确认安装后，可以选择四种使用方式：

1. **套用 Ink Press 模板**：用自己的产品截图、文案和品牌颜色替换现成宣传片内容。
2. **自主制作完整宣传片**：把项目路径、网页或截图交给 Agent，由它设计视觉方向、镜头、音乐和声音。
3. **共同创作**：先确认产品定位、视觉方向、镜头映射和完整分镜，再开始制作。
4. **只使用一个动效**：从在线 Gallery 挑选镜头卡名称，让 Agent 将该效果适配到指定素材。

未来可参考的调用方式：

```text
使用 video-shotcraft，为这个网页产品制作一支功能宣传片。先检查产品内容并给出模式建议，不要直接开始制作。
```

```text
参考 video-shotcraft Gallery 里的【镜头卡名称】，把这个动效适配到我的产品截图。
```

#### 使用前注意

- 需要 Node.js、React、Remotion 和浏览器渲染环境，并非开箱即用的视频生成服务。
- 若需要截取登录后的产品页面，应使用演示账号和虚构数据，避免客户资料、个人信息、密钥或内部数据进入画面。
- 仓库代码采用 Apache-2.0，但 Remotion 和内置音频有各自的授权要求；商用前需要重新核对。
- 仓库文档中的镜头卡数量曾出现 104 与 106 的差异，说明仍在快速更新，正式使用前应以当时版本为准。
- 当前仅做了公开文档层面的了解，尚未逐文件审查代码和脚本。

### Microsoft Playwright MCP

- **原始仓库**：[microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp)
- **官方替代方案**：[microsoft/playwright-cli](https://github.com/microsoft/playwright-cli)
- **类型**：微软官方 MCP Server，向 Codex、Claude 等 Agent 提供 Playwright 浏览器自动化能力
- **当前状态**：待评估，未安装
- **收录日期**：2026-07-30

#### 它能做什么

Playwright MCP 让 Agent 通过网页的结构化无障碍快照理解页面，并执行打开网页、点击、输入、切换标签页、上传下载、截图、保存 PDF、检查控制台和网络请求等操作。它支持 Chrome、Edge、Firefox、WebKit、移动设备模拟以及持续浏览器会话，普通表单和后台页面的操作通常比纯截图坐标识别更稳定。

比较适合：

- 重复收集比赛、电影节、AI 工具和行业网站资料
- 自动下载公开规则、附件，或保存网页截图和 PDF
- 测试作品集网站、AI 影视网页工具和本地 Web 项目
- 检查页面按钮、表单、手机布局、控制台和接口错误
- 为软件宣传片或 `video-shotcraft` 自动采集网页状态和界面素材
- 需要保留登录状态、跨多个页面持续执行的浏览器长流程

它不能自动绕过登录验证、验证码或网站的反自动化限制，也不适合主要依赖画布和视觉坐标的复杂剪辑器、白板、游戏或图形编辑器。它不能替代 Windows 桌面操作工具。

#### 对小陌的价值

当前临时搜索、打开网页和截图已有其他浏览器工具可完成，因此暂时没有必须安装的必要。未来出现以下任务时再重点考虑：

1. 需要反复执行同一套网页查询、填写、核对或下载流程。
2. 开始制作或维护自己的网页工具，需要自动化测试和回归检查。
3. 需要批量采集网页界面，作为产品视频或影视中的屏幕素材。
4. 现有浏览器工具在结构化表单、控制台或网络调试方面明显不足。

#### 简要使用方式

未来完成安全审查并确认安装后，可以向 Agent 提出类似任务：

```text
使用 Playwright MCP 只读检查这个网站，整理页面结构和可下载的公开资料。不要登录、提交表单或发送任何内容。
```

```text
使用 Playwright MCP 测试这个本地网页的主要功能流程，记录失败步骤、控制台错误和截图，不修改业务数据。
```

#### 使用前注意

- 需要 Node.js 18 或更高版本以及支持 MCP 的客户端。
- 它具有真实点击、输入、上传和下载能力；微软明确说明 Playwright MCP 本身不是安全边界。
- 若连接日常浏览器或持久化配置，可能接触 Cookie、登录状态和页面敏感数据。优先使用独立、隔离的浏览器配置与演示账号。
- 默认限制允许访问的网站、文件目录和输出位置；提交、发送、发布、支付及账号权限变更必须保留人工确认。
- 微软目前更推荐编码 Agent 优先考虑更节省上下文的 Playwright CLI + Skill；MCP 更适合需要持续状态、页面结构检查和长时间自主循环的任务。
- 当前只完成了官方 README 和安全说明层面的了解，尚未安装或在本机验证兼容性。

### MediaCrawler

- **原始仓库**：[NanmiCoder/MediaCrawler](https://github.com/NanmiCoder/MediaCrawler)
- **官方文档**：[MediaCrawler 文档](https://nanmicoder.github.io/MediaCrawler/)
- **类型**：基于 Python、Playwright / Chrome CDP 的多平台自媒体公开数据采集工具
- **当前状态**：待评估，未安装
- **收录日期**：2026-07-30

#### 它能做什么

MediaCrawler 用同一套代码分别适配小红书、抖音、快手、B站、微博、百度贴吧和知乎，可按关键词、指定内容 ID 或创作者主页采集公开帖子、视频信息和评论，并支持二级评论、登录状态缓存、代理配置、评论词云及数据导出。

数据可以保存为 CSV、JSON、JSONL、Excel、SQLite 或 MySQL。开源版还提供 WebUI，但仍需要启动 Python 后端和前端服务，并不是安装后直接使用的普通桌面软件。

“支持七个平台”不等于一次搜索自动汇总全网结果。实际使用时通常仍要选择平台、登录对应账号、配置关键词或内容 ID，再分别运行采集任务。

#### 对小陌的价值

未来可能适合：

- 比较同一 AI 影视话题在不同平台的内容趋势
- 收集观众对短片、角色、题材、画风或 AI 工具的公开评论
- 查找创作者账号、案例、比赛信息和潜在受众语言
- 为发行复盘准备评论样本，再区分数据事实、用户反馈和解释假设
- 批量整理公开帖子和评论，供后续去重、抽样、分析或沉淀到 Obsidian

如果只是处理单条 B站课程或抖音视频，现有专用学习 Skill 更轻量；MediaCrawler 的主要增益是跨平台、批量、评论和创作者研究。它只负责采集原始数据，不会自动把数据变成可靠结论或知识笔记。

#### 简要使用方式

未来完成代码、账号和合规审查并确认安装后，可先从单平台、小样本、只读采集开始：

```text
使用 MediaCrawler 调研【关键词】在【平台】上的公开内容。只采集少量样本和必要字段，不下载媒体，不采集个人敏感信息，不使用日常账号。
```

```text
使用 MediaCrawler 获取这条公开内容及其评论，用于非商业研究。限制数量和频率，保留原始链接与采集日期，不进行点赞、关注、发布或私信。
```

#### 使用前注意

- 需要 Python、uv、Node.js；标准模式还需要 Playwright 浏览器环境。
- 官方当前默认通过 Chrome CDP 连接已有浏览器，可能复用 Cookie、登录状态和扩展。不要直接连接日常主账号，优先使用独立测试账号和隔离浏览器配置。
- 评论采集默认关闭，需要主动修改配置；截图中“全部内容一套搞定”的说法有所简化。
- 频繁或大规模采集可能触发验证码、限流、登录异常或账号处罚，平台页面变化也可能随时导致程序失效。
- 评论和账号页面可能包含昵称、头像、位置等个人信息，应实行字段最小化、限定保存期限，避免传播或公开原始个人数据。
- 仓库作者明确限定为学习研究用途，禁止商业使用和大规模抓取；正式使用还需逐个平台核对当时的平台规则和适用法律。
- Pro 版、Agent Skill、多账号和部分增强功能属于另一套商业产品，不能把其宣传能力视为当前开源版默认功能。
- 当前只完成了官方仓库和文档层面的了解，尚未逐文件安全审查或在本机验证。
