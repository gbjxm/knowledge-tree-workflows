# 迁移与路径映射

## 2026-07-18 便携化

本次只改变知识树体系在文件系统中的承载位置，没有改变 Vault 内部目录、笔记、附件、链接或六类框架。迁移切换前后曾完成 113 文件全量一致比对，完整基线保存在 `manifest\vault-before-migration.json`。此后 Obsidian 可正常维护瞬时 UI 文件 `.obsidian\workspace.json`；日常验证仍严格保护其余 112 个文件。

| 旧位置或含义 | 新位置或处理方式 |
|---|---|
| `D:\obsidian\个人影视知识树` | `<便携根目录>\个人影视知识树` |
| `D:\obsidian\.codex` | `<便携根目录>\.codex`，配置升级为相对路径 v2 |
| `D:\ProgramData\CodexHome\skills\七个知识树Skills` | `<便携根目录>\skills` 为规范副本；安装目录只是部署副本 |
| `D:\obsidian\.learning-cache` | 原内容转入本机“不发送”存档；新缓存使用 `<便携根目录>\.runtime\raw-cache` |
| `_archive`、`_backups`、`.workflow-tests`、`.learnings`、旧 `skill-packages` | 转入本机“不发送”存档，不进入便携包 |
| 旧 C 盘 Vault | 继续作为关闭的迁移备份，不删除、不注册为活动目标 |

Vault 内少量旧绝对路径属于历史来源记录，未被重写，也不是运行时默认值。它们只说明当时的来源位置；当前机器路径始终以 `.codex\knowledge-tree.json` 的解析结果为准。

由于当前机器的 D 盘根目录 ACL 拒绝建立计划中的 `D:\影视知识树本机存档`，本机资料实际收纳在便携目录的同级 `D:\obsidian\_本机资料`。该目录不属于便携包，不能发送到新电脑。
