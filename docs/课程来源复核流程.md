# 课程来源复核流程

用于在当次授权范围内，按原视频复核学习区已有课程，保存可理解、可回查、可继续提炼方法的知识。每批先验收再替换；开始一次复核不自动授权四门课全部覆盖。既有资料与个人理解保留，原课练习作为知识保存。

## 每课六步

1. **认清原件和课的边界。**按元数据核对 BV、P、CID、课名和时长，区分一课多 P 与多个独立课程。P2、P3 可以顺序枚举，实际课号与合课关系按课程目录确认。保留旧稿、既有主题关联和个人记录。
2. **先读来源，再看旧稿。**先读完整可用转写，结合实际取得的画面、板书、演示与字幕，按来源顺序记录观点、理由、独特案例、反例、条件与步骤。写作和复核均遵循[共享来源内容契约](../skills/grow-creative-library/references/accuracy-and-merging.md)，其中的信息增量检查与识别疑点处理同样适用于总结、回顾和普通具体名词。来源清单形成后再与旧稿比较；清单本身也要回查，不视为天然正确的答案。
3. **围绕具体知识补核。**抽帧概览用于定位。疑词、否定词、数字、图示编号、画面指代和异常转写段按其影响定点查证，采用[B站原媒体核验说明](../skills/bilibili-study-notes/references/media-evidence.md)。图示与字幕可以支持对应老师讲述；连续运动、切换观感、声音与同步关系需要相应媒体证据。未核部分写明范围，原课未提供的内容不补造。
4. **写可直接阅读的正文。**围绕课程问题组织原理、方法和案例，保留选择的理由、成立条件和来源时间。来源事实、整理归纳、原课练习与个人理解分别归属。审核计数、纠错经过、下载过程和详细待核放来源记录；正文留下影响理解的限制，不复制后台清单和整份转写。
5. **双向复核并检查少量使用任务。**从来源找笔记遗漏，再从笔记找无依据新增，最后核对旧稿独特内容的去向。压缩是否损失信息、识别疑点是否被写实，按共享契约逐段检查。按实际内容用少量问题检查能否解释理由、处理条件变化、承认未讲部分并提炼带条件的方法；不要求日常每课重跑完整A/B评测。
6. **验收一批，再进入下一批。**结构通过和转写到片尾均不等于知识完整。处理影响理解的错误和关键缺口，完成与最终文件一致的来源复核登记，再按当次已采用范围替换。个人理解另存；老师练习继续保留。主题笔记和既有方法技能只在确有内容变化且属于已授权范围时同步。

## 信息取舍

| 内容 | 处理 |
|---|---|
| 定义、论点、因果、适用条件、反例、步骤、图示关系 | 保留实际含义及必要论证，不只剩术语或结论 |
| 外表相似、实际解释不同条件的案例 | 保留差异，不按数量或长短硬删 |
| 讲师的“一般”“这是我的解释”等限定 | 随结论保存，避免变成普遍硬规则 |
| 总结、复述与回顾 | 先核信息增量，再合并纯重复；新增内容在合适处保存一次 |
| 原课练习及其要求 | 保留来源归属，区分是否提供示范答案，不自动生成用户待办 |
| 用户已有理解、学习事实 | 另存保留，不因移除学习栏目而删除 |
| 寒暄、宣传、无信息增量重复 | 压缩或省略，来源记录简记处理范围 |
| 识别不稳的具体细节、缺失的声画 | 区分可确认关系与未核细节，按共享契约概括、标疑或定点补核 |

## 完成范围与后续提炼

- 不固定每课字数、压缩比例或抽帧间隔。黑板讲述、连续电影示范和软件操作需要的证据不同。
- 分别记录已取得、已转写、已读、已核图、已核原声或连续画面的范围。已有图文能支持的知识可以带准确归属保存；未审的独立声画知识仍限制整课完成声明。
- 保留历史输入、旧稿和测试失败。更改笔记后重新核对受影响内容并生成新版本登记，不以只刷新哈希代替复核。
- 来源笔记验收后，再按实际问题提炼适用情境、所需输入、判断依据、操作顺序、例外、失败例和来源。跨课综合与原课观点分开；形成方法卡也不等于已经证明真实创作效果。
- 小样本的文本整理通过，只支持对应规则与材料范围。正式批量时仍需每批核验声画缺口、合课归位、个人记录保护与最终文件绑定，不把一次测试写成四门课全部验收。
