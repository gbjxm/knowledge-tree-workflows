# 抖音学习笔记

## 目标

把公开抖音知识视频转换成两层产物：仓库外的原始证据缓存，以及仓库内的单篇来源笔记。按[分区契约](../grow-creative-library/references/library-layout.md)确定目的；个人学习材料默认留学习区，需要时在区内综合，用户选定具体知识后才进入创作主题。

本 Skill 与 `bilibili-study-notes` 职责对齐，但提取链路专用于抖音：启动独立临时 Edge 配置、强制静音、后台刷新匿名 Cookie，关闭该临时浏览器后再调用 `yt-dlp`。不得操控用户桌面，不得读取或导出用户日常浏览器 Cookie。

## 开始前

1. 读取 `references/extraction-boundaries.md`，遵守浏览器、Cookie、缓存和失败边界。
2. 使用知识树配置加载器解析活动 workspace、vault、source_notes 与 raw_cache；禁止凭记忆硬编码路径。
3. 若用户要求写入知识树，先使用 `grow-creative-library` 确定目的、去向和来源架构；已明确或已授权的决定不重复确认；只提取到缓存时无需创建笔记。
4. 查找同一抖音 ID 或来源 URL 的既有笔记，避免重复建档。

## 提取流程

在 Skill 目录执行：

```powershell
$env:PYTHONUTF8 = '1'
python scripts/douyin_extract.py '<抖音链接>' --transcribe --model base --language zh
```

常用参数：

- `--metadata-only`：只验证后台浏览器、Cookie 与元数据链路。
- `--clip 0,180`：只转写前三分钟，用于快速验收。
- `--out <目录>`：覆盖原始缓存位置；脚本会拒绝把原始文件写入活动 vault。
- `--browser-timeout 30`：延长公开页面加载等待时间。

脚本输出目录默认是 `<raw_cache>/douyin/<抖音ID>-<安全标题>/`，可包含：

- `metadata.json`：经过筛选的公开元数据与提取状态；
- `page-text.txt`：公开页面可见文本，若后台页面成功读取；
- `audio.m4a`：用于本地转写的音频；
- `transcript.md`：带时间码的 faster-whisper ASR 文本。

## 整理笔记

先执行共享[内容保全与双向复核契约](../grow-creative-library/references/accuracy-and-merging.md)，按原材料建立内容清单后写作，再核对原材料、清单与笔记的对应。默认保留完整理解所需的实质观点、论证、独特例子与限定条件，不把主题提炼提前当成来源笔记的压缩目标。

判断是否依赖字幕之外的画面或声音示范；需要时仅通过本 Skill 允许的后台、静音、隔离工具补看相关原媒体。原帧/片段及复核记录留在配置的库外缓存。无法取得的部分如实列缺口，不得接管日常浏览器、把重绘图当原帧，或凭 ASR 推断已看完整视频。

1. 复制 `assets/episode-note-template.md` 作为单篇来源笔记骨架。
2. 分区配置下，个人学习来源默认放在 `source_notes/访谈与专题/抖音学习笔记/`，专业创作用途明确时按对应岗位归位；旧配置沿用既有来源位置；不要把音频、Cookie、浏览器配置或大段逐字稿放进 vault。
3. 明确区分三类证据：视频页面公开信息、平台章节或摘要、ASR。ASR 不是官方逐字稿，专名与关键数字需回听或交叉核验。
4. 时间线以实际时间码为锚点；正文提炼论证脉络、关键概念、方法与案例，不粘贴完整转写。不默认添加复习题、学习任务、待理解字段或空个人栏目；讲者原有训练方法作为来源内容保留并标明身份。
5. 独立视频默认使用：`笔记架构: 单篇材料`、`聚合单位: 单篇`、`架构状态: 已确认`。
6. 只有跨材料可复用、能指导未来行动且本次要求融合的内容才创建主题笔记；按授权分区整理，用来源链接和时间码保留溯源，不从个人学习自动转入创作。
7. 若用户要求知识树沉淀，交给 `grow-creative-library` 完成主题路由、地图与主页更新；仅在用户主动请求学习时使用 `internalize-film-knowledge`，学习交流默认不写回，明确要求保存结果后才记录。

## 完成标准

- `metadata.json` 能对应正确抖音 ID、标题、作者、时长与来源 URL。
- 转写覆盖目标区间；完整转写时，末段时间码应接近视频总时长。
- 来源笔记只有一个一级标题，frontmatter 字段完整，结论均能追溯到公开页面或时间码。
- 原始缓存位于 vault 外，临时 Edge 配置已删除，没有持久化 Cookie。
- 原材料按共享[保留与按需盘点规则](../grow-creative-library/references/durable-source-evidence.md#原材料保留与按需盘点)保存；保留已取得的输入、用于整理的转写、人工校正和复核依据，不因存放在缓存或仍有在线链接就判为可删。无需逐份登记或重复确认，不为归档额外下载完整视频；临时浏览器配置和凭据仍按原隔离边界处理。
- 写入知识树时，相关校验与严格审计通过后才报告完成。
- 在既有来源说明中分开写材料获取范围、笔记内容复核范围和尚未核实部分；末段接近总时长只辅助判断转写时域，不证明中间无损坏或画面知识完整。
- 用共享[覆盖检查接口](../grow-creative-library/references/source-coverage-check.md)核对当前原文本/笔记与覆盖记录的版本和定位，再完成语义双向复核。结构通过和登记闭合不等于语义完整，待核项随部分结果交付，不隐去缺口。

## 停止条件

遇到登录、验证码、私密/已删除视频、地区或年龄限制时停止自动提取并如实说明。不得改用用户现有浏览器配置、绕过验证、反复重试或接管桌面。网络或新鲜 Cookie 错误只允许一次有边界的重试。
