# 抖音提取边界

## 浏览器

- 仅启动专用临时 Edge 用户目录。
- 固定使用 `--headless=new`、`--mute-audio`、`--disable-sync`、`--disable-extensions`。
- 不使用 computer-use，不聚焦或控制用户桌面，不读取默认 Edge 配置。
- 只关闭本次启动的临时浏览器；不得批量结束用户自己的 Edge 进程。

## Cookie 与隐私

- 临时配置只用于获得公开页面所需的匿名 Cookie。
- 在 `yt-dlp` 读取 Cookie 前先关闭临时浏览器，避免数据库锁定。
- 临时配置必须位于系统临时目录，并在任务结束时删除。
- 不导出 cookies.txt，不把 Cookie、签名媒体 URL或浏览器配置写入缓存或笔记。

## 缓存与笔记

- 音频、转写和抓取元数据属于原始证据，写入配置的 `raw_cache/douyin`。
- 原始缓存必须在活动 Obsidian vault 外。
- vault 只保存整理后的 Markdown；不保存音视频与完整浏览器页面。

## 失败策略

- 登录、验证码、私密、删除、地区或年龄限制：停止并报告。
- Cookie 数据库仍被锁：等待后重试一次；再次失败即停止。
- 403 或媒体地址失效：用同一临时匿名配置重试一次；不得无限重试。
- 转写失败但元数据已成功：标记为部分完成，保留已取得证据。
